## 1. Executive Objective: Full End-to-End Wiring & Prudent Code Replacement

Whereas Milestone `v3.9` (`Phases 203–209`) established the foundational T3 research corpus and landed initial additive primitives (`ModelOperationalStatus`, `ReasoningEffort`, `CostProvenanceTier`, `ResumableTurnStreamRegistry`, `LazyMcpGroupRegistry`, `SessionPrivacyPosture`, `EnhancedPromptReceipt`), several legacy Vox code paths still bypass these primitives or rely on pre-audit implementations:
1. `crates/vox-orchestrator-mcp/src/chat_tools/chat/agent_loop/salvage_and_stream.rs` still sets `cost_usd: None` (`L187`), lacks an O(1) streaming token/n-gram loop breaker (`RepetitionGuard`), lacks false tool-refusal auto-recovery (`ToolRefusalDetector`), and does not synchronize mid-stream multi-tab joins under an atomic stream buffer lock.
2. `crates/vox-orchestrator/src/budget/tracker.rs` (`UsageTracker`) only increments raw `AtomicU64` counters with zero pre-flight balance gating (`402` Battery Unit gate), external multi-benchmark priors (`SnitchBench`, `SkateBench`, `SweBench`, `LiveBench`), or 3-tier post-turn cost reconciliation.
3. `crates/vox-orchestrator-mcp/src/agy_worktree.rs` (`DelegationWorktree::cleanup` at `L60–66`) runs `git worktree remove --force`, which is unsafe on Windows NTFS directory junctions in Git `< 2.54` and lacks per-worktree `WorkspaceLease` serialization and `.env*` worktree provisioning.
4. `crates/vox-orchestrator/src/agentos/checkpoint_engine.rs` is a 12-line stub (`should_sparse_checkpoint`) rather than a real Git plumbing checkpoint engine (`refs/vox/checkpoints/` via `git write-tree` + `git commit-tree`).
5. `crates/vox-orchestrator-mcp/src/dei_tools/orchestrator_snapshot.rs` serializes full uncompressed snapshots without response-level ID-table interning (`orchestrationV2IdTable`), body deduplication (`orchestrationV2DedupedBodies`), or cold-connect idle subagent omission (`threadFamilies`).
6. `crates/vox-orchestrator-mcp/src/chat_tools/chat/mentions.rs`, `preamble_and_retrieval.rs`, and `server_state/webhook_intake.rs` lack `@rule:<name>` user rules, dynamic `$variable` prompt interpolation, signed/filtered webhook ingress (retaining a deprecated GitLab token stub at `L27–32`), and external CLI session import (`~/.claude`, `~/.codex`, `~/.cursor`).
