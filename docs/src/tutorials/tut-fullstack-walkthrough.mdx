# Interactive Full-Stack Walkthrough: One .vox File to SQL, Rust & React

{/* kb:summary */}
This interactive tutorial walks through building a complete full-stack module in a single `.vox` file and inspecting the four compiler outputs it generates in lockstep: Turso/SQLite schema definitions, typed Rust Axum route handlers with `Result[T]` error propagation, reactive TypeScript/React components, and JSON-Schema Model Context Protocol (MCP) agent tools.
{/* /kb:summary */}

<Aside type="tip" title="Zero-Drift Full-Stack Architecture">
  In traditional stacks, adding a single field requires editing a SQL migration, a backend struct, an API handler, and a frontend TypeScript interface. In Vox, you declare the domain model once and inspect all four generated targets side by side.
</Aside>

## Step-by-Step Build Path

<Steps>

1. **Declare the Typed Schema (`table`)**

   Every `table` block automatically provisions a primary key (`Id[Ticket]`) and maps fields to both SQLite/Turso column affinities and Rust/TypeScript types:

   ```vox
   table Ticket {
       title: str
       priority: int
       resolved: bool
   }
   ```

2. **Add Read Queries and Write Mutations (`query` / `mutation` / `server`)**

   Queries are read-only; mutations and server functions return `Result[T]` so database or validation errors must be handled explicitly with `?` or `match`:

   ```vox
   table Ticket {
       title: str
       priority: int
       resolved: bool
   }

   query open_ticket_count() to int {
       return len(db.Ticket.all())
   }

   server create_ticket(title: str, priority: int) to Result[str] {
       if priority < 1 {
           return Error("Priority must be at least 1")
       }
       let _id = db.Ticket.insert({ title: title, priority: priority, resolved: false })?
       return Ok("Created ticket: " + title)
   }
   ```

3. **Expose an AI Agent Tool (`tool`) and Reactive UI (`component`)**

   The `tool` keyword generates an MCP tool schema with HMAC receipt verification, while `component` emits a reactive `.tsx` view:

   ```vox
   table Ticket {
       title: str
       priority: int
       resolved: bool
   }

   tool "Resolve a support ticket by ID" resolve_ticket(id: Id[Ticket]) to Result[str] {
       db.Ticket.delete(id)?
       return Ok("resolved")
   }

   component TicketHeader() {
       view: column(raw_class="ticket-header") {
           heading(level=2) { "Support Queue" }
           text() { "Typed across SQL, Axum, React, and MCP" }
       }
   }
   ```

</Steps>

    title: str
    priority: int
    resolved: bool
}

query open_ticket_count() to int {
    return len(db.Ticket.all())
}

    db.Ticket.delete(id)?
    return Ok("resolved")
}

fn main() to Result[str] {
    let id = db.Ticket.insert({ title: "Upgrade KB to Starlight MDX", priority: 1, resolved: false })?
    print("Open tickets: " + str(open_ticket_count()))
    let status = resolve_ticket(id)?
    print("After resolve: " + str(open_ticket_count()))
    return Ok(status)
}`} />
