## 2. Multi-Model Parallel Execution & Dispatch Strategy (`Flash / Argon` vs `5.5 Sonnet / Pro`)

Per [`docs/src/architecture/gemini-3-5-flash-antigravity-limitations-2026-06-18.md`](../docs/src/architecture/gemini-3-5-flash-antigravity-limitations-2026-06-18.md) and [`docs/src/contributors/antigravity-handoff-and-skill-gaps-2026-06-18.md`](../docs/src/contributors/antigravity-handoff-and-skill-gaps-2026-06-18.md):
- **`Flash / Argon` (`Model: "flash"` or fast headless `agy -p` / Cursor Argon worker):** High throughput, low latency, lowest token cost. Best suited for **bounded, mechanical, verify-before-use tasks with disjoint file sets** (`git mv` test relocations, `Cargo.toml` dependency pruning, `include_str!` local file vendoring, URL/workflow YAML fixes, mechanical subcrate module moves after a trait seam exists). Must have explicit `file:line` targets and a two-strike circuit breaker.
- **`5.5 Sonnet / Pro` (`Model: "pro"` / Claude Code lead / `inherit`):** Deep multi-hop reasoning, Rust trait/lifetime coherence, cross-crate invariant preservation, and CI parser synchronization. Best suited for **architectural seams and shared-file bottlenecks** (`vox-mcp-context` `ServerState` trait/base extraction, `vox-orchestrator-models` Part B4 `TaskCategory` & `auto_select.rs` decoupling, `vox-code-audit` internal dependency decoupling, `pre_push.rs` + `ssot_drift.rs` + `lefthook.yml` lockstep refactoring, and `vox-orchestrator::models` OpenRouter vs local routing fix).
- **Golden Parallelism Rule:** Never dispatch two parallel agents that write to the same file (`Cargo.toml`, `docs/src/architecture/layers.toml`, `contracts/ci/crate-edges.allow.v1.json`, `crates/vox-cli/src/commands/mod.rs`). Run disjoint crate edits in `[PARALLEL-SAFE]` waves, then run one `[SEQUENTIAL]` integration pass on root manifests and contracts.
