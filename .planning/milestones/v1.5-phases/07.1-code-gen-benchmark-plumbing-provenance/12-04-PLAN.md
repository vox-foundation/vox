<objective>
Create the typed run record every later plan writes and reads: a §5 provenance record with a single completeness gate, and an eval-corpus report that carries honest statistics (BENCH-03 report side, BENCH-04; D-04, D-05).

Purpose: the current report is an untyped `serde_json::json!` literal, which is how provenance fields get silently dropped, and `run_complete` is false only on the spend cap. All statistics primitives exist in `vox-eval::corpus_stats` with zero callers. This plan is pure (no I/O, no new crate edges: vox-eval has no vox-crypto edge, so hashing stays in vox-cli in 12-07) and has no dependency on any other plan, so it runs in Wave 1.
Output: `crates/vox-eval/src/provenance.rs` and `crates/vox-eval/src/report.rs` with test modules, registered in `lib.rs`.
</objective>
