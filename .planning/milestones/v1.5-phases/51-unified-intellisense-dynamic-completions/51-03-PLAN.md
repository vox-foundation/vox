# Plan 51-03: Terminal `InputEditor.tsx`/`DiscoveryRail.tsx` & Chat `Loquela.tsx` Unified Ghost Text + Keyboard-Navigable Popover Wiring

<objective>
Wire `intellisenseEngine.ts` and `IntelliSensePopover.tsx` into both the Axis Console Terminal (`InputEditor.tsx` + `DiscoveryRail.tsx`) and the Chat Composer (`Loquela.tsx`):
1. **Terminal (`InputEditor.tsx` & `DiscoveryRail.tsx`)**:
   - Remove the `if (!value.startsWith('vox'))` silo so `InputEditor.tsx` provides dynamic ghost text (`data-testid="ghost"`) AND the categorized `IntelliSensePopover` for `vox <cmd> [--flag]`, `/slash` commands & skills, `!nu` / shell pipelines, `?prompt` agent queries, `@term` / `@file` mentions, and command history.
   - Add full keyboard navigation (`↑`/`↓` to cycle candidates and update ghost text + `DiscoveryRail.tsx`, `Tab`/`→` to accept ghost/selected item, `Ctrl+Space` to open dynamic suggestions on empty or partial input, `Esc` to dismiss popover before triggering control-mode takeover).
2. **Chat (`Loquela.tsx`)**:
   - Replace the separate prefix-only `slashOpen` and keyboard-inaccessible `showAtPopover` menus with the unified `IntelliSensePopover` + inline ghost-text hint, fixing `@` mention keyboard navigation (`↑`/`↓`/`Tab`/`Enter`/`Esc`) and adding `@term:<session>#<block>`, `@skill:<name>`, `@mcp:<tool>`, and `@symbol:<name>` completions alongside `@file` and `@agent`.
</objective>
