# Plan 51-02: Unified Frontend `intellisenseEngine.ts` + Categorized `IntelliSensePopover.tsx` (7-Source Convergence & Legacy VSCode Modernization)

<objective>
Build the shared frontend IntelliSense engine (`crates/vox-gui/ui/src/lib/intellisenseEngine.ts`) and categorized glass popover (`crates/vox-gui/ui/src/components/ui/IntelliSensePopover.tsx`) that converge all 7 completion sources — CLI `CommandCatalog` (`discoverySuggest`), `BUILTIN_SLASH` + Terminal `CommandRegistry`, `SKILL.md` skills, `capabilityIndex.generated.ts` (canonical MCP tools, replacing the deprecated `vox-vscode` `mcpToolRegistry`), Nushell structured pipeline stages (`!nu`), live terminal blocks (`@term:<session>#<block>`), workspace files (`@file:<path>`), and `.vox` LSP symbols/decorators (`@symbol:<name>`) — with context-aware dynamic boosting.
</objective>

## Tasks

### Task 1: Implement `crates/vox-gui/ui/src/lib/intellisenseEngine.ts` `[MODEL: FLASH-3.8]` `[SEQUENTIAL]`

<files>
- crates/vox-gui/ui/src/lib/intellisenseEngine.ts
- crates/vox-gui/ui/src/lib/__tests__/intellisenseEngine.test.ts
</files>

<action>
1. Create `crates/vox-gui/ui/src/lib/intellisenseEngine.ts` exporting:
   - `CompletionCategory`: `'all' | 'command' | 'slash' | 'skill' | 'term' | 'file' | 'mcp' | 'nu' | 'symbol' | 'history'`
   - `IntelliSenseItem`: `{ id: string; label: string; insertText: string; ghostSuffix: string; category: CompletionCategory; badge: string; description: string; signature?: string; actionId?: string; score: number; meta?: string; chip?: { kind: string; label: string; meta?: string } }`
   - `parseCompletionTrigger(input: string, cursorOffset?: number, surface?: 'terminal' | 'chat')`:
     - Detects active trigger token (`vox ...`, `/...`, `!nu ...` / `!...`, `?...`, `@term:...`, `@file:...`, `@skill:...`, `@mcp:...`, `@symbol:...`, bare `@...`, or pipe stage `| ...`).
   - `computeIntelliSenseItems(ctx: IntelliSenseContext): IntelliSenseItem[]`:
     - Merges candidates from:
       1. `discoverySuggest` (`vox` CLI commands & `--flags`),
       2. `buildSlashEntries(skills)` + Terminal `CommandRegistry` (`/help`, `/model`, `/model route`, `/budget`, `/skills`, `/memory`, `/context`, `/sh`, `/ai`, `/nu`, `/security`, `/control`),
       3. Canonical MCP tools & capabilities from `CAPABILITY_INDEX` (`crates/vox-gui/ui/src/generated/capabilityIndex.generated.ts`, superseding `vox-vscode`'s `mcpToolRegistry.generated.ts`),
       4. Nushell structured pipeline stages (`ls`, `ps`, `open`, `where`, `select`, `get`, `to json`, `from json`, `sort-by`, `each`, `flatten`),
       5. Live terminal blocks from `terminalBridge` (`@term:<session>#<block>` with exit code badge and automatic boost when `exitStatus !== 0`),
       6. Repo files (`list_repo_files`) and active agents,
       7. `.vox` language surface decorators/keywords/types (`@component`, `@actor`, `@workflow`, `@activity`, `@table`, `@mcp.tool`, `@gpu`, `fn`, `match`).
     - Applies dynamic context boost:
       - If the latest terminal block failed (`exitStatus !== 0`), boosts `@term` failed block chip, `?fix error in last block`, and `/audit`.
       - If the active shell backend is Nushell (`nu`) or input contains `|`, boosts Nushell pipeline stages (`| where`, `| select`, `| to json`).
2. Create `crates/vox-gui/ui/src/lib/__tests__/intellisenseEngine.test.ts` testing trigger detection, fuzzy scoring, 7-source merging, failed-block context boosting, and ghost suffix computation.
</action>
