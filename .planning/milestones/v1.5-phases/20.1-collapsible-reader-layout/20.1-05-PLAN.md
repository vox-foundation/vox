    Write the rules below unlayered. Let PAD = `var(--sl-content-pad-x)`, RAIL = `var(--vox-rail-width)`, SIDE = `var(--sl-sidebar-width)`, MAX = `var(--vox-content-max)`, GUT = `max(var(--sl-content-pad-x), calc(var(--vox-control-size) + 0.5rem))`.
    1. Desktop (`@media (min-width: 72rem)`), each selector beginning `html[data-has-sidebar]` so it beats Page.astro's inline `[data-has-sidebar]` rule:
       - collapsed + TOC shown (`[data-vox-left='collapsed']:not([data-vox-toc='hidden'])`, or a page without a TOC): `--sl-content-inline-start: RAIL; --sl-content-width: min(MAX, calc(100vw - RAIL - SIDE - 2 * PAD))`.
       - pinned + TOC hidden (`[data-has-toc][data-vox-left='pinned'][data-vox-toc='hidden']`): `--sl-content-width: min(MAX, calc(100vw - SIDE - PAD - GUT)); --sl-content-margin-inline: auto` (centred in the space right of the sidebar).
       - collapsed + TOC hidden: `--sl-content-inline-start: RAIL; --sl-content-width: min(MAX, calc(100vw - RAIL - PAD - GUT)); --sl-content-margin-inline: auto`.
       - a page without a TOC keeps Starlight's own `html:not([data-has-toc])` width and only gains the rail shift when collapsed.
    2. Tablet (`@media (min-width: 50rem) and (max-width: 71.99rem)`): collapsed sets only `--sl-content-inline-start: RAIL` and `--sl-content-width: min(MAX, calc(100vw - RAIL - 2 * PAD))`.
    3. Prose cap at ≥50rem under `html[data-vox-left]`: `.sl-markdown-content > :is(p, ul, ol, dl, blockquote, h2, h3, h4, h5, h6, .sl-heading-wrapper, .starlight-aside) { max-inline-size: var(--vox-prose-max) }`, start-aligned (no auto margins), so wide blocks (`table`, `pre`/`.expressive-code`, `img`, `figure`) keep the full column.
    4. Motion, only under `html[data-vox-layout-ready]` inside `@media (prefers-reduced-motion: no-preference)`: `.main-frame` transitions `padding-inline-start 200ms ease-out`; `.sl-container` transitions `inline-size 200ms ease-out`; `.right-sidebar-container` `inline-size 200ms ease-out`; the flyout's 150ms/100ms from 20.1-02 stays. Everywhere else (pre-ready, reduced motion) these elements and `#starlight__sidebar`, `.vox-rail` have `transition: none`. Never put a transition on a custom property.
    5. Do not set Starlight's private `--__toc-width`; the header test in Task 2 confirms the header copes.
  </action>
