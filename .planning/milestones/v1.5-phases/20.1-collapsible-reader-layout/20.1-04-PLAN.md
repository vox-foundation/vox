<task>
  <name>Task 2: Playwright Visual-Stepper Spec in docs-astro/tests/reader-layout.spec.ts</name>
  <action>
    Create `docs-astro/tests/reader-layout.spec.ts`:
    1. Define viewport sizes:
       - `desktop`: 1280x800
       - `tablet`: 800x1024
       - `phone`: 375x667
    2. Define themes: `['dark', 'light']`.
    3. Define pages: `['/', '/tutorials/tut-getting-started/']`.
    4. Test steps per permutation:
       - Check `body` has no horizontal scroll (`scrollWidth <= clientWidth`).
       - On desktop:
         - Verify initial pinned state.
         - Click `#vox-sidebar-pin-toggle`, verify `data-sidebar-state="collapsed"` and rail width.
         - Hover over `.sidebar-pane`, verify expanded overlay.
         - Click `#vox-toc-hide-btn`, verify `data-toc-state="hidden"` and article expansion.
         - Click `#vox-toc-restore-btn`, verify `data-toc-state="visible"`.
         - Reload page, verify state persisted from `localStorage`.
       - On phone/tablet:
         - Verify touch drawer remains operable without broken hover overlays.
       - Save screenshots for each state into `docs-astro/test-results/review-bundle/${page}-${viewport}-${theme}-${step}.png`.
  </action>
  <verify>
    Run `pnpm --dir docs-astro build && cd docs-astro && npx playwright test tests/reader-layout.spec.ts`.
  </verify>
