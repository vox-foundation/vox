## Decisions applied

- **D-03 (reversible):** "new or changed" means allowlist membership only; no git or content-hash input.
- **D-04 (costly):** backlog file shape `schema_version`, `epoch`, `epoch_note`, `docs: [{path, rules}]`, rows sorted by path, rule ids sorted; read here, written only by the 04-07 command.
- **D-06:** the lint rejects a contradictory doc (explicit `training_eligible: true` while forced ineligible) using the shared function.
- **D-07:** topic/domain must be a prefLabel; an altLabel or a deprecated alias in frontmatter is an error naming the prefLabel to use.
- **Discretion, required facets on a new doc:** `topic`, `domain`, `authorship` (+ `authorship_model` for LLM authorship) and the summary block. Everything else is optional and only format-checked when present (`review_by`, `verified_at` dates; `sources[]` on any page). Promoted pages (`origin: web-promoted`) additionally need sources with url/date/hash and are held to the quote cap.
- **Discretion, scope:** `.md` only (matches the KB corpus rule), excluding `docs/src/archive/**` (Archival Protocol) and `*.generated.md` (machine output).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| doc author (human or LLM agent) -> facet lint | the lint is the gate that keeps unfaceted, mislabeled or contradictory docs out |
| backlog / taxonomy contract files -> lint | the excuse list and the vocabulary decide what passes |
