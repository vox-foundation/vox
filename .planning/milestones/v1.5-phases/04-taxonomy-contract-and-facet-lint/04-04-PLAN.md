## Decisions applied

- **D-05 (reversible):** a doc with no `authorship` keeps the flag default `true`.
- **D-06 (costly):** one shared eligibility function; the substring path is removed; the fixture proves forced-false exclusion and no summary text in output.
- **Discretion, malformed facets:** a doc whose frontmatter fails `parse_facets` is excluded (fail closed). Otherwise a typo such as `origin: web-promotd` would silently make a web page eligible. The real-tree oracle proves no current doc is affected.
