## Decisions applied

- **D-04 (costly):** generated by a seeding command, never hand-edited; `--tighten` only removes; adding needs the user's authorization. Mechanically: an addition is accepted only with `epoch` + 1 and a new `epoch_note`, which only the seeding command writes, and AGENTS.md (04-08) makes re-seeding user-authorized-only, like crate-edges exceptions.
- **D-03:** the gate compares backlog contents only (no doc content or git history of docs).
- **Discretion, command home:** flags on the existing `vox-doc-pipeline` binary (no new `vox ci` subcommand, no registry churn), per 04-PATTERNS.md.
