<action>
Implement `extract_mentions(source_file: &Path, content: &str) -> Vec<ExtractedMention>` in `crates/vox-doc-pipeline/src/claims/extractor.rs`:
- Use `pulldown-cmark::Parser` with `OffsetIter` to walk the document AST.
- Classify context:
  - Prose inline code: backticked text (e.g. \`crates/vox-cli\`, \`VOX_DB_URL\`, \`vox audit docs\`).
  - Code blocks: examine info string (`vox`, `rust`, `bash`, `sh`, `toml`, `text`, etc.).
  - If code block contains `// vox:skip` or is tagged `text`, set `MentionRole::Mentions`.
  - In normal code blocks or prose specifying usage/config, set `MentionRole::Prescribes`.
- Extract candidates using regex tokenizers:
  - File paths: matching repo structure (`crates/`, `docs/`, `contracts/`, `.planning/`, `scripts/`, or relative `.rs`/`.md`/`.toml`/`.yaml`/`.json` paths).
  - Crate names: `vox-*` crate identifiers.
  - Rust symbols: path-qualified `a::b::c` or `Type::method`.
  - CLI commands: `vox <subcommand> [flags]`.
  - Env vars: `[A-Z0-9_]{3,}` matching `VOX_*` or known prefixes.
  - Config keys: dotted config identifiers matching config schemas.
- Record 1-indexed line numbers and byte offsets.
- Add unit tests for fence detection, `// vox:skip` role downgrading, and multi-line markdown extraction.
</action>

- Load ground truth from repo:
  - Workspace members from root `Cargo.toml`.
  - File existence from repo root filesystem.
  - CLI commands from `contracts/cli/command-registry.yaml`.
  - Environment variables from `contracts/config/env-vars.v1.yaml`.
  - Config keys from `contracts/config/registry.v1.yaml`.
  - Retired symbols from `contracts/documentation/retired-symbols.v1.yaml`.
- Implement `resolve_mention(&self, mention: &ExtractedMention) -> ResolvedMention`:
  - Check `retired-symbols.v1.yaml` first: if pattern matches, return `ResolutionStatus::Retired` with replacement and rationale.
  - If `FilePath`: check if `repo_root.join(normalized_path).exists()`. If exists -> `Resolved`, else -> `Missing`.
  - If `CrateName`: check workspace crates. If in workspace -> `Resolved`, else -> `Missing`.
  - If `CliCommand`: check command registry. If command exists -> `Resolved`, else -> `Missing`.
  - If `EnvVar`: check env vars registry. If found -> `Resolved`, else -> `Missing`.
  - If `ConfigKey`: check config registry. If found -> `Resolved`, else -> `Missing`.
  - If `RustSymbol`: verify against known workspace symbol patterns or crate modules; if ambiguous -> `Ambiguous`, if verified -> `Resolved`, if unknown -> `Missing`.
- Wire `scan_file` and `scan_corpus` in `crates/vox-doc-pipeline/src/claims/mod.rs`.
- Add integration tests covering resolved, missing, and retired symbols across sample docs.
</action>
