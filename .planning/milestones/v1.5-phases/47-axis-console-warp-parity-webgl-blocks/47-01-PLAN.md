<objective>
Cut over `crates/vox-gui`'s terminal backend (`commands/pty.rs`) to `vox_terminal_core::SessionHost` (`DaemonHost` over `PersistentDaemon` when reachable, falling back to an in-process `LocalHost`), retire the unused `crates/vox-gui/src/commands/terminal_core.rs` (`TerminalSessionManager`), and expose typed `termSession*` wrappers in `crates/vox-gui/ui/src/transport.ts`.

Purpose: Satisfy `TERM-05` (Design Doc Task H6 backend cutover) so the Axis Console and `vox term` share one live daemon-hosted PTY and block state machine without duplicate in-process GUI session state.
Output: Updated `crates/vox-gui/src/commands/pty.rs`, retired `terminal_core.rs`, and typed `transport.ts` wrappers with passing Rust + Vitest tests.
</objective>
