# Plan 53-02: DB-Backed `ScaffoldInput` & `FindingPageInput` Assembler (Zero Manual JSON Files)

<objective>
Close Gap 3 from [`scientia-publication-and-deep-research-claims-vs-reality-audit-2026.md`](../../../../docs/src/architecture/scientia-publication-and-deep-research-claims-vs-reality-audit-2026.md):
1. **DB-Backed `assemble_scaffold_from_db` & `assemble_finding_page_from_db`**: Build a deterministic assembler that hydrates `vox_scientia_manuscript::scaffold::ScaffoldInput` and `vox_scientia_HTML::finding_page::FindingPageInput` directly from `VoxDb` (`publication_manifests` + `scientia_claims` + `novelty_evidence_bundles` + `ro_crate` metadata) given only a `publication_id` and optional `VenueStyle`.
2. **CLI & Daemon HTTP Endpoints Without Offline JSON Files**:
   - Update `vox scientia publication-manuscript-draft`, `publication-render-latex`, `publication-arxiv-bundle`, and `publication-finding-page-render` so `--publication-id <id>` is the primary input (keeping `--scaffold <path>` / `--page <path>` as optional overrides).
   - Expose `POST /api/v2/scientia/publications/:id/manuscript`, `POST /api/v2/scientia/publications/:id/latex`, `POST /api/v2/scientia/publications/:id/arxiv-bundle`, and `POST /api/v2/scientia/publications/:id/finding-page` in `crates/vox-orchestrator-mcp/src/gui_ops/scientia.rs` and `crates/vox-gui/src/commands/scientia.rs`.
</objective>

## Tasks

### Task 1: Implement `assemble_scaffold_from_db` & `assemble_finding_page_from_db` and Make `--scaffold` / `--page` Optional in CLI `[MODEL: ARGON-4]` `[SEQUENTIAL]`

<files>
- crates/vox-cli/src/commands/scientia_phase_handlers.rs
- crates/vox-cli/src/commands/scientia_cli.rs
</files>

<action>
1. In `crates/vox-cli/src/commands/scientia_phase_handlers.rs`:
   - Add `pub async fn assemble_scaffold_from_db(db: &vox_db::VoxDb, publication_id: &str, venue_override: Option<VenueStyle>) -> anyhow::Result<ScaffoldInput>`:
     - Load the `publication_manifests` row via `db.get_publication_manifest(publication_id).await?`.
     - Load all `scientia_claims` for `publication_id` via `db.list_scientia_claims(Some(publication_id)).await?`.
     - Load the latest `novelty_evidence_bundle` if linked in `metadata_json`.
     - Construct `ScaffoldInput` (`title`, `authors`, `abstract_text`, `claims`, `methods_markdown`, `results_markdown`, `discussion_markdown`, `bibliography_bibtex`, `venue`) from the DB records.
   - Add `pub async fn assemble_finding_page_from_db(db: &vox_db::VoxDb, publication_id: &str) -> anyhow::Result<FindingPageInput>`.
   - Update `publication_manuscript_draft`, `publication_render_latex`, `publication_arxiv_bundle`, and `publication_finding_page_render` so when `scaffold_json_path` / `page_json_path` is `None`, they call `assemble_scaffold_from_db` / `assemble_finding_page_from_db` using `publication_id`.
2. In `crates/vox-cli/src/commands/scientia_cli.rs`:
   - Make `--scaffold` optional when `--publication-id` is passed on `publication-manuscript-draft`, `publication-render-latex`, and `publication-arxiv-bundle`, and make `--page` optional when `--publication-id` is passed on `publication-finding-page-render`.
</action>
