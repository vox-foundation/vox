<files>

<action>
1. In `crates/vox-research-shim/src/research/verifier.rs`:
   - Add `pub fn lexical_containment_score(claim_text: &str, evidence_text: &str) -> (f64, bool)`:
     - Extract normalized alphanumeric content tokens (length >= 3, excluding common English stop words) and bigrams from `claim_text` and `evidence_text`.
     - Check for explicit negation conflict (`not`, `never`, `no`, `false`, `deprecated`, `removed`, `unsupported`, `fails`) or numeric mismatch (if `claim_text` contains numbers that are absent from `evidence_text`).
     - Return `(containment_score, has_conflict)` where `containment_score = 0.7 * token_recall + 0.3 * bigram_recall`.
   - Add `pub fn try_fast_lexical_verify(claim: &Claim, hits: &[ResearchHit]) -> Option<ClaimVerdict>`:
     - Scan `hits` (checking both `hit.snippet` and the first 1,200 chars of `hit.raw_content`).
     - Collect hits with `score >= 0.82 && !has_conflict`. If at least one supporting hit exists and no hit has a high-overlap negation conflict (`score >= 0.70 && has_conflict`), return `Some(ClaimVerdict { verdict: Verdict::Supported, confidence: max_score.clamp(0.82, 0.96), supporting_count, contradicting_count: 0, evidence_spans, resample_stability: 1.0 })`.
   - Add `pub fn evidence_context_for_claim(claim: &Claim, hits: &[ResearchHit], limit: usize) -> String`:
     - Score every `(idx, hit)` in `hits` by `lexical_containment_score(&claim.text, &hit.snippet).0 + 0.1 * hit.score`, select the top `limit` hits, and format each using its **original `[idx]`** in `hits` (`"[{idx}] {}\nURL: {}\n{}"`) so `supporting_indices` / `contradicting_indices` returned by the LLM still index directly into `evidence_hits`!
   - Wire `try_fast_lexical_verify` before `select_claims_for_verification` in `verify_claims_with_config` (so fast-verified claims do not consume the `MAX_CLAIMS_VERIFIED_PER_RUN` LLM cap!) and use `evidence_context_for_claim(&claim, evidence_hits, 8)` inside `sample_claim`.
2. Add unit tests in `crates/vox-research-shim/src/research/verifier.rs` proving:
   - `try_fast_lexical_verify` short-circuits verbatim/high-containment claims as `Verdict::Supported` with accurate `source_id` spans,
   - negation or numeric mismatches do NOT short-circuit as `Supported`,
   - `evidence_context_for_claim` selects relevant hits beyond index 8 while preserving their original `[idx]` markers.
</action>
