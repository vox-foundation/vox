**Analog:** `crates/vox-cli/src/commands/ci/gui_surface_registry.rs` (pure check fns taking data, returning `Vec<String>` violations; `run` turns them into one `anyhow!`).

Gate errors keep the `gui-surface-registry:` prefix; call the gate from `run` after `missing_groups` check and before the TS drift compare.


**Tests:** in-file `#[cfg(test)] mod tests` with `repo_root()` via `CARGO_MANIFEST_DIR/../..` (gui_surface_registry.rs:315-320). The Cargo-`default`-list pin test and the `build_catalog()` parity test copy this `repo_root()` idiom (tdd-guard needs tests in the same file as new `pub(crate) fn`).

**Source:** `capability_index/ratchet.rs:118-143`, `mod.rs:50-64,126-150`. **Apply to:** exemption set, dedicated floor, orphan. `--write` never writes a baseline; missing baseline is an error; `tighten(None)` bootstraps. Baselines are user-authorized-only to raise (AGENTS.md).

**Source:** `gui_surface_registry.rs:181-197`. **Apply to:** `coverage-exemptions.v1.yaml` loader.

**Source:** `write_or_verify_text` (`capability_index/mod.rs:84-90`, imported at :23 from `operations_catalog`). **Apply to:** any new generated file/baseline write; do not hand-roll compare.

**Source:** `emit.rs:207-213` `ts_str`/`ts_opt`. **Apply to:** every string emitted into generated TS, esp. exemption `reason` (gui_surface_registry's `opt()` is unsafe for free text). Do not emit exemption text into llms/docs JSON (`safe_line`, emit.rs:50).

### Test-first, same-file tests
**Source:** AGENTS.md Test-First; `gui_surface_registry.rs:253+`, `ratchet.rs:145+`. Every new `pub(crate) fn` gets a `#[test]` in the same file. Mutation proofs M1-M10 (RESEARCH) with before/after sha presence checks.
