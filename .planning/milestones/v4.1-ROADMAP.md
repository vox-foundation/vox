**Goal**: Replace ad-hoc UUID/counter ID generation and uncompressed snapshot JSON with `VoxIdAllocatorV2` (`{ allocate, derive }`), `ForwardCompatibleEnvelope<T>`, `WireIdTableInterner`, `LiveBodyDeduper`, and `omit_idle_subagents` cold-connect filtering.
**Depends on**: Phase 215
**Requirements**: `T3-WIRE-ID-01`, `T3-WIRE-ID-02`, `T3-WIRE-ID-03`, `T3-WIRE-ID-04`
**Success Criteria**:
  1. `VoxIdAllocatorV2` (`allocate` + `derive`) replaces ad-hoc ID generation in `vox-orchestrator` and produces identical entity IDs across event stream replays.
  2. `ForwardCompatibleEnvelope<T>` preserves unknown future union variants as `{ tag: "unknown", raw }` across GUI/MCP wire boundaries.
