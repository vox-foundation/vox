# Plan 406-01: Docs Contextualization, Whole-Module .vox Synthesis, Compiler-Verified DPO & Multi-Spoke Mix Coverage

## Objective

Eliminate silent data drops and prompt ambiguity in documentation and AST corpus extraction, strengthen compiler-verified DPO preference pair generation, and bring all remaining spoke mixes into explicit `include_lanes` and `spoke_validate` coverage.

## Tasks

1. **Contextualize Doc Prompts & Fix `response_mode` (`crates/vox-corpus/src/corpus/extract_docs.rs`)**
   - Include `frontmatter.title` and heading breadcrumb context in `extract_qa_sections` and `extract_code_blocks` prompts (preserving explicit non-empty headings cleanly and updating/adding unit tests).
   - Detect injected ` ```vox ` code fences in relational QA responses so `response_mode` is `"mixed"` rather than `"prose_only"` when executable code blocks are present.
   - Align `docs_qa` / `docs_code` lane & rating handling (`rating >= 4` for verified/rich code & canonical architectural Q&A where appropriate, or domain filter alignment in `domain-profiles.yaml`).

2. **Whole-Module Synthesis & Compiler-Verified DPO (`crates/vox-corpus/src/corpus/extract_vox/part_walk.rs`, `crates/vox-corpus/src/corpus/dpo.rs`)**
   - Extend `extract_from_vox_file` / `part_walk.rs` so non-trivial multi-construct `.vox` files emit whole-module cohesive synthesis pairs alongside individual AST slices.
   - Tighten `dpo.rs` `generate_dpo_from_extract` so `chosen` is validated with `vox_compiler::pipeline::run_frontend_str` before generating compiler-verified AST mutations, avoiding unparseable `chosen` samples in syntax preference pairs.

3. **All-Spoke `include_lanes` & Domain Profile Alignment (`mens/config/*.yaml`, `crates/vox-populi/src/mens/tensor/spoke_validate.rs`)**
   - Add explicit `include_lanes:` lists to `mix-research-expert.yaml`, `mix-research.yaml`, `mix-populi-meta.yaml`, `mix-rocks.yaml`, and `mix-agents.yaml`.
   - Ensure `mens/config/domain-profiles.yaml` does not silently drop documentation replay (`documentation` category / `min_rating` alignment) while keeping `vox-lang` mix consistent.
   - Add `spoke_validate` validation/unit tests covering spoke mix `include_lanes` completeness with workspace-relative paths.
