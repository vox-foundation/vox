# Plan 406-02: Token-Normalized Grad Accum, Document-Masked Packed QLoRA, rsLoRA / lm_head Guard & Portable Relative Preflight

## Objective

Upgrade the Candle Metal QLoRA training loop and CLI/config surface with token-normalized gradient accumulation, document-masked sequence packing (`block_diagonal_causal_mask` + per-document RoPE position reset), `rsLoRA` scaling, explicit `--lora-exclude-lm-head` protection, and strictly workspace-relative corpus preflight paths — verified on `Device::Cpu` without disturbing any live Metal GPU run.

## Tasks

1. **Portable Relative `train_path` Preflight (`crates/vox-ml-cli/src/commands/schola/train/run_train.rs`)**
   - Allow `check_corpus_threshold` to resolve either an explicit `train_file` (relative path like `target/dogfood_mix/train.jsonl`) or `<data_dir>/train.jsonl`, with unit tests covering relative paths.

2. **Config & CLI Flag Plumbing (`training_config.rs`, `config.rs`, `vox-ml-cli`)**
   - Add `lora_exclude_lm_head`, `use_rslora`, `token_normalized_grad_accum`, and `sequence_packing` fields (`#[serde(default)]`) to `LoraTrainingConfig` in both `vox-populi` and `vox-plugin-mens-candle-core`.
   - Expose matching CLI flags in `action_populi_enum.rs`, `dispatch.rs`, `train_arm.rs`, and `gpu.rs`.

3. **rsLoRA, lm_head Exclusion, Token-Normalized Grad Accum & Packed Forward (`crates/vox-plugin-mens-candle-metal/...`)**
   - Compute `effective_lora_alpha` supporting `use_rslora` (`alpha * sqrt(rank)` so `qlora-rs` `alpha/rank` yields `alpha/sqrt(rank)`) and wire `lora_exclude_lm_head` consistently in `candle_qlora_train/{mod.rs, finalize.rs}`.
   - Implement `token_norm_window_scale` & token-normalized loss accumulation across `grad_accum` micro-steps in `training_loop/{forward.rs, mod.rs, logic.rs}`.
   - Implement `block_diagonal_causal_mask`, local per-segment RoPE position IDs, and `forward_packed` in `model.rs` (tested on `Device::Cpu`).

## Verification

- `rustfmt --edition 2024` on each modified `.rs` file
- `timeout 300s cargo test -p vox-ml-cli --lib corpus_threshold`
- `timeout 300s cargo test -p vox-plugin-mens-candle-metal --lib packed_forward`
- `timeout 300s cargo test -p vox-plugin-mens-candle-metal --lib token_norm_window_scale`
- `timeout 300s cargo test -p vox-plugin-mens-candle-metal --lib effective_lora_alpha`
