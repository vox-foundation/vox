## Isolated staging (applies to every commit in this plan)

- **Clean path** (no uncommitted change before your edit): `git add -- <path>` (a deleted path is
  staged the same way).
- **Shared dirty path** (`Cargo.lock`, `contracts/ci/crate-build-map.v1.json`,
  `docs/src/architecture/where-things-live.md`, and `.planning/*.md` if dirty at commit time):
  build the index blob from HEAD so no one else's hunk can ride along.
  1. `git show HEAD:<path> > target/phase03-01-<name>.staged`
  2. Apply exactly this plan's edit to that copy (Edit tool or a block-scoped `awk`).
  3. `git update-index --cacheinfo 100644,$(git hash-object -w target/phase03-01-<name>.staged),<path>`
  4. Apply the same edit to the working-tree file too (so the next session's commit keeps it),
     unless the working-tree line no longer reads the pre-edit value; then leave it and say so in
     the SUMMARY.
  5. Prove isolation: `git diff --cached --numstat -- <path>` equals the expected counts.
- Before every commit: the index was empty at the start (`git diff --cached --quiet`), no merge is
  in progress, and the sorted staged path list equals the task's list exactly (checked
  mechanically). Commit with `git commit -F <msgfile>` and NO pathspec (a pathspec commit would take
  the whole working-tree file). Never `git add -A`, `--no-verify`, stash, checkout, restore or reset.
</staging_protocol>
