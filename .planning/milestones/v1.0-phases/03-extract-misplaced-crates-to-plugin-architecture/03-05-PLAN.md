<objective>
Repoint every in-process Candle Whisper consumer to vox-plugin-speech through the plugin host
(D-08, D-12), without deleting anything yet — 03-06 deletes `stt-candle` once nothing reaches it.

Purpose: REQ-dead-crate-misplaced (oratio half of SC#4). Design choice (Claude's discretion within
D-08/D-12): instead of editing each caller (mic.rs, serve.rs, session, subtitle), vox-speech's own
backend dispatch gets one seam — a host-registered Whisper transcriber with the plugin's exact
`transcribe` signature (PCM bytes + config JSON -> JSON). vox-speech cannot depend on vox-plugin-host
(that would be a new crate edge), so the two hosts that already depend on it (vox-gui, vox-ml-cli)
register a ~15-line function that calls the plugin. One seam covers every caller, keeps Sherpa
in-process, and leaves mic.rs's careful config/error handling untouched.

Output: three commits (vox-speech seam; vox-gui registration with its derived contracts; vox-ml-cli
registration) plus a mutation proof.
</objective>
