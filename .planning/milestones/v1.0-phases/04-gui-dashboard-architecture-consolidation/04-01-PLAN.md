## Visible correction to CONTEXT.md D-01 (not applied silently)

CONTEXT.md D-01 literally instructs: update ADR-045's frontmatter `status: "current"` to the
value `accepted`. **This plan does not do that, deliberately.**

`vox-doc-pipeline` enforces a closed enum for the frontmatter `status:` key
(`crates/vox-doc-pipeline/src/pipeline/lint.rs:37-44`): `current`, `experimental`, `legacy`,
`research`, `roadmap`, `deprecated`. Any other value trips `LintKind::UnknownStatus`. The
literal D-01 instruction is a hard lint failure, not a style preference. Across all 24 ADRs
with a frontmatter `status:` key, zero use the value D-01 names — including the locked ADRs
037, 041, and 047, which all keep `current`.

The underlying intent of D-01 — "an explicit, unambiguous Accepted marker on ADR-045" — is
satisfied instead by the repo's own established mechanism: a body `**Status**: Accepted
(date)` line directly under the H1, mirroring ADR-037's line 11. That is what Task 1 does.
D-01's reversibility rating (costly) is carried onto Task 1 unchanged.
