<objective>
Expose the ledger's claim check as an agent-callable tool, route the ledger's crypto through
vox-crypto, and surface the verdict in chat (D-03, D-04, D-10, D-11).

Purpose: TRUST-01's "independently check for authenticity" half (ROADMAP SC#2): 05-01 made every
call carry a receipt; this plan lets anyone check a set of claimed receipt ids and shows a
fabricated/unverified claim in the chat. D-04 closes the AGENTS.md §Cryptography Policy #1 debt in
the same file.

Output: three feature commits (tool, crypto routing, chat verdict chip) plus a test-first pin commit.
</objective>
