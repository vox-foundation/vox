<objective>
Wire tool-call receipts into the live MCP dispatch path and show them in the chat transcript — the
TRUST-01 vertical slice (D-01, D-02, D-10, D-11, D-12).

Purpose: `ToolReceiptLedger` and the `Orchestrator::{issue,fulfill,verify}_tool_receipt` wrappers
exist but have zero production callers (05-RESEARCH Summary). This plan makes every dispatched tool
call carry a receipt and lets the user see, per tool call in a chat turn, whether it carries a
verified receipt.

Output: one feature commit (dispatch wrap + chat event + chip), one test commit (Playwright spec),
and recorded mutation proofs.
</objective>
