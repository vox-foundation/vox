<objective>
Give the hopper intake spec an optional `resource_id` that survives storage and reaches the
dispatched task (D-08, D-13) — the MESH-01 intake slice.

Purpose: 05-05's dispatcher acquires an exclusive lock on the task's `resource_id`. In production
the orchestrator's hopper is swapped to `SqliteHopper` (core/init.rs:53), so the field must be
persisted or it silently disappears between submission and dispatch. The same plan exposes it at
the HTTP intake boundary with validation.

Output: three feature commits (in-process path; schema 94; SQLite wiring + HTTP boundary).
</objective>
