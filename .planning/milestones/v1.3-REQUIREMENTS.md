# Requirements: Vox (`docs-freshness` v1.3)

**Defined:** 2026-10-08
**Core Value:** The public documentation site (`voxlang.org`) must stay building, deployable, truthful to the codebase, and mechanically protected from drift without human babysitting or unverified claims.

## Completed Requirements

- [x] **DEPLOY-01**: `voxlang.org` Cloudflare Pages deployments unblocked; builds succeed cleanly in CI with Astro Starlight.
- [x] **DEPLOY-02**: Single-issue failure escalation policy with fast failure diagnostics on broken frontmatter or links.
- [x] **DEPLOY-03**: Git-derived page modification timestamps accurately resolve across symlinked doc trees.
- [x] **DEPLOY-04**: Continuous post-deployment smoke verification checks verify live page availability.
- [x] **HONEST-01**: Frontmatter-driven status banners (`status: current | roadmap | draft | deprecated`) render prominently on reader-facing pages.

- [x] **HONEST-03**: Internal engineering research, sprint notes, and retrospective documents are isolated in the `Internals` sidebar.
