# Plan 77-03: Persistent `VoxDb` Trusty-URI Dataset Snapshots & Per-Spoke Mixture Replay

<objective>
Persist immutable, Trusty-URI-identified multi-spoke dataset snapshots and per-spoke mixtures into `VoxDb` and reload them deterministically (`CORPUS-06`).
</objective>

<tasks>
1. **`CORPUS-06` in `crates/vox-corpus/src/dataset_snapshot.rs`**:
   - Define `SpokeMixtureCount` and `TrustyDatasetSnapshot` (`snapshot_id`, `trusty_uri`, `content_digest`, `created_at_rfc3339`, `spoke_counts`, `total_rows`, `split`).
   - Implement `build_trusty_snapshot(snapshot_id: &str, records: &[TrainingRecordV2], split: SplitPolicy) -> TrustyDatasetSnapshot`.
   - Implement `#[cfg(feature = "database")] pub async fn persist_snapshot_to_db(db: &vox_db::VoxDb, snapshot_id: &str, records: &[TrainingRecordV2], split: SplitPolicy) -> anyhow::Result<TrustyDatasetSnapshot>` and `load_snapshot_from_db(db: &vox_db::VoxDb, snapshot_id: &str) -> anyhow::Result<(TrustyDatasetSnapshot, Vec<TrainingRecordV2>)>`.
2. **`CORPUS-06` in `crates/vox-corpus/src/arca_replay.rs`**:
   - Add `ReplayRow::to_training_record_v2(&self) -> Option<TrainingRecordV2>` and `#[cfg(feature = "database")] pub async fn replay_snapshot_for_spoke(db: &vox_db::VoxDb, snapshot_id: &str, spoke: Option<SpokeKind>) -> anyhow::Result<Vec<TrainingRecordV2>>`.
</tasks>
