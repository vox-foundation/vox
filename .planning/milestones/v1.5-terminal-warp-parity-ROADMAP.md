# Roadmap: Vox Terminal Session Host & Axis Console Warp-Parity (`H1–H8`)

## Overview

This milestone completed the clean-room Warp-parity terminal embedding across Vox (`vox-terminal-core`, `vox-orchestrator-d::term_dispatch`, `vox-term` CLI, and `vox-gui` Axis Console) per [`docs/src/architecture/terminal-session-host-design-2026.md`](../../docs/src/architecture/terminal-session-host-design-2026.md) (`D20`), without an AGPL fork of `warpdotdev/Warp`.

It unified CLI and GUI terminal sessions on `SessionHost` (`DaemonHost` + `LocalHost` fallback), retired duplicate terminal state machines (`Console/osc633.ts` and `commands/terminal_core.rs`), enabled GPU text rendering via `@xterm/addon-webgl` with DOM fallback, added interactive Warp-style command/output block cards (`BlockStreamView.tsx`) with `User`/`Agent` badges and context pinning, wired organic terminal parsing (`!shell`, unprefixed Console shell commands, Vox-native expressions via `vox_interp::eval_line`, and `?prompt` / `/ai` / `/model route` intelligent model routing via `vox_orchestrator::models`), and verified the full stack with Rust integration tests, Vitest, Playwright E2E, and multimodal computer-vision screenshot audits.
