# Phase 112 Plan 01: Editable Chat Task List, Session Context Pinning & Token Budget Controls (`CHAT-EDIT-01..04`)

## Objective
Deliver full inline task list CRUD (`ChatExecutionRail.tsx`, `PlanPanel.tsx`), bidirectional session context pinning & `@kb` citation editing (`ChatSurface.tsx`, `Loquela.tsx`), and interactive token budget / compaction strategy controls (`ContextWindowMeter.tsx`).

## Tasks
1. **`CHAT-EDIT-01`:** Add inline session task creation (`execution-rail-add-task-input`, `execution-rail-add-task-btn` -> `hopper_submit`), status toggle (`execution-rail-task-toggle-${id}` -> `hopper_mark_done`), inline title editing (`execution-rail-task-edit-${id}`), and task removal (`execution-rail-task-remove-${id}` -> `hopper_cancel`) in `ChatExecutionRail.tsx`.
2. **`CHAT-EDIT-02`:** Expand `PlanPanel.tsx` `EDITABLE_STATUSES` to `pending`, `queued`, and `blocked_on_approval`; add per-step status toggle (`plan-node-toggle-${id}`), remove (`plan-node-remove-${id}`), and standalone `+ Add step`.
3. **`CHAT-EDIT-03`:** Wire bidirectional `vox:context-pins-change` sync between `ChatExecutionRail.tsx` (`execution-rail-context-pins`) and `ChatSurface.tsx` (`kb-context-inspector-drawer`), and add inline context chip editing (`loquela-chip-edit-${id}`) in `Loquela.tsx`.
4. **`CHAT-EDIT-04`:** Add token usage readout (`used / max · %`), `auto-compact @ 80%`, and sibling compaction strategy button (`context-meter-strategy-btn`) in `ContextWindowMeter.tsx`.
