# Roadmap: Vox (`docs-freshness` v1.3)

## Overview

Milestone v1.3 transformed `voxlang.org` into a self-maintaining, continuously verified public documentation surface. It resolved Cloudflare Pages deployment unblocks, established collapsible and responsive reader layouts, built an automated claim extraction and verification pipeline (`vox-doc-pipeline::claims`), created the code-anchored freshness ledger (`ledger.v1.json`), introduced the tighten-only deficit baseline ratchet (`baseline.v1.json`), expanded auto-generated reference and crate API docs across 127 workspace crates (`docs/src/api/*.generated.md`), and established reader trust banners and golden drift benchmarks.
