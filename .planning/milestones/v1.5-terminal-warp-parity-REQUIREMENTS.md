# Requirements: Terminal Session Host & Axis Console Warp-Parity

**Defined:** 2026-10-13
**Completed:** 2026-10-14
**Core Value:** A single clean-room Rust `SessionHost` (`vox-terminal-core` + `vox-orchestrator-d::term_dispatch`) owns all PTY/OSC-633 block state, organic input routing (shell, Vox-native expressions, and model-routed AI turns), safety-floor-gated agent execution, secret-redacted chat context injection, and Warp-parity WebGL + structured block cards across both `vox term` and the Axis GUI Console.

## Completed Requirements

### 1. Terminal Session Host CLI Attach, Agent `term_run` Tool & Chat Context (Phase 46)

- [x] **TERM-01**: `BlockOrigin` (`User` | `Agent { agent_id }`) is tracked on `vox_terminal_core::block::Block` and `LocalHost::submit_with_origin` / `DaemonHost`, while wire `term.input` and `term.submit` continue fail-closed refusal of non-`user` origins (`46-01`).
- [x] **TERM-02**: `vox-term` (`vox term`) auto-detects a live `vox-orchestrator-d` via `orch.ping` (`DaemonHost` with `LocalHost` fallback), supports `--attach <session_id>` and `--local` flags, and lists live daemon sessions in the `vox-term` command palette (`46-02`, Task H7).
- [x] **TERM-03**: `TermDispatch::run_agent_command` gates agent-initiated terminal execution through `vox_orchestrator::oversight::floor::classify_floor` before executing on the daemon `LocalHost` with `BlockOrigin::Agent` (`46-03`, Task H8a).
- [x] **TERM-04**: `LocalHost::redacted_context_bundle` and `"term.context"` RPC return recent redacted terminal blocks (`redact_owned` via `vox-redact`) for sessions linked to the active chat session (`46-04`, Task H8b).

### 2. Axis Console Warp-Parity Terminal, WebGL Renderer & Block Chrome (Phase 47)

- [x] **TERM-05**: `crates/vox-gui/src/commands/pty.rs` routes `term_session_open`, `term_session_list`, `term_session_attach`, `term_session_input`, `term_session_submit`, `term_session_resize`, and `term_session_close` through `SessionHost` (`DaemonHost` when `PersistentDaemon` is reachable, `LocalHost` fallback), retiring `commands/terminal_core.rs` (`TerminalSessionManager`) (`47-01`).
- [x] **TERM-06**: `TerminalTab.tsx` attaches to `term_session_attach` (snapshot replay + gap-free `seq` stream), enables GPU rendering via `WebglTerminalAddon` with automatic DOM fallback on `onContextLoss`, and retires the duplicate TypeScript OSC-633 reducer (`Console/osc633.ts`) (`47-02`, Task H6).
- [x] **TERM-07**: `Console.tsx` and `BlockStreamView.tsx` render Warp-style interactive command/output block cards (`BlockStatus` badge, exit code, `User`/`Agent` origin badge, Copy Command, Copy Output, Re-run, Bookmark/Pin to Chat Context, and Ask Agent on failure) alongside the WebGL xterm viewport (`47-03`).
- [x] **TERM-08**: Axis Console multi-session tab bar & session picker lists live `term.list` sessions (including sessions started in `vox term`), provides a one-click "Continue in `vox term`" action (`vox term --attach <id>`), and passes Vitest + Playwright E2E + computer-vision verification (`47-04`).
