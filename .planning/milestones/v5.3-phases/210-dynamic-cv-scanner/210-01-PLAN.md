# Phase 210 Plan 01: Dynamic All-Surface CV Auto-Discovery & Interactive State Crawler

## Objective
Replace static CV surface enumeration with a dynamic discovery manifest (`discoverAllGuiSurfacesAndPanels`) that derives all 32 `SURFACE_REGISTRY` views, all 14 `ChatSurface` dock panels (`CORE_PANEL_IDS` + `OPT_IN_PANEL_IDS`), and interactive `[data-cv-subsurface]` / `[data-cv-popover-trigger]` state markers, while adding DOM layout density metrics (`composerToolbarRowCount`, `composerToolbarHeightPx`, `duplicateControlGroupCount`) to `auditDomQualityInPage` and `evaluateGuiSurfaceRubric`.

## Tasks
1. Create `crates/vox-gui/ui/src/lib/cvSurfaceDiscovery.ts` and `cvSurfaceDiscovery.test.ts` exporting `discoverAllGuiSurfacesAndPanels()`.
2. Extend `auditDomQualityInPage` (`crates/vox-gui/ui/e2e/review/audits.ts`) and `GuiDomAuditMetrics` / `evaluateGuiSurfaceRubric` (`crates/vox-gui/ui/src/lib/cvFlywheel.ts`) with `composerToolbarRowCount`, `composerToolbarHeightPx`, `duplicateControlGroupCount`, `discoveredSubTabLabels`, and `discoveredPopoverTriggers`.
3. Wire `discoverAllGuiSurfacesAndPanels()` into `crates/vox-gui/ui/e2e/review/cv-flywheel.spec.ts` and persist the discovery manifest in `cv-flywheel-all-surfaces.json`.
