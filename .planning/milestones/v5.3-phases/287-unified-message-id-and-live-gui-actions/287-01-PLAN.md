# Plan 287-01: Unified `message_id` & Telemetry Across Tauri/MCP, Live Transcript Actions, Mid-Turn Steer Composer & `streamWatchdog.ts`

## Goal
Close Cluster 5 of `docs/src/architecture/t3-vox-wave5-deep-review-and-parity-closure-2026.md`:
1. Preserve `backend_message_id` (`usr:...` / `ast:...`), `battery_spent_bu`, `remaining_balance_bu`, `quality_score`, `flesch_kincaid_grade`, `compaction_audit`, `posture_audit`, and `next_queued_follow_up` across `vox-gui` (`chat.rs`/`chat_turn.rs`), and teach `history.rs` (`chat_edit_message_in_place`, `chat_regenerate`, `chat_compact_up_to`) to match by `message_id`, `id`, or turn-index fallback while syncing mutations to `state.db` and restoring the turn's Git checkpoint on `chat_regenerate`.
2. Enable `✎ Edit` on both user and assistant messages in `ChatTranscript.tsx`, wire `↻ Regenerate` (`execute: true`) so it updates `sessionChatStore`, add `✂ Compact Here` (`compactChatUpTo`), wire `/compact` in `App.tsx`, and wire real branch comparison in `handleOpenBranchComparison`.
3. Fix the `Enter`-key task-abort bug in `Loquela.tsx` (`handleKeyDown`), render `[⚡ Steer Turn]` and `[+ Queue Next]` (`steerChatQueue`) during active turns, and auto-dispatch `next_queued_follow_up`.
4. Implement `crates/vox-gui/ui/src/lib/chat/streamWatchdog.ts` (`30s` first-token / `120s` idle timeout), wire `resumeChatStream` on session hydration/reconnect, and wire `ChatExecutionRail.tsx`, `ContextWindowMeter.tsx`, `SessionInteropModal.tsx`, `ConsensusGridView.tsx`, and `t3Wave3Rpc.ts` (`vcsMusePoolAdopt`, `sessionImportBundle`, `sessionListExternal`, `guestShareMint`, `guestShareSubmit`, `guestShareModerate`).
