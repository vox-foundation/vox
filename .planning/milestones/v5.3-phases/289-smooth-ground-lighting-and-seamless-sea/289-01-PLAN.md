# Phase 289 Plan 01: Smooth Ground-Plane-Recessed Lighting, 2D-Feathered Elliptical Sun-Shafts & Periodic Seamless Sea Synthesis

**Phase:** 289 (`289-smooth-ground-lighting-and-seamless-sea`)
**Requirements:** `URBS-SMOOTH-LIGHT-01`, `URBS-SMOOTH-LIGHT-02`, `URBS-SMOOTH-LIGHT-03`, `URBS-SMOOTH-LIGHT-04`

## Goal
Eliminate alpha-overlay lighting artifacts and repeating water tile seams in `VRBS` by rendering warm brazier/forge/worksite bounce illumination on the terrace ground plane before 3D buildings are painted, replacing hard-edged polygon god-rays with 2D-feathered elliptical radial gradients, replacing the hard `ctx.arc` district pulse with soft torch/window rim shimmer, and synthesizing `2π`-periodic seamless water waves in `pbrMaterials.ts`.

## Tasks
1. **Periodic Seamless `seaWater` Tile (`URBS-SMOOTH-LIGHT-04`)**:
   - Upgrade `buildSeaWaterTile` in `pbrMaterials.ts` to use `2π`-periodic trigonometric wave harmonics (`Math.sin((x / size) * Math.PI * 2 * k)`) so `x = 0` and `x = size - 1` (and `y = 0` / `y = size - 1`) match seamlessly without visible `64×64` tile boundaries.
   - Reduce the `seaWater` pattern overlay alpha in `paintFullBleedRomanLandscape` (`worldRenderer.ts`) from `0.62` to `0.18` and add subtle horizon-to-shore wave swell bands.
2. **Pre-Building Ground-Plane Bounce Illumination (`URBS-SMOOTH-LIGHT-01`)**:
   - Upgrade `drawAdditiveLightPools` in `lightingAndFx.ts` and call it in `WorldRenderer.paint` *before* 3D buildings and wonders are painted on each terrace so buildings rest *on* illuminated stone and naturally occlude ground light rather than having milky alpha circles painted over their roofs.
3. **2D-Feathered Elliptical Sun-Shafts (`URBS-SMOOTH-LIGHT-02`)**:
   - Upgrade `drawVolumetricGodRays` in `lightingAndFx.ts` to use rotated elliptical radial gradients (`ctx.translate`, `ctx.rotate`, `ctx.scale`, `createRadialGradient`) that feather smoothly to `rgba(..., 0)` in all `360°` directions with zero hard polygon edges.
4. **Soft Torch Shimmer & Window Rim-Light (`URBS-SMOOTH-LIGHT-03`)**:
   - Remove the solid `ctx.arc` circle in `WorldRenderer.drawAnimatedWorldEffects` and replace it with a feathered radial gradient shimmer.
