# Plan 283-01: System Prompt `$variable` Target Fix, Sanitizer Tag Completeness, `ToolRefusalDetector` & Lazy MCP Meta-Tools

## Goal
Close Cluster 1 of `docs/src/architecture/t3-vox-wave5-deep-review-and-parity-closure-2026.md`:
1. Interpolate `$variables` on `system_prompt` (not just the user prompt), format `$current_datetime` as full ISO-8601 UTC (`YYYY-MM-DDTHH:MM:SSZ`), and teach `detect_workspace_git_branch` to follow `gitdir:` when `.git` is a regular worktree file.
2. Expand `escape_user_prompt_special_tokens` (`<tool_call>`, `</tool_call>`, `<tool_response>`, `</tool_response>`, `<think>`, `</think>`), expand `compact_historical_web_search` (`<WebFetch>...</WebFetch>`), escape active-turn user prompts before LLM invocation, and persist extracted reasoning (`parse_special_entity_tags`) into `ChatTranscriptEntry::thought_signature`.
3. Wire `pi-t3chat` `ToolRefusalDetector` (`[SYSTEM TOOL CORRECTION]`, `max_corrections = 2`) and `NotT3Chat` search circuit breaker (`total_searches >= 3` strips search tools) into `agent_loop.rs`.
4. Wire `sanitize_mcp_tool_search_env` in `external_mcp.rs` and expose `LazyMcpGroupRegistry` (`vox_list_mcp_servers`, `vox_list_mcp_tools`, `vox_call_mcp_lazy`) in `ServerState`, `tool_registry.rs`, `input_schemas.rs`, and `dispatch.rs`.

## Tasks
1. **Task 1 (`T3-PROMPT-LOOP-01`):** Upgrade `detect_workspace_git_branch` in `system_prompt_vars.rs` to inspect `.git` when it is a file (`gitdir: ...`), format `$current_datetime` as ISO-8601 UTC (`YYYY-MM-DDTHH:MM:SSZ`), and call `interpolate_system_prompt_variables` on `system_prompt` in `message.rs` / `preamble_and_retrieval.rs`.
2. **Task 2 (`T3-PROMPT-LOOP-02`):** Expand `escape_user_prompt_special_tokens` and `compact_historical_web_search` in `context_sanitizer.rs`, apply `escape_user_prompt_special_tokens` to active-turn user prompts in `agent_loop.rs` and `message.rs`, and populate `thought_signature` from `parse_special_entity_tags` in `persist_and_envelope.rs`.
3. **Task 3 (`T3-PROMPT-LOOP-03`):** Add `should_nudge_tool_use` (`ToolRefusalDetector` with `max_corrections = 2`) and `total_searches >= 3` search-tool stripping in `agent_loop.rs`.
4. **Task 4 (`T3-PROMPT-LOOP-04`):** Wire `sanitize_mcp_tool_search_env` in `external_mcp.rs`, add `lazy_mcp_registry: Arc<PrMutex<LazyMcpGroupRegistry>>` to `ServerState`, and expose `vox_list_mcp_servers`, `vox_list_mcp_tools`, and `vox_call_mcp_lazy` in `dispatch.rs`, `tool_registry.rs`, and `input_schemas.rs`, with unit tests.
