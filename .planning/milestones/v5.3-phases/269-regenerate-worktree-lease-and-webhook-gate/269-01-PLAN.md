# Phase 269 Plan 01: `vox_chat_regenerate` & `vox_chat_edit_message_in_place` Backend MCP Tools, `DelegationWorktree` Lease/Env Wiring, `submit_webhook_events` Dedupe/Rate Gate & Compact `vox_orchestrator_status`

## Objective

Close `GAP-07`, `GAP-08`, and `GAP-09` by:
1. Implementing `chat_edit_message_in_place` (`vox_chat_edit_message_in_place`) and `chat_regenerate` (`vox_chat_regenerate`) in `history.rs` and registering them in `tool_registry.rs`, `input_schemas.rs`, and `dispatch.rs`.
2. Wiring `WorkspaceLeaseMap::global().lease_for(repo_root)` and `provision_untracked_env_files` into `DelegationWorktree::create` (`agy_worktree.rs`).
3. Wiring `WebhookDedupeAndRateGate::admit_delivery` into `submit_webhook_events` (`webhook_intake.rs`).
4. Wiring `compact` / `omit_idle_subagents` into `vox_orchestrator_status` (`dispatch.rs`) and upgrading `tests/transfer_budget.rs` to test the real compact projection and tool-output capping functions on a 900-row / 1.1 MiB fixture.

1. In `crates/vox-orchestrator-mcp/src/chat_tools/chat/history.rs`:
   - Implement `chat_edit_message_in_place(state: &ServerState, args: serde_json::Value)` to update a target message's `content` in-place in `chat_history:{session_id}` without truncating subsequent turns.
   - Implement `chat_regenerate(state: &ServerState, args: serde_json::Value)` to locate the target assistant (or user) message in `chat_history:{session_id}`, extract the preceding user prompt + posture overrides (`model_override`, `reasoning_effort`, `execution_mode`), truncate from the target turn onward, and invoke `chat_message`.
   - Register both tools in `tool_registry.rs`, `input_schemas.rs`, and `dispatch.rs`.
2. In `crates/vox-orchestrator-mcp/src/agy_worktree.rs`:
   - Acquire `WorkspaceLeaseMap::global().lease_for(repo_root)` in `DelegationWorktree::create` and call `provision_untracked_env_files(repo_root, &wt_path)` after `git worktree add`.
3. In `crates/vox-orchestrator-mcp/src/server_state/webhook_intake.rs`:
   - Gate incoming events in `submit_webhook_events` through a shared `WebhookDedupeAndRateGate::admit_delivery` before pushing to `webhook_inbox`.
4. In `crates/vox-orchestrator-mcp/src/dispatch.rs` and `crates/vox-orchestrator-mcp/tests/transfer_budget.rs`:
   - Route `vox_orchestrator_status` to `dei_tools::orchestrator_status_compact(state, omit_idle_subagents)` when `args["compact"].as_bool().unwrap_or(false)` is true.
   - Upgrade `transfer_budget.rs` to exercise `cap_and_summarize_tool_output` on a 1.1 MiB payload and compact status projection on a 900-agent fixture.
</steps>
