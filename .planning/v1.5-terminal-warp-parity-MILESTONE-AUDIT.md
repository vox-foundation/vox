## End-to-End Flows Verified

1. **Shell Execution (`!cmd` & Console unprefixed shell):** `cargo check --workspace` and `!echo hello` open `BlockOrigin::User` blocks, capture stdout/stderr and exit codes, and emit `BlockOpened` → `BlockOutput` → `BlockClosed`.
2. **Vox-Native Expression Evaluation:** Expressions (`40 + 2`, `let x = 21`) evaluate via `vox_terminal_core::vox_interp::eval_line` and render `=> 42` in a structured block.
3. **Intelligent Model Routing (`?prompt`, `/ai`, `/model route`):** `vox_terminal_core::agent::route_agent_prompt` classifies prompts via `vox_orchestrator::models::infer_prompt_intents` and selects the optimal model via `select_with_default_registry` (`Debugging` → `QUALITY_FIRST`, `Planning` → `QUALITY_FIRST`, `Research` → `COST_FIRST`, `Parsing` → `FAST`, `CodeGen`/`General` → `BALANCED`).
4. **Safety-Floor-Gated Agent Execution (`H8a`):** `TermDispatch::run_agent_command` checks `classify_floor("term_run", ...)`; destructive commands (`rm -rf /`) are blocked before any block opens, while allowed commands record `BlockOrigin::Agent`.
5. **Secret-Redacted Chat Context Bundle (`H8b`):** `LocalHost::redacted_context_bundle` and `"term.context"` RPC scrub secrets (`ghp_...`, `sk-...`) via `vox_redact::redact_owned` before returning blocks linked to a chat session.
6. **Multi-Session Tabs, Block Pinning & CLI Handoff (`H6–H7`):** Axis Console renders live sessions, pins blocks with amber borders (`data-pinned="true"`), switches session tabs (`term-2`), copies `vox term --attach <id>`, and renders cleanly under computer-vision inspection (`console-warp-parity-blocks.png`, `routing-explainer.png`).
