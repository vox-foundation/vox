<objective>
Make the reasoning scorer fail closed and record how many items it scored.

Purpose: BENCH-03 and roadmap success criterion 3. Today `load_model(...)?` returns before any report is written, an inference error becomes an empty completion that is graded wrong and counted, an empty batch scores `{0.0, 0.0, 0}`, the report writer creates the adapter directory if it is missing, and the scorer file itself is untracked.
Output: `BenchOutcome` in `vox-eval`; a committed `reasoning_eval.rs` that loads slices through `load_slice`, writes a `not_scored` report (n 0, no score keys) on every failure when the adapter directory exists, always returns `Err` on failure, and builds `ReasoningReport` only from `Scored`. The truncation override is removed; the max-tokens override is registered.

A green test is not a model score. No model weights are needed or used.
</objective>
