# Phase 345 Plan 01: MENS Regression Root-Cause Fixes (`supervised_ratio`, `<think>` Traces & Cued Answer Grader)

## Objective
Identify and fix every concrete root cause of MENS training/collateral regressions across the Qwen3 ladder (`0.6B`, `1.7B`, `4B`):
1. **`REGFIX-01` (`supervised_ratio: 4.5% < 10.0%` & 4x prompt bloat)**: `generate_training_system_prompt()` in `crates/vox-corpus/src/training/mod.rs` called `generate_system_prompt()` (8.6 KB / ~2,200 tokens from `mens/config/system_prompt.txt`) instead of `builtin_system_prompt()` (1.48 KB / ~350 tokens), contrary to `builtin_system_prompt()`'s own doc comment and unit test. Switching to `builtin_system_prompt()` raises `supervised_ratio` from `4.5%` to `~20–25%` and eliminates prompt middle-trimming.
2. **`REGFIX-02` (`vox_think` `debug` auto-fix hallucination & `plan-check` unclosed `<think>` overthinking)**: `train_mixed.jsonl` contained `0.0%` `<think>` reasoning traces and `23.9%` `error_correction` ("Fix the bug") rows, causing 1.7B to spot bugs on `vox_think` `debug` items ("Do not fix it. What integer does `main()` return as written?") and output the *fixed/intended* value instead of the literal return value (6 of 8 `debug` losses), and causing 10 losses from unclosed `<think>` at 2048 tokens. Add `crates/vox-corpus/src/corpus/vox_reasoning_synth.rs` generating 120 compiler-verified, leakage-checked `<think>` traces across `literal_debug`, `state_trace`, and `invariant_check`, wired into `mens/config/mix.yaml`, `mens/config/mix-vox-lang.yaml`, and `mix_prepare.rs`.
3. **`REGFIX-03` (`extract_cued_answer` stopword & truncated-cue shadowing in `qwen_reasoning.rs`)**: Harden `extract_cued_answer` so it scans cues right-to-left, rejects English prose stopwords (`"The"`, `"that"`, `"not"`, `"in"`), extracts numbers after `"The integer returned is 42"`, and recovers earlier valid cues when a trace truncates right after `"So the answer is "`.
4. **`REGFIX-04` (`1.7B` 28-layer LoRA rank/alpha scaling)**: Use `--rank 8 --alpha 16 --grad-accum 8` on 28-layer small models (`0.6B`, `1.7B`) where `rank=16, alpha=32` over-perturbs `lm_head` + projection logits.
