  <action>
    1. In `crates/vox-cli/src/lib.rs`, add `infer_subcommands = true, infer_long_args = true` to `#[command(...)]` on `VoxCliRoot`.
    2. In `crates/vox-cli/src/argv_normalize.rs`, implement `classify_recovery(raw_args: &[String]) -> RecoveryOutcome`:
       - Guard inputs: if `raw_args.len() <= 1`, or `raw_args.len() > 16`, or any token is `"--help"` / `"-h"` / `"--version"` / `"-V"`, return `RecoveryOutcome::Unrecoverable`.
       - Separate `raw_args[1..]` into leading command-token candidates (non-flag tokens before the first file-like token containing `/`, `\`, or ending with `.vox`, `.rs`, `.json`, `.toml`, `.yaml`, `.md`), flags (tokens starting with `-`), and positional tail.
       - Look up `side_effect_class` for any matched `CommandCatalogEntry` by matching `entry.capability_id` (or `cli.<path.join(".")>`) against `vox_capability_registry::bundled_index().rows`, defaulting to `"local_mutation"` when a row has no explicit `side_effect_class` (fail-safe conservative default).
       - **Rule 2a (Token Permutation):** For command-token prefixes of length $k \in \{2, 3\}$, compare their sorted lowercase token multiset against the sorted `entry.path` (and `entry.aliases`) of compiled-in `CommandCatalog` entries. If exactly one `CommandCatalogEntry` matches (and its `path` != the original order), construct `RecoveryOutcome::Resolved` with `RecoveryKind::TokenPermutation` and `rewritten_argv` placing `entry.path` first followed by the remaining positional and flag tokens. If multiple entries match, sort by `entry.path` and return `RecoveryOutcome::Shortlist`.
       - **Rule 2b (Unique Leaf Elision):** If the first non-flag token `t0` is not a top-level command, find all `CommandCatalogEntry` rows where `entry.path.len() >= 2` and `entry.path.last() == Some(&t0)`. If `matches.len() == 1`, return `RecoveryOutcome::Resolved` with `RecoveryKind::UniqueLeafElision` and `rewritten_argv` prepending the parent path segments.
       - **Rule 2c (Wrong-Subcommand Flag Redirection):** If `raw_args` starts with a valid subcommand `cmd_path` (e.g. `["build"]`) and contains an unknown long flag `--flag` (not in that entry's `arguments` or `GlobalOpts`), search sibling entries in the same `source_group` / `product_lane` (prioritizing `compile` ↔ `build` ↔ `run` ↔ `check` ↔ `test` in `fabrica`/`app`) whose `arguments` declare `long == Some(flag)`. If a unique sibling (or canonical `compile` for `--release` / `--target`) owns that flag, return `RecoveryOutcome::Resolved` with `RecoveryKind::WrongSubcommandFlag`.
       - **Rule 2d (Capability Index Fuzzy Shortlist Fallback):** Join the command-token candidates and call `vox_capability_registry::resolve(vox_capability_registry::bundled_index(), &query)`. Map `Resolution::Exact` or `Resolution::Shortlist` rows that have `row.cli.is_some()` into `RecoveryOutcome::Shortlist`.
    3. Format all modified `.rs` files with `rustfmt --edition 2024`.
  </action>
