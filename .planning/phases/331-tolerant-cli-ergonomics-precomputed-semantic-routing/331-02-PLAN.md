# Phase 331 Plan 02: Dual-Persona & Side-Effect Safety Gate (`CLI-TOL-03`)

<objective>
Wire the `side_effect_class` (`read_only` vs `local_mutation` / `remote_mutation`) and caller-persona (`InteractiveHuman` vs `NonInteractiveOrAgent`) execution gate into `argv_normalize` and `crates/vox-cli/src/main.rs`, ensuring humans get frictionless read-only auto-repair and `[Y/n]` mutation safety while LLM agents and scripts receive deterministic exit-code-2 `aci.error_recovery` redirects without ever hanging on prompts.
</objective>

## Threat Model (ASVS L1)

| Threat ID | Component | Threat Description | Mitigation | Severity |
|-----------|-----------|--------------------|------------|----------|
| T-331-03 | `decide_execution` | Mutating command (`remove`, `clean`, `deploy`, `cutover`) auto-executes from a fuzzy or permuted input without explicit user consent | `decide_execution` only permits `ExecutionDecision::AutoExecute` when `side_effect_class == "read_only"` AND `persona == CallerPersona::InteractiveHuman` AND `kind` is `TokenPermutation`, `UniqueLeafElision`, or `SynonymRewrite` | High |
| T-331-04 | `parse_cli_with_tolerance` | Headless subagent or CI job hangs indefinitely waiting for `[Y/n]` stdin read | Check `CallerPersona::detect` (TTY + env vars + `--json` scan) before any stdin prompt; `NonInteractiveOrAgent` never calls stdin read | High |
</threat_model>

    1. Implement `CallerPersona::detect_with(raw_args: &[String], stdin_tty: bool, stdout_tty: bool, env_non_interactive: bool) -> CallerPersona` and `CallerPersona::detect(raw_args: &[String]) -> CallerPersona` (using `std::io::IsTerminal` on `std::io::stdin()` and `std::io::stdout()`, plus checking `std::env::var_os` for `CI`, `VOX_MCP`, `VOX_NONINTERACTIVE`, `VOX_CLI_GLOBAL_JSON`, and scanning `raw_args` for `"--json"`).
    2. Implement `decide_execution(outcome: RecoveryOutcome, raw_args: &[String], persona: CallerPersona) -> Option<ExecutionDecision>`:
       - For `RecoveryOutcome::Unrecoverable`, return `None` (caller falls back to `clap_err.exit()`).
       - For `RecoveryOutcome::Resolved(cand)`:
         - If `persona == CallerPersona::InteractiveHuman`:
           - If `cand.side_effect_class == "read_only"` and matches!(cand.kind, RecoveryKind::TokenPermutation | RecoveryKind::UniqueLeafElision | RecoveryKind::SynonymRewrite): return `Some(ExecutionDecision::AutoExecute(cand))`.
           - Otherwise return `Some(ExecutionDecision::PromptConfirm(cand))`.
         - If `persona == CallerPersona::NonInteractiveOrAgent`:
           - Return `Some(ExecutionDecision::RejectWithDiagnostic(CliErrorRecovery { ... }))`.
       - For `RecoveryOutcome::Shortlist(cands)`:
         - Return `Some(ExecutionDecision::RejectWithDiagnostic(CliErrorRecovery { ... }))` listing the shortlist invocations.
    3. Implement `format_recovery_diagnostic(recovery: &CliErrorRecovery, json_mode: bool) -> String` emitting either structured JSON (`{"error": ..., "aci": {"error_recovery": recovery}}`) when `json_mode` is true, or a clear human/LLM text block with `error[<error_code>]: ...` and `help: canonical command:\n  <cmd>` when `json_mode` is false.
    4. Implement `pub fn parse_cli_with_tolerance() -> VoxCliRoot` in `crates/vox-cli/src/argv_normalize.rs` and call it from `crates/vox-cli/src/main.rs` in place of `vox_cli::VoxCliRoot::parse()`. On `ExecutionDecision::AutoExecute(cand)`, print `eprintln!("→ running canonical: {}", cand.rewritten_argv.join(" "));` and re-parse `VoxCliRoot::try_parse_from(&cand.rewritten_argv)`. On `ExecutionDecision::PromptConfirm(cand)`, print the prompt to `stderr`, read one line from `stdin`, execute if `"y"` / `"yes"` / `""`, or `std::process::exit(2)`. On `ExecutionDecision::RejectWithDiagnostic(diag)`, print `format_recovery_diagnostic` to `stderr` (or `stdout` if `--json`) and `std::process::exit(2)`.
    5. Run `rustfmt --edition 2024` on changed files.
  </action>
