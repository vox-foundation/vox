<objective>
Implement the spoke-aware local model selector in `vox-orchestrator` and `vox-populi`. The selector unifies live VRAM titration across all 6 Qwen3 sizes (`0.6B`..`32B`), checks `spoke_gates.json` to guarantee only passed adapters are chosen, dispatches tasks by file extension and lane tokens, routes retrieval lanes to the B3 embedder, and preserves the Lane G RLVR hook.

**Ordering:** Wave 2 of Phase 340. Depends on plan 340-01 for `spoke_gates.json` and multi-spoke repo paths.

**Purpose:** Provide a zero-manual-configuration, fail-safe inference path that always selects the right model size and verified specialized adapter for any coding or agentic turn.
</objective>
