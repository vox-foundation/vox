<objective>
Implement the multi-spoke HuggingFace repository layout (`spokes/<spoke>/`), top-level backward-compatible `vox-lang` aliasing, and the unified `spoke_gates.json` gate manifest across `vox-populi` and `vox-ml-cli`.

**Ordering:** Wave 1 of Phase 340. Depends on Phase 338 gate receipts schema (plan 338-02) and Phase 339 model card infrastructure.

**Purpose:** Move MENS from mono-spoke root repos to organized multi-spoke repositories (`brbrainerd/vox-mens-qwen3-<size>`) without breaking legacy clients or tools pulling from the root.
</objective>
