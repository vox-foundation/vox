<objective>
Turn the manual freshness-ledger refresh into a daily bot that proposes changes as a draft PR a human reviews, and collect the two decisions that shape the rest of the automation.

Purpose: DOCS-DRIFT-05 part 1. RESEARCH F5 verified: the ledger is refreshed by hand (`vox audit docs --update-ledger`), no workflow runs it, and `generate_freshness_ledger` stamps `updated_at` with `Utc::now()` and `head_commit` with HEAD, so a naive daily job would open a PR every day with no real change. Precedent for a bot PR is `harness-eval-nightly.yml` (PAT-preferred token via env, explicit push URL, SHA-pinned checkout with persist-credentials false); unlike it, this bot must stop at a draft PR.
Output: idempotent ledger writes, the `Docs Drift Refresh` workflow with contract tests, and two recorded decisions.
</objective>
