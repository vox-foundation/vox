<objective>
Make the docs-system SSOT map unable to disagree silently with the machinery: a stage checks that every gate in §4 runs where the table says, and that §6 lists only gaps nothing closes.

Purpose: DOCS-DRIFT-06. After 343-01..08 the map gained rows (regen parity, overlay parity, CLI claims, orphan pages, check-links hardening, Docs Drift Refresh) and lost §6 bullets; nothing yet stops the next edit from drifting. A unit test alone would not run on docs-only PRs (PR CI tests only affected crates), so the check is an ssot-drift stage in the fast tier.
Output: `docs_system_parity.rs`, the stage, `pre_push::tier_labels`, a tagged and normalized §4/§6, the ledger row.
</objective>

Noun primary: docs-system-ssot.md §4/§6 stay the human-authored map of the docs system.
Decision: no-change. The probe table in `docs_system_parity.rs` is a consumer that verifies the map against the machinery; it does not generate the map, and the map does not become generated.
</assumption_delta_decision>
