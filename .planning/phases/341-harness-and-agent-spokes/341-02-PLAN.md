<objective>
Execute the v1 agent sequencing protocol on `Qwen3-0.6B`: train the mono `harness` union adapter first, gate it on the 72-episode 6-behavior `suite:agent_episodes` and collateral check, train split `tool-selection` and `argument-generation` adapters, run the head-to-head comparison, and publish the passing weights to `spokes/<spoke>/` in `brbrainerd/vox-mens-qwen3-0.6b`.

**Ordering:** Wave 2 of Phase 341. Depends on Plan 341-01 for compiled datasets and profile configuration.

**Purpose:** Empirically resolve whether a single unified agent adapter or specialized split adapters provide superior MCP tool selection and schema compliance on `0.6B`, establishing the proven agent spoke for the ladder.
</objective>
