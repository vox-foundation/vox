<objective>
Training with no named size uses the plan 01 selector for every spoke, base and preset. The load path re-reads free memory and steps an automatic pick down, or refuses an explicit size that no longer fits.

Purpose: SIZE-02 training call site and the pre-load re-read. Chat and the GUI host are plan 03. Mesh routing stays phase 319.
Output: resolve_training_selection, the local free-memory read at the train entry, and confirm_before_load inside schola run_train.

Locked decisions this plan implements:
- D-02, D-04: The unnamed-size path fails closed when free memory is unreadable. Do not substitute a constant.
- D-06: One dense size. Every spoke base and preset follow it. A spoke preset of qwen3_16g does not remain when the pick is 14B.
- D-07: resolve_base_model uses the new selector only when no size was named. strong_code_default and small_code_default stay on pick_base. Do not retune those tags. Do not change mesh.
- D-10: Immediately before load, re-read free memory. Automatic picks step down. The result names the original size, the loaded size, and the reading. If the smallest measured row no longer fits, do not load.
- D-11: An explicit resolve_qwen3_size name is not stepped down.
- D-12: Unit tests inject the reading. They do not probe a GPU, download weights, or start a training run.
</objective>
