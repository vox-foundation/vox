# Phase 322 Plan 01: Calibrated Turn Decisions and Dynamic Action Catalog

<objective>
Implement `DEC-01..04` and `CAT-01..02` in `crates/vox-orchestrator-mcp`:
1. Pre-turn `TurnDecisionPack` upstream of `build_selection_request`, selective-prediction calibration evaluator (`accuracy`, `ece`, `coverage_at_error`), and `!inference_privacy_local_only_from_env()` privacy gate (`DEC-01`, `DEC-04`).
2. Post-tool `PostToolDecisionPack` integration with `evaluate_post_tool_batch_hook`, `evaluate_stop_hook`, and `apply_repair_escalation_to_config`, plus flag-off byte-for-byte identity tests across all four control points (`DEC-02`, `DEC-03`).
3. ChatARC dynamic action catalog shortlist (`K <= 10`) composing skill entries, `TOOL_REGISTRY`, and `vox_capability_registry::bundled_index()` CLI rows, with calibrated choice activation and fail-open behavior (`CAT-01`, `CAT-02`).
</objective>
