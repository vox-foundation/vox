Metric definitions (so tests and report agree). For one question on one split: n_total = number of lines; an item is answered when the pack returned an Answer for that question; correct when its value equals the gold encoding.
- laplace_precision(correct, fired) = (correct + 1) / (fired + 2); 0/0 gives 0.5, the 322-01 prior.
- ece(items, bins = 10): equal-width confidence bins over [0, 1]; sum over non-empty bins of |accuracy − mean confidence| × bin size / item count.
- coverage_and_risk(items, n_total, tau): answered-at-τ = items with confidence ≥ tau; coverage = answered-at-τ / n_total; risk = errors among them / answered-at-τ (0.0 when none).
- coverage_at_error(items, n_total, eps): the largest coverage over thresholds t taken from the distinct item confidences such that risk(t) ≤ eps; 0.0 when no threshold qualifies.
Hand-computed check set: items [(0.9, correct), (0.9, wrong), (0.6, correct), (0.6, correct)], n_total 5 → ece 0.4; coverage_and_risk at 0.8 → (0.4, 0.5); coverage_at_error eps 0.0 → 0.0; eps 0.25 → 0.8; laplace_precision(3, 4) → 0.6667 (±1e-4), (0, 0) → 0.5.
