Locked decisions, numbered from 320-CONTEXT.md (that file states them as prose, not D-NN labels):
- D-01: Candidates are the measured qwen3_code QLoRA rows. Their floors already live on those rows: 0.6B 2000, 8B 12000, 14B QLoRA 20000, 32B 60000. 1.7B and 4B stay floor_measured false, reason floor_unmeasured, and name no adapter. The 14B LoRA row is not a candidate.
- D-02: One free-memory reading, injected in tests. Total VRAM is not the budget. Write smallest floor first. Every qwen3_code QLoRA size gets a record.

- D-04: Reasons are floor_unmeasured, does_not_fit, base_snapshot_absent, and train_not_run.

Tests inject a Ready fixture whose record is trained and whose manifest names the pin, and an absent fixture whose record is base_snapshot_absent. No network and no GPU probe.
- D-06: Do not invent floor_mb. Do not add a crate edge. Do not edit phase 322 paths. The clap command is plan 02.
