# Phase 368 Plan 01: Romanesque MENS Corpus & Pipeline Studio GUI + Auto-Sync JSONL Flywheel

## Objective
Eliminate manual JSONL regeneration and expose a dynamic, Romanesque-styled MENS Corpus & Pipeline Studio inside `vox-gui` (`MensCorpusStudioPanel.tsx` integrated into `MensTrainingView.tsx`), backed by real `vox-corpus` fingerprint/mix automation, live JSONL pagination/search/editing, `vox_compiler::parser::parse` AST validation, and real `mens/runs/qwen3-*` + `reasoning_compare/checkpoints` telemetry.

## Tasks

### Task 1: Auto-Materializing Mix Engine & Real Tauri Backend Commands (`MENS-STUDIO-GUI-01`, `MENS-STUDIO-GUI-02`)
- Upgrade `crates/vox-gui/src/commands/mens_run_reports.rs` so `read_ladder_status` reads real `mens/runs/qwen3-{size}/gate_receipt.json`, `spoke_gates.json`, and `collateral_damage_report.json` instead of only hardcoded fallback strings.
- Add real backend DTOs and `#[tauri::command]` handlers in `crates/vox-gui/src/commands/mens_run_reports.rs` (and register in `crates/vox-gui/src/main.rs`):
  - `mens_corpus_studio_snapshot(mix_config: Option<String>, run_dir: Option<String>)`: Reads all `mens/config/mix*.yaml` files, computes live config + source fingerprints, reads `{output_stem}.mix_report.json`, computes `supervised_ratio_pct` and `system_prompt_tokens` from `builtin_system_prompt()` and actual mix completions, and reads live ladder checkpoint progress (`mens/runs/reasoning_compare/checkpoints/*/*.jsonl`) + McNemar $p$-values (`collateral_damage_report.json` / `reasoning_compare/*.json`).
  - `mens_corpus_read_jsonl(source_path, query, family_filter, think_only, offset, limit)`: Reads any source or output `.jsonl` under the workspace root (auto-materializing `vox_reasoning_traces.jsonl` via `vox_orchestrator_mcp` / `vox_cli` when requested and absent), parses `<think>` traces and Vox code blocks, validates Vox code with `vox_compiler::parser::parse` (via `vox_orchestrator_mcp`), and returns paginated records + distinct task families.
  - `mens_corpus_save_jsonl_row(...)`: Validates and saves an edited or newly added JSONL row (or source weight update in `mix*.yaml`), and when `auto_sync: true`, automatically re-runs the mix pipeline and updates `train_mixed*.jsonl`, `{output_stem}.mix_report.json`, and `mens/data/train.jsonl`.
  - `mens_corpus_rebuild_mix(mix_config, force_resynth_traces)`: Re-synthesizes `vox_reasoning_traces.jsonl` if requested/missing and runs `run_mix_with_options` + syncs `mens/data/train.jsonl`.
- Add unit tests in `crates/vox-gui/src/commands/mens_run_reports.rs` covering snapshot, JSONL read/filter/AST validation, inline row edit + auto-sync mix rebuild, and real `qwen3-*` ladder checkpoint reading.

### Task 2: Romanesque 3-Arch `MensCorpusStudioPanel.tsx` & `MensTrainingView.tsx` Integration (`MENS-STUDIO-GUI-03`)
- Create `crates/vox-gui/ui/src/components/surfaces/Models/MensCorpusStudioPanel.tsx` matching the Romanesque Concept Art (`concept_mens_pipeline_studio_romanesque_1794153153510.jpg`):
  - Top Romanesque Arch Frieze with Spoke/Mix selector pills (`vox-lang`, `rust`, `agents`, `harness`, `full-mix`), Active Config badge, live Dependency Fingerprint badge (`FRESH` / `STALE` / `AUTO-MATERIALIZED`), and `RomanBrassGauge` Supervised Token Ratio dial.
  - Left Arch (`Mix Sources & Auto-Materializer DAG`): Live source cards with editable weights, line counts, share bars, `AST VERIFIED` / `AUTO-SYNTH` tags, `Auto-regenerate mix on source edit` toggle, and `[Verify & Rebuild Mix]` action button.
  - Center Arch (`Live JSONL Record Inspector & Inline AST Editor`): Search input, task family filter pills (`literal_debug`, `state_trace`, `invariant_check`, `vox_codegen`, `<think> present`), virtualized/paginated JSONL table with `AST VALID` badges, and split bottom editor drawer (`Code & Prompt`, `<think> Reasoning Trace`, live `vox_compiler::parser` diagnostics, and `[Save Row & Auto-Sync Mix]`).
  - Right Arch (`Ladder Checkpoints & Collateral Gate Matrix`): Live Qwen3 Ladder cards (`0.6B`, `1.7B`, `4B`, `8B`, `14B`) with `RomanBrassGauge` dials, checkpoint item progress (`e.g. 71/128 GSM8K • +3.13% VOX_THINK`), McNemar $p$-values, and Held-Out Leakage Guard status.
- Integrate `MensCorpusStudioPanel` into `MensTrainingView.tsx` so operators can inspect, edit, validate, and auto-sync corpus JSONLs directly from the MENS workbench.
