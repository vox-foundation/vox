<objective>
Real model output on every trained card (CARD-03 rendering, CARD-07): the D2 examples section and
the recorded output that ends "Use it", with honest fallbacks, plus the remaining goldens for the
with/without-examples cases (CARD-11).

Orchestrator decisions applied: decision 1 (verdict lines from stored fields; message-level
verdicts are a user choice listed in 339-10); decision 2 (the literal loss rule, totals carry fixes
and breaks); decision 3 (each verdict line names the size and item id, so two wins never produce the
same sentence).

Checker items applied:
- B2: D2 is locked, so the totals sentence states the rule for that size.
- B1: no adapter output or score from an older serving path reaches a card.
- W2: the verdict phrases are the docs-page list, tested against the page itself.

No real run records the current serving path yet. Real cards will show examples only for the sizes
re-evaluated after 335's serving change (339-10 records which ones).

Purpose: a reader sees what the adapter changes, on that size's own items, chosen by a fixed rule.
Output: `partials/examples.md`, `partials/use_it.md`, regenerated trained goldens, two new goldens,
mutation proof 6, the where-things-live row.
</objective>
