# Phase 339 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Scope: Hugging Face model cards (`README.md`) and programmatic, data-driven SVG visual dashboards (`assets/overview.svg` for `vox-mens-index` and `assets/scorecard.svg` for `vox-mens-qwen3-*`) generated by `vox-populi` via Askama markdown templates. 5. Compiler verification success badge and syntax highlight token (`#34d399`).

Warning / Advisory color (semantic non-accent): `#fbbf24` (Amber) reserved strictly for `Gate: needs re-gate`, unmeasured hardware floors, and architectural tags.

## UI Considerations

Applicable state considerations resolved: 8 covered, 2 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Untrained size (32B or unmeasured rung) | ✅ covered | The card renders `Model Weights Not Yet Trained` empty-state copy with no simulated metrics or false scores, showing hardware requirement and local training command |
| partial | Unevaluated size (14B trained without eval) | ✅ covered | The card renders `Evaluation Incomplete for This Size` empty-state copy, lists weights as present, and directs developer to run `vox mens eval-gate --size 14B` |
| error | Stale gate pass (1.7B, 4B, 8B on retired 32-item rule) | ✅ covered | Status badge and SVG render `Gate: needs re-gate` in Amber, detail the blocker reason, and suppress automatic serve recommendation |
| error | Gate regression (0.6B failing gsm8k_think) | ✅ covered | Status badge and SVG render `Gate: failed` in Coral, show the McNemar p-value and exact failing slice, and state the retraining remediation path |
| populated | Gate current pass (future passing run) | ✅ covered | Status badge and SVG render `Gate: passed` in Emerald, provide verified pull and serve commands, and link to the gate receipt |
| partial | Missing checkpoint text for examples | ✅ covered | When held-out checkpoint outputs are missing, the card renders the honest fallback string `"no recorded output"` instead of silently dropping the item |
| accessibility | High contrast & dark mode SVGs on Hub | ✅ covered | All visual information in SVGs adheres to WCAG AA contrast ratio (≥ 4.5:1), embeds `<title>`, `<desc>`, and `aria-label`, and is duplicated in semantic markdown tables and text below |
| long-text | Multi-line prompts or error descriptions | ✅ covered | Long prompts wrap within the 240-character preview or collapsible `<details>` blocks; SVG text elements use clipped text-anchor or fixed width containers |
| visual | SVG rendering across dark/light Hub themes | 🧪 backstop | Human side-by-side review checkpoint validates rendered SVGs against Hub dark and light modes before any gated push |
| interaction | Ungated pull command execution | 🧪 backstop | CLI command requires explicit `--allow-ungated` flag to proceed with download, displaying the documented destructive warning |
