# Plan 80-02: Playwright Real-Backend E2E Suite for Chat/Loquela, Terminal, Palette & Explorer (`REAL-01`, `REAL-02`, `REAL-03`)

## Objective

Deliver the Playwright real-backend E2E server and bridge (`crates/vox-gui/ui/e2e/real-backend/`) and the end-to-end Playwright verification suite (`crates/vox-gui/ui/e2e/real-backend-journeys.spec.ts`) proving `Chat`/`Loquela`, `Terminal` (`Console.tsx`), `⌘K` Universal Palette, and `ExplorerView.tsx` against a live ephemeral HTTP backend with disk persistence across `page.reload()` and zero `installTauriMock` stubs.

## Tasks

1. **Create `realBackendServer.ts`, `realBackendBridge.ts`, and `realBackendBridge.test.ts` (`REAL-01`)**:
   - `realBackendServer.ts`: Ephemeral localhost HTTP server (`127.0.0.1:0`) persisting state in a temporary directory on disk (`mkdtempSync`) and supporting optional upstream pass-through to `VOX_REAL_BACKEND_URL`.
   - `realBackendBridge.ts`: Browser init script installing `window.__TAURI_INTERNALS__.invoke` backed strictly by `fetch()` calls to the ephemeral server URL.
2. **Create `crates/vox-gui/ui/e2e/real-backend-journeys.spec.ts` (`REAL-02`, `REAL-03`)**:
   - Verify `Chat` + `Loquela` session creation, `chat_turn` submission, reply rendering, and message persistence across `await page.reload()`.
   - Verify `Console` (`Terminal`) session creation/attach, `!cargo test` / `40 + 2` block execution, secret redaction on context export, and block persistence across `await page.reload()`.
   - Verify `⌘K` Universal Palette and `ExplorerView.tsx` against the live command catalog from the backend server.
