# Phase 397 Plan 01: Standalone `crates.io` Wave 2 Expansion (15 -> 21 Publishable Crates)

## Objective
Expand the publishable standalone crate set from 15 to 21 crates for Milestone v6.8, registering the Wave 2 packages (`vox-ast`, `vox-redact`, `vox-jsonschema-util`, `vox-http-client`, `vox-test-harness`, `vox-drift-check`) with full workspace metadata, clean packaging manifests, dedicated READMEs, hakari exclusions, and distribution profile parity.

## Completed Tasks

1. **Package Manifest & Metadata Standardisation**:
   - Configured `[package]` metadata in all 6 crates (`vox-ast`, `vox-redact`, `vox-jsonschema-util`, `vox-http-client`, `vox-test-harness`, `vox-drift-check`):
     - `version.workspace = true`
     - `edition.workspace = true`
     - `license.workspace = true`
     - `repository.workspace = true`
     - `authors.workspace = true`
     - `rust-version.workspace = true`
     - `readme = "README.md"`
     - Preserved existing crate descriptions.
   - Removed `workspace-hack` from `[dependencies]` across all 6 crates.
   - Added all 6 crates to `final-excludes` `workspace-members` in `.config/hakari.toml`.
   - Authored informative, clean `README.md` documents for all 6 crates.

2. **Decoupled Internal Dependencies**:
   - `vox-drift-check`: Decoupled unpublishable dependencies (`vox-compiler`, `vox-config`). Inlined path constants (`REPO_DRIFT_CACHE_DIR`, `REPO_DRIFT_BASELINE_FILE`, `REPO_DOT_VOX_CACHE_DIR`) and implemented a zero-dep literal token scanner for Vox source files in `extractors/vox.rs`. Preserved `vox-code-audit` (which is already Tier 3 published with `version = "0.6.0"`).
   - `vox-ast`, `vox-redact`, `vox-jsonschema-util`, `vox-http-client`: Verified zero unpublishable internal dependencies.
   - `vox-test-harness`: Configured package metadata and README.

3. **Workspace Dependency Versions**:
   - Updated root `Cargo.toml` `[workspace.dependencies]` to specify `version = "0.6.0"` for all 6 crates:
     - `vox-ast`
     - `vox-redact`
     - `vox-jsonschema-util`
     - `vox-http-client`
     - `vox-test-harness`
     - `vox-drift-check`

4. **Public Manifest & Distribution SSOT Registration**:
   - Added Tier 4 entries in `crates/_public.toml` in topological order.
   - Appended all 6 new publishable crates in topological order to `contracts/distribution/profiles.v1.yaml` (`publish.crates`).
   - Synced `crates/voxup/profiles.v1.yaml` to be byte-identical to `contracts/distribution/profiles.v1.yaml`.
