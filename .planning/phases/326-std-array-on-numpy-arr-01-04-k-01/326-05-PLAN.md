    Write zscore_golden_typechecks first, in crates/vox-compiler/src/typeck/builtins.rs. Parse and typecheck examples/golden/py_array_stats.vox. It fails until Ty::Array and the seven methods exist.

    Add Ty::Array holding a boxed inner Ty in ty.rs. signature() text is Array of the inner signature. to_hir_type lowers to HirType::Generic with the name Array and one inner type. Do not add a HirType variant. Do not edit LEXER_KEYWORDS.

    In expr_ops.rs, when either operand of Sub or Div is Ty::Array, handle it before host int/float promotion. The same inner dtype yields Array of that dtype, including a 0-d plan against a 1-d plan. A mismatched inner dtype pushes a diagnostic that names astype and yields Ty::Error. Do not fall through to host promotion. Do not change host scalar promotion of 1 plus 1.0. Leave Add and Mul, and the integer and bool mappings, to plan 07.

    For std, before the positional zip in check_arguments, accept only a named argument whose name is correction and whose value is an int. Positional std(0) and a missing name are diagnostics. Do not default correction.

    When the receiver is Ty::Array and the method is to_list, require HirCapability::Python on the enclosing function (D-02). Plan methods add no capability. Do not add an array arm to stdlib_module_capability. Read HirCapability::Python. Do not add the variant.

    to_list on Array of f64 returns Result of list of float (host f64). Do not return a host f32 list.
