## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust `#[test]` / `#[tokio::test]` via `cargo test -p <crate>` / `cargo nextest run -p <crate>` |
| **Config file** | `.config/nextest.toml` |
| **Quick run command** | `cargo test -p vox-capability-registry` ; `cargo test -p vox-cli --lib capability_index` (run in background) |
| **Full suite command** | Hosted CI only (`Check, Build, and Test (Rust)`); never workspace-wide locally |
| **Estimated runtime** | ~60–300 seconds per crate (cold builds longer; always background) |

---

## Sampling Rate

- **After every task commit:** `cargo check -p <touched crate>` + that task's new unit tests (background)
- **After every plan wave:** `cargo test -p vox-capability-registry`, `cargo test -p vox-cli --lib capability_index`, `cargo test -p vox-orchestrator-mcp --test capability_tool_dispatch`, then `vox ci capability-index` + `vox ci operations-verify` on a freshly built `target/debug/vox`
- **Before `/gsd-verify-work`:** hosted CI green on the draft PR
- **Max feedback latency:** 300 seconds (background builds)

3. Remove the `ds!("capability_index", …)` line → source-text test fails.
4. Add an op resolving to no owner → ratchet fails.
5. Remove the MCP dispatch arm → `capability_tool_dispatch` and `operations-verify` fail.
