<objective>
Build the rust spoke's held-out compile-and-test bench (D-09, D-22, SPOKE-07 rust part) and prove it
discriminates with a scripted oracle and named known-bad controls (D-10). No model runs here; plan
338-07 wires it into the rust gate and plan 338-08 runs the 0.6B base control.

**Ordering:** this plan touches only vox-corpus files and new data files, none of which phases 335 or
337 edit, so the D-15 ordering rule does not apply and it has no 335/337 precondition. Its dependency on 338-01 is ordering only: D-18 makes the
stale-pass fix the first wave of 338, ahead of everything else, so this plan runs in wave 2 alongside
338-02 and 338-03 rather than beside 338-01.

D-14: reuse the humaneval runner's file-redirected, kill-on-timeout exec instead of a new process
layer; test-first; no new crate edge and no new dependency (std-only candidate crates, `tempfile` is
already a dependency).

Expected wall-clock (D-16): no GPU. Quick tests (2 items x oracle and stub) about 20-40 s after the
crate is built. The full control matrix (5 policies x 12 items, `#[ignore]`) about 3-6 min, dominated by
`cargo test` of tiny std-only crates sharing one target dir per run.

Purpose: a rust adapter can later be gated on whether its code compiles and passes tests it never saw.
Output: `vox_corpus::corpus::rust_bench`, 12 items, README.
</objective>
