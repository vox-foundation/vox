# Plan 77-01: Canonical Multi-Spoke Training Schema (`TrainingRecordV2`) & `.vox` / Rust Admission Gates

<objective>
Define the canonical multi-spoke `TrainingRecordV2` / `SpokeKind` / `OracleReceipt` schema in `vox-corpus` (`CORPUS-01`) and wire deterministic admission gates for `.vox` (`lex -> parse -> HIR -> typeck` + interpreter smoke check, `CORPUS-02`) and Rust workspace items (`syn::parse_file` + stub/panic quality gate, `CORPUS-03`).
</objective>

<tasks>
1. **`CORPUS-01` in `crates/vox-corpus/src/training/contract.rs`**:
   - Define `SpokeKind` (`VoxLang`, `RustWorkspace`, `StructuredShell`, `McpToolChain`, `AgentHarness`), `OracleReceipt`, `RecordProvenance`, and `TrainingRecordV2`.
   - Implement `TrainingRecordV2::new(...)`, `compute_content_digest(...)`, `trusty_uri()`, and `verify_integrity()`.
2. **`CORPUS-02` in `crates/vox-corpus/src/corpus/corpus_readiness.rs`**:
   - Implement `verify_vox_admission(source: &str) -> OracleReceipt` running `vox_compiler::pipeline::run_frontend_str` (`lex -> parse -> HIR -> typeck`) and rejecting any `.vox` snippet with parse/typeck errors or retired decorators.
   - Implement `admit_vox_record(prompt: &str, response: &str, origin: &str) -> Option<TrainingRecordV2>`.
3. **`CORPUS-03` in `crates/vox-corpus/src/corpus/extract_rs.rs`**:
   - Implement `verify_rust_item_admission(source: &str) -> OracleReceipt` using `syn::parse_file` and quality checks (rejecting `todo!()`, `unimplemented!()`, or syntax errors).
   - Add `RsTrainingPair::to_training_record_v2(&self) -> Option<TrainingRecordV2>`.
</tasks>
