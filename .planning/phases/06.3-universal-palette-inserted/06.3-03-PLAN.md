For each of the 21 verbs listed in <context>, open its handler and classify it with this rubric (D-02/D-03; never by name):
- `destructive`: deletes or irreversibly overwrites persisted user or project data. Examples: DB tables or rows, installed plugins or skills, snapshots restored over current state, git history or working-tree rollback, or any file the user cannot regenerate with a vox command.
- `writes_files`: creates or modifies files whose contents can be rebuilt (caches, generated artifacts, pruned derivable snapshots).
- `spawns_process`: starts or stops processes or services without deleting persisted data. A stop/down verb whose handler discards queued or in-flight work irrecoverably is `destructive` instead.
- `null`: the handler cannot be located or its effect cannot be determined (feature-gated code not compiled in this tree counts only if the source is unreadable). Null keeps the verb side-effecting in the UI.
