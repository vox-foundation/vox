Toasts render in components/ui/Toasts.tsx:30-75 (close button only today). `pushToast` also records into the notice center via `noticeFromToast` (lib/notices.ts:37-49), which copies only text fields.

- guards/toastBodyGuard.test.ts bans `body: String(`, `setX(String(` and bare `String(e|err|error)`. Read error text with a typeof/instanceof check instead.
- CommandCatalogForm builds `argsObj` keyed by `arg.long || arg.name` (:56-69). Positional args (long and short both null) were sent as `--name value`, which clap rejects.
- Dialog primitives: components/ui/Dialog.tsx (Radix: focus trap, Esc, aria-modal, DialogTitle required). Analog: components/surfaces/Chat/TaskDiffDialog.tsx.
