<objective>
THRU-04 (D-21): drop qlora's always-zero internal LoRA arm (two rank-r matmuls, a scalar tensor, a
broadcast multiply and a broadcast add per linear per step) from every inference linear with a dense
variant that is bit-identical to today's path, and prove it on CPU, on Metal, and against the real-model
references.

**Amended 2026-11-06 (train/serve parity fix).** Inference no longer folds ΔW into W before NF4: an
adapted layer is `QuantizedLinear::Adapted { base, a_t, b_t, scale }`, built by `build_linear` in
inference.rs (the single construction site). Its trained arm is NOT the arm this plan drops and must stay;
only `base` (a plain `from_weight` layer with zero B) converts to Dense. The 337-05 references must be
recorded on the post-fix code (they are, if 337-05 runs after commit of the parity fix; check
`git log -1 --format=%H -- crates/vox-plugin-mens-candle-metal/src/inference.rs` predates the reference
log).

**Ordering:** after 337-05, so R1-before measured the unchanged code. Plugin-only; no 335 files.

**Expected wall-clock (D-17):** Task 3 Metal checks ~2 min plus reference reruns 0.6B ~6 min and 4B
~8 min: about 16 min.

Purpose: cut per-linear dispatches (part of F and A) with zero numeric change, and free the NF4 copy that
the qlora struct keeps next to its dequantised cache.
Output: QuantizedLinear::Dense, into_inference, two qlora accessors, tests, a mutation proof.
</objective>
