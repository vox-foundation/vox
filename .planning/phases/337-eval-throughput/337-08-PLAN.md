<objective>
THRU-03 and the plugin half of THRU-05: batch the row-independent attention prelude across rows, bound
the batch width by a verified width the host passes in, then prove identity on real models at the widths
used (R2) and measure R1-after for the THRU-12 table.

**Ordering:** after 337-07 (model.rs). The host side of the cap (decode-identity.yaml) is 337-09, which
copies the width this plan proves.

**Expected wall-clock (D-17):** R2: 0.6B N 32 cap 128 widths 8, 16, 32 with reference ~10 min; 4B N 16
cap 64 widths 4, 8, 16 with reference ~8 min; 4B N 32 cap 64 width 32 ~10 min; optional extra 0.6B
width ~5 min. R1-after ~93 min (5 / 8 / 15 / 25 / 40 min by size). Total about 2 h 5 min.

Purpose: per-row op count toward ~11 per layer (337-RESEARCH Pattern 2) and a width bound backed by
evidence instead of the "token-identical at any size" claim.
Output: row-batched prelude, max_batch_size clamp, tests, mutation proof, measured AFTER rows and the
verified width.
</objective>
