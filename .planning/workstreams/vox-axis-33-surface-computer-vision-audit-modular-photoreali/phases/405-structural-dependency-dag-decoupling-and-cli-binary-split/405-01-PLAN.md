# Phase 405 Plan 01: Structural Dependency DAG Decoupling, Compilation Firewalls, Thin CLI Dispatch & Apple Silicon Linker Optimization

## Goal
Establish `vox_repository::core` leaf facade separation, insert `#[inline(never)]` LLVM/rmeta compilation firewalls across `crates/vox-repository` and `crates/vox-cli`, verify third-party & Apple Silicon linker/profile invariants via `dev_loop_guard`, and record measured incremental check/test timings in `contracts/reports/v68-structural-dag-speedup.v1.json`.

## Tasks

1. **Leaf Facade & `vox-repository` Compilation Firewalls (`STRUCT-DAG-SPEED-01`, `STRUCT-DAG-SPEED-02`):**
   - Expose `pub mod core` in `crates/vox-repository/src/lib.rs`.
   - Apply `#[inline(never)]` firewalls on `discover.rs`, `resolve.rs`, `capabilities.rs`, `repo_catalog/catalog.rs`, `repo_catalog/query.rs`, and `repo_catalog/federation.rs`.
   - Add `test_core_module_leaf_facade_exports` in `crates/vox-repository/tests/federation_tests.rs`.
2. **Thin `vox-cli` Dispatch Boundary & Graph Audit (`STRUCT-DAG-SPEED-03`, `STRUCT-DAG-SPEED-04`):**
   - Apply `#[inline(never)]` firewall on `vox_cli::commands::ci::run_body::run`.
   - Audit `vox-compiler`, `vox-db`, and `vox-config` manifests (confirming zero coupling to `vox-repository`) while honoring `Cargo.lock` / `layers.toml` freeze rules.
3. **Linker Verification & Benchmark Report (`STRUCT-DAG-SPEED-05`):**
   - Run `cargo test -p vox-repository --test federation_tests`, `cargo test -p vox-cli-ci --lib dev_loop_guard`, `cargo check -p vox-repository`, and `cargo check -p vox-cli`.
   - Publish `contracts/reports/v68-structural-dag-speedup.v1.json` with exact observed counts and timings.
