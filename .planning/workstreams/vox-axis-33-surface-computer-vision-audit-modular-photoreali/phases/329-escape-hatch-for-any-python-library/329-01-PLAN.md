# Phase 329 Plan 01: Tier 2 Python Escape Hatch (`PYX-01..04`, `K-01`)

## Objective
Enable `.vox` programs to invoke the curated Python ecosystem (`scipy`, `scikit-learn`, `pillow`, `pandas`) and project-bound libraries through a contextual `import py <alias> from "<module>"` syntax backed by lock-verified `.vox.pyi` sidecar contracts, opaque `PyObject` typing, `Denied`-policy blocking, hashed telemetry, syntax-K tier metrics, and `vox py bind`.

## Tasks

1. **Contextual Parser, Formatter, and HIR Lowering (`PYX-01`, `K-01`)**
   - Add `ImportPathKind::PyModule { alias, module }` to `crates/vox-ast/src/decl/types.rs` with zero new `LEXER_KEYWORDS`.
   - Implement contextual `try_parse_py_module_import` in `head_import.rs`, `printer.rs` formatting, and `HirPyImport` lowering in `hir/nodes/decl.rs` and `hir/lower/mod.rs`.
2. **Sidecar Contracts, `uv.lock` Verification, Typecheck & Opacity (`PYX-01`, `PYX-03`, `PYX-04`)**
   - Add `crates/vox-compiler/src/python_escape_support.rs` using `vox_crypto::secure_hash` for `# vox-lock-blake3:` verification and hashed telemetry.
   - Author curated sidecars under `contracts/python/sidecars/` (`scipy.signal`, `scipy.stats`, `sklearn.cluster`, `PIL.Image`, `pandas`).
   - Enforce `Denied` module rejection, stale/missing sidecar rejection, `PyObject` field/index/op/boundary opacity, `.decode(...)`, `uses python_unverified`, and `vox/python/unverified-call` diagnostics.
3. **Runtime Worker Dispatch, `vox py bind`, Telemetry, and Syntax-K (`PYX-02`, `PYX-03`, `PYX-04`, `K-01`)**
   - Add `VoxValue::PyModule` / `PyObject`, `materialize_escape_call`, and worker `family == "escape_call"` with `_is_denied_escape_target`.
   - Add `PyCmd::Bind { module }` (`vox py bind`) in `vox-cli-research`.
   - Register `python.escape_call` in `contracts/telemetry/events.v1.yaml` and wire `count_python_tier_calls` in `vox-codegen::syntax_k` + `support_metrics.llm_surface`.
   - Add `examples/golden/py_escape_psd.vox`, update `canonical-ladder.v1.yaml`, `complexity-budget.v1.json`, and `source-token-budget.v1.json`, and verify via `py_escape_hatch_test.rs`.
