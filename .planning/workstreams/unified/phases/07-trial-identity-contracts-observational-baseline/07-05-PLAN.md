<objective>
Create the pure L2 trial engine crate `vox-research-trial-core` (D-02). It contains:
- the expanded, versioned `CampaignPreregV1`;
- a typestate gate in which only `verify_campaign` can produce a `VerifiedCampaign`: allowlist first, signature over canonical bytes, then `campaign_id` recomputed;
- the campaign and run lifecycle transition checks;
- `RunIdentity` for attempts and retries.

Register the crate, and make `vox-cli-research` its consumer and re-exporter.

Purpose: TRIAL-01, 02, 03 and 05 all hang on one identity and one gate that the production runner (07-09) must call. Phase 12 consumes the same types (D-08). The existing `verify_prereg` never checks the id (RESEARCH Q1.3), so this gate closes that hole by construction.
Output: the new crate with tests, its `layers.toml` / `where-things-live.md` rows, and the `vox_cli_research::trial_core` re-export.
</objective>

<assumption_delta_decision>
Detector: `assumption-delta scan 7` returned `detected: false`. Recorded anyway at the orchestrator's request, because the trust root changes.
- Primary noun: the **Clavis signer allowlist** (`SignerAllowlist`). A campaign's `signer_pubkey_hex` is demoted to a *claimed* signer that must be on the list.
- Decision: **promote**. `verify_campaign` trusts only allowlisted keys, and an empty list trusts nobody. The legacy orchestrator `PreregGate` stays untouched, and both are fed from the same Clavis list (D-07, single trust root).
- Invariant test: `foreign_signer_refused` plus `swapped_signer_key_fails`, guarded by mutation proof 2.
</assumption_delta_decision>
