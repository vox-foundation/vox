<objective>
Wire the §5 provenance record, the typed report, the MENS card check and the scoreboard guard into `vox model eval-corpus` (BENCH-04, BENCH-05 eval side, BENCH-03 report side; D-05, D-06, D-07, D-11).

Purpose: the report today omits the vox git sha, binary hash, grammar identity and weights hash (design G11), hashes `config_digest` with a direct `sha2` import (a crypto-policy violation), uses an FNV context hash, and writes routing's `model_scoreboard` even for incomplete or ingested runs. This plan collects every §5 field the harness can observe, hands them to 12-04's single completeness gate, refuses unlabeled `mens/*` rows through 12-06's card check, and only lets complete runs reach routing.
Output: provenance collectors and the typed report in eval_corpus.rs; spec/reference paths on `Fixture`.
</objective>
