<objective>
Tracer slice for the capability index. One real end-to-end path: catalog -> generator -> committed index -> drift gate -> embedded loader.

- `vox ci capability-index --write` reads `contracts/operations/catalog.v1.yaml` and writes `contracts/capabilities/capability-index.v1.json`, with one row for every CLI and MCP projection.
- `vox ci capability-index` (check mode) and `vox ci ssot-drift` fail when that file is stale.
- `vox-capability-registry` embeds the file and looks up rows by id.

Purpose: prove the architecture on the riskiest seams first. Those seams are the costly D-01 path and schema, the include_str! bootstrap (RESEARCH Pitfall 7), feature-independent inputs (Pitfall 2) and the drift registration (DISC-02). Later plans then only fill nullable fields and add consumers.

Output: the index schema and file, the L2 types and loader, the `vox ci capability-index` subcommand wired into ssot-drift and ssot-regen.vox, and mutation proofs for the gate.
</objective>

- Top level, struct `CapabilityIndex`:
  - `schema_version` (u32, always 1)
  - `generator` (String, "vox ci capability-index")
  - `coverage_snapshot` (Option of `CoverageSnapshotMeta`)
  - `domains` (Vec of `DomainDef`)
  - `rows` (Vec of `IndexRow`)
- `CoverageSnapshotMeta`: `corpus_id`, `git_sha`, `built_at` (all String).
- `DomainDef`: `id`, `label`.
- `IndexRow`, in this order:
  - `id`, `kind` (RowKind), `title`
  - `summary` (Option String), `op_id`, `status`, `domain`, `product_lane`, `side_effect_class`, `tier` (all Option String)
  - `cli` (Option CliRef), `mcp` (Option McpRef), `gui` (Option GuiRef), `owner` (Option OwnerRef)
  - `source_path` (Option String)
  - `docs` (Vec DocLink), `skills` (Vec String), `equivalents` (Vec String), `refs` (Vec String)
  - `coverage` (Option CoverageRef)
- `RowKind`, serde snake_case: `cli`, `mcp_tool`, `surface`, `crate`, `skill`, `doc`. Kind sort order is the declaration order.
- `CliRef`: `path` (Vec String), `invocation` ("vox " + path joined by spaces), `feature_gate` (Option String).
- `McpRef`: `name`.
- `GuiRef`: `view_key`, `nav_label`, `representation_tier` (all Option String) and `catalog_form` (bool).
- `OwnerRef`: field `crate_name` serialized as `crate`, `layer` (Option u8), `rule` (String).
- `DocLink`: `path` (repo-relative, `/` separators) and `origin` ("default" | "claim" | "pinned").
- `CoverageRef`: `kind` (Option String), `basis` (String), `ambiguous` (bool), `reason` (Option String).
