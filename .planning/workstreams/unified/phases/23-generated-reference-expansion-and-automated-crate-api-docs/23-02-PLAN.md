<action>
1. Implement `crates/vox-cli-ci/src/crate_api_docs.rs`:
   - Inspects `Cargo.lock` / `Cargo.toml` and workspace packages from `cargo metadata`.
   - Filters to first-party workspace crates (excluding workspace-hack / third party).
   - For each crate, extracts:
     - Name, version, description, license, repository.
     - Public crate exports / modules from `src/lib.rs` (top-level `pub mod`, `pub struct`, `pub enum`, `pub fn`, `pub trait`).
     - Features and workspace dependencies.
   - Generates `docs/src/api/<crate-name>.generated.md` with YAML frontmatter:
     - `title: "<crate-name> (generated API reference)"`
     - `description: "<crate description>"`
     - `category: "API Reference — Crates"`
     - `status: current`
   - Includes standard WARNING_BLOCK.
   - Provides `run(repo_root: &Path, write: bool) -> Result<()>` with write/verify modes.
2. Register `CiCmd::CrateApiSync { write: bool }` in `cmd_enums.rs` and dispatch in `run_body.rs`.
</action>
<verify>
`cargo run -p vox-cli -- ci crate-api-sync --write` runs and creates generated docs under `docs/src/api/`.
</verify>
</task>
