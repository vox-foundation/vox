# Phase 55 Plan 01–04: Autonomous Mermaid Observation, Validation, LLM Self-Repair & Astro Rendering

## Objective
1. **MERMAID-01 (`vox-doc-pipeline::pipeline::mermaid` + `vox_validate_mermaid`):** Build a deterministic Mermaid diagram validator and auto-fixer checking supported diagram types (`flowchart`, `graph`, `sequenceDiagram`, `stateDiagram`, `stateDiagram-v2`, `classDiagram`, `erDiagram`, `xychart-beta`), balanced `subgraph`/`end` and bracket delimiters, unquoted special characters (`()`, `[]`, `{}`) in node labels and `-- ... -->` edge labels, and raw HTML tags in unquoted labels. Wire into `vox-doc-pipeline` lint and expose `vox_validate_mermaid` in `vox-orchestrator-mcp`.
2. **MERMAID-02 (`SelectionIntent::mermaid_repair` + `agent_loop.rs` observation & tool-call repair):** Add `SelectionIntent::mermaid_repair()` to `vox_orchestrator::models::select` (`TaskCategory::CodeGen`, `SelectionAxes::COST_FIRST`, `complexity: 3`, `max_cost_usd_per_call: Some(0.01)`). In `run_agent_turn`, automatically observe broken ```` ```mermaid ```` blocks in assistant responses and markdown tool writes, invoke `vox_validate_mermaid` as a tool call, and run a budgeted repair pass using the `mermaid_repair` selected model (falling back to deterministic tool repair when at the iteration/budget boundary).
3. **MERMAID-03 (Repo Mermaid Audit & `docs-astro` SVG Renderer):** Audit all existing Mermaid blocks in `docs/src/` (`deep-research-waves-and-competitive-analysis-research-2026.md`, `as-any-casts-reduction-strategy-research-2026.md`, etc.), fix broken unquoted edge/node labels, and add client-side Mermaid SVG rendering with an error-boundary fallback in `docs-astro`.
4. **MERMAID-04 (Tests):** Unit and integration tests in `vox-doc-pipeline`, `vox-orchestrator`, and `vox-orchestrator-mcp`.
