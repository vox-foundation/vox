## Deviations from Plan

None to scope. Notes:

- **Parity gaps (index data, not Rust changes).** The TS index row carries only the first docs path (no origin), the coverage kind string only (no `ambiguous` flag or `reason`), and no owner-resolution failure marker beyond a null crate. So Docs shows one path without `(origin)`, a null coverage reads `none (not computed)` instead of `none (<reason>)`, and an ambiguous coverage is not flagged. Rust side left unchanged as instructed; closing the gap needs extra fields in `generate_ts` and is a candidate follow-up, not required by D-07 as written.
- `buildExplainCard` gained the optional `asOf` parameter (decision above); the plan's four-argument call still works.
- Plan 06.3-09 note: the card has no special path for a CLI row without a live catalog entry; it is the same card, with Open form disabled and the reason shown.

## Notes for later plans

- Hand-off closed: `onExplain` is now wired in App.tsx. The drawer needs the capability index loaded; it loads on first palette open, so Explain from the palette is always synchronous after that.
- e2e palette headings must be scoped to `getByRole('dialog', { name: 'Command palette' })`; the explain drawer is a second dialog, found with `getByRole('dialog').filter({ hasText: 'Equivalents' })`.
- Playwright clipboard needs `context.grantPermissions(['clipboard-read','clipboard-write'])` (chromium only).
