- The federated scorer gives exact 100, prefix 80, includes 50 (federatedSearchIndex.ts:77-88). Entries carry `score` after `searchFederatedIndex`.
- Doc paths: vox_docs_index returns absolute paths. Index doc rows use repo-relative `docs/src/...`. `read_doc_markdown` resolves relative paths against `<repo>/docs/src` and rejects anything outside it (crates/vox-gui/src/commands/docs_index.rs:108-127). So the doc key and the path passed to onOpenDoc = the text after the last `docs/src/` (backslashes normalized to `/`).
- Installed skills reach Omnibar as `skills: CommandCatalogEntry[]` with `path: ['skill', name]` (lib/installedSkills.ts). The installed name is `path.at(-1)`.
- `useFederatedSearchIndex` is used only by Omnibar. Its `getCatalog` + `getActionManifest` effect feeds `command`/`action` kinds, which no longer reach the palette (D-05; manifest actions duplicate index CLI/MCP rows, RESEARCH F-5).
