<action>
1. Create `contracts/reports/docs-freshness/baseline.v1.json` recording current grandfathered broken mentions.
2. Create `contracts/reports/docs-freshness/suppressions.v1.json` schema and initial structure.
3. Implement `crates/vox-doc-pipeline/src/claims/suppressions.rs`:
   - Data model: `DocSuppression` with `id`, `page_path`, `anchor_id`, `owner`, `reason`, `expires_after` (RFC3339 / YYYY-MM-DD).
   - Validation: verify that all suppressions have non-empty owner and reason, and that `expires_after >= today`. Expired suppressions are flagged with an error.
4. Implement `crates/vox-doc-pipeline/src/claims/gate.rs`:
   - `evaluate_drift_gate(current_findings, baseline, suppressions)`:
     - Filter current findings to reader-facing `status: current` pages (`tutorials/`, `reference/`, `how-to/`, `explanation/`).
     - Allow any finding that is active in `suppressions.v1.json` or present in `baseline.v1.json`.
     - Flag any **new** unsuppressed broken mention as a hard gate failure.
     - Implement ratchet tightening: if a baselined finding is resolved, `--tighten` updates `baseline.v1.json` to remove it (never adds new entries).
</action>
<verify>
`cargo test -p vox-doc-pipeline claims::gate claims::suppressions` passes.
</verify>
</task>

<name>Task 2: CLI integration for drift gate and re-attestation</name>
<files>
crates/vox-cli/src/commands/audit.rs

<action>
1. Update `vox audit docs` in `crates/vox-cli/src/commands/audit.rs`:
   - Add `--check-drift` flag: runs the tighten-only gate. Exits 1 if new broken mentions or expired suppressions exist, 0 otherwise.
   - Add `--tighten-baseline` flag: removes resolved findings from `baseline.v1.json`.
   - Add `--attest <path>` flag: re-attests the specified documentation page against the current git HEAD commit, updates its anchor hashes in `ledger.v1.json`, and sets `state: "verified"`.
   - Add `--attest-reviewed` flag: re-attests all pages whose anchors were modified in the current branch diff after reviewer inspection.
</action>
<verify>
`cargo run -p vox-cli -- audit docs --check-drift` runs and validates cleanly.
</verify>
</task>
