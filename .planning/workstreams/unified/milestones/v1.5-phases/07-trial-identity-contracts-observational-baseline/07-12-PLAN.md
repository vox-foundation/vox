<objective>
Expose the observational baseline through the one existing CLI surface, `vox research eval`:
- draft a baseline campaign from the shipped default pipeline config;
- sign it with the Clavis key and immediately verify it;
- run it through the production runner with the real pipeline and write the results.v2 report.

Then hand the live baseline run to the human, because it needs keys, network and spend.

Purpose: BASE-01 and success criterion 8 need a real baseline campaign run once with no policy change. Everything up to the live call is automated and tested hermetically.
Output: `trial/cli.rs`, the extended Eval flags, a clap test, a cli.md row update, and a human-verified live baseline report.
</objective>
