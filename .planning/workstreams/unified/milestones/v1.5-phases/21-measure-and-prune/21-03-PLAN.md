<action>
Implement `crates/vox-doc-pipeline/src/claims/prune.rs`:
1. `build_inbound_link_graph(docs_dir: &Path) -> HashMap<PathBuf, HashSet<PathBuf>>`:
   - Walks all `.md` and `.mdx` files in `docs/src`.
   - Extracts markdown link destinations `[label](target.md)` and resolves relative links to canonical paths.
   - Computes inbound reference counts.
2. `get_substantive_git_dates(repo_root: &Path) -> HashMap<PathBuf, u64>`:
   - Uses `Command::new("git")` to batch-fetch author dates while filtering out mechanical commits matching `chore(docs): regenerate`, `ssot-autoregen`, `style: fmt`, `ci: sync`.
   - Attaches `// vox-arch-check: allow git-exec` with rationale if needed.
3. `find_duplicate_clusters(pages: &[PageMetadata]) -> Vec<TopicCluster>`:
   - Computes Jaccard similarity over normalized title/slug tokens.
4. `classify_disposition(page: &PageMetadata) -> Disposition`:
   - `MoveToInternals`: status is `research` or `roadmap`, or internal architecture note.
   - `Archive`: 0 inbound links AND (dead mentions >= 3 OR age > 180 days OR status is `legacy`/`deprecated`).
   - `Merge`: duplicate-topic cluster member where newer canonical document exists.
   - `Keep`: reader-facing tutorials, guides, references with healthy mentions.
5. Unit and integration tests in `crates/vox-doc-pipeline`.
</action>
<verify>
`timeout 120s cargo test -p vox-doc-pipeline claims::prune` passes.
</verify>
</task>
