## Findings & Applied Fixes

### 1. [Warning/Fixed] Window-Level Enter Key Interception in Omnibar
- **Location:** `crates/vox-gui/ui/src/components/layout/Omnibar.tsx`
- **Issue:** Window-level Enter keydown listener intercepted Enter when focus was on non-row interactive buttons (such as the "Browse all in Explorer" facet button or "Retry" button), suppressing native click activation and triggering the first command in the list.
- **Fix:** Added `data-row="true"` to row buttons and guarded the Enter listener: if focused/target element is a button that does NOT have `data-row`, the listener returns early and lets native browser click activation proceed.
- **Verification:** Unit tests and Playwright E2E test `Browse all N in the Explorer link opens Explorer with seeded query (19)` passed.

### 2. [Warning/Fixed] Missing Dependency Array on `useLayoutEffect` in Omnibar
- **Location:** `crates/vox-gui/ui/src/components/layout/Omnibar.tsx`
- **Issue:** `useLayoutEffect` had no dependency array, causing focus checks on every single re-render (including every keystroke).
- **Fix:** Provided `[open]` as the dependency array so focus check runs only when the palette opens.
- **Verification:** Verified focus retention on open and zero re-render thrash.

### 3. [Warning/Fixed] Clippy `manual_pattern_char_comparison` Lint
- **Location:** `crates/vox-cli/src/commands/ci/gui_coverage_gate.rs:25`
- **Issue:** `gate.split(|c| c == '|' || c == '+' || c == ',')` triggered clippy warning.
- **Fix:** Replaced closure with char slice `gate.split(['|', '+', ','])`.
- **Verification:** `cargo test -p vox-cli --lib gui_coverage_gate` passed.

### 4. [Warning/Fixed] Clippy `unnecessary_map_or` Lint
- **Location:** `crates/vox-cli/src/commands/ci/capability_index/groups.rs:135`
- **Issue:** `r.gui.as_ref().map_or(false, |gui| gui.catalog_form)` triggered clippy warning.
- **Fix:** Replaced with idiomatic `r.gui.as_ref().is_some_and(|gui| gui.catalog_form)`.
- **Verification:** `cargo test -p vox-cli --lib capability_index::groups` passed.

### 5. [Info/Fixed] Unused State Re-renders in ExplorerTree
- **Location:** `crates/vox-gui/ui/src/components/surfaces/Explorer/ExplorerTree.tsx:64`
- **Issue:** `const [, setFocusedAction] = useState<ActionSlot | null>(null);` triggered redundant component re-renders on every keyboard navigation step while the action slot was already tracked in `pendingFocusRef`.
- **Fix:** Removed unused state and associated `setFocusedAction` calls.
- **Verification:** All 6 `ExplorerTree` Vitest tests and APG roving tabindex Playwright tests passed.

### 6. [Info/Fixed] Runtime Tool Injection Documentation
- **Location:** `crates/vox-cli/src/commands/graphify/mcp_tool_names.rs:33`
- **Issue:** `orch.oversight_set` injection into tool names lacked rationale comment.
- **Fix:** Added explanatory comment documenting that it is injected at runtime by the orchestrator daemon for dynamic oversight level changes.
- **Verification:** `cargo test -p vox-cli --lib graphify::mcp_tool_names` passed.
