## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local graph cache (.vox/cache, gitignored) -> snapshot | Built locally; becomes a committed file only through an explicit `--refresh-coverage` |
| Cargo.toml descriptions / plugin catalog -> index | Contributor-authored text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.2-17 | Tampering | graph-coverage snapshot | medium | mitigate | Written only by an explicit `--refresh-coverage`. Drift never rebuilds it (D-07). It records the source git_sha so reviewers can see what it reflects. Generated attribute plus review of the PR diff |
| T-06.2-18 | Denial of service | graph JSON read | low | mitigate | Bounded reads via vox_bounded_fs. A missing graph gives a clear error, not a panic |
| T-06.2-19 | Tampering | crate description / skill text | low | mitigate | Single-lined, with control characters stripped (06.2-01 summary sanitizer) before it reaches any emitter |
| T-06.2-20 | Repudiation | stale coverage shown as current | low | mitigate | D-08: the card and index always show `as of <sha> (<date>)`. Staleness is visible, not hidden |
</threat_model>
