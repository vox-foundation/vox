## Shared Patterns

### Byte-exact write-or-verify with LF normalization
**Source:** `operations_catalog.rs:203-205, 906-924`. **Apply to:** every generated artifact in this phase. Never raw `fs::write` + `.trim()` (gui_surface_registry.rs:241-248 is the weaker older form).

### Determinism
**Source:** `gui_surface_registry.rs:77-87` (explicit sort in `backfill`) and RESEARCH Pitfall 6. **Apply to:** all emitters: sorted rows by (kind order, id), `BTreeMap`, no timestamps, `/` path separators, no `canonicalize()` in stored data.

### Feature-independent inputs
**Source:** `gui_surface_registry.rs:153-179`. **Apply to:** generator inputs; read committed registries, not compiled clap tree.

### Test-First + mutation proof
**Source:** `docs.rs` source-text dispatch test (~885-893), commit `6e9b79286` mutation note. **Apply to:** every new `pub fn` (same-file `#[cfg(test)]`), plus mutation proofs listed in RESEARCH Validation (row deletion, source drift, ds! line removal, ratchet, MCP arm removal) with `grep -c` before/after guards; compare file contents (`-diff` hides `git diff` for generated files).

### Bounded reads and validation
**Source:** `vox_bounded_fs::read_utf8_path_capped` (`operations_catalog.rs:13`), `vox_jsonschema_util::{compile_validator, validate}` (`operations_catalog.rs:213-231`). **Apply to:** `inputs.rs`, schema checks for the committed index.

### Dependency discipline
No new workspace crate edges needed: `vox-cli -> vox-capability-registry` and `vox-orchestrator-mcp -> vox-capability-registry` already in `contracts/ci/crate-edges.allow.v1.json`. Generator lives in `vox-cli` (not `vox-cli-ci`; that crate lacks the dep and `read_catalog`). If the planner finds a new edge necessary, PROPOSE only; do not edit `crate-edges.allow.v1.json` or `fan-in-snapshot.v1.json`.

### Generated-file hygiene
**Source:** `.gitattributes:75-84`. **Apply to:** add `contracts/capabilities/capability-index.v1.json`, `contracts/reports/graph-coverage.v1.json`, `crates/vox-gui/ui/src/generated/capabilityIndex.generated.ts` with `linguist-generated=true -diff`. Do NOT mark `llms.txt`, `llms-full.txt`, `vox-docs.json` generated (hand-reviewed with generated regions).
