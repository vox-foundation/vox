Write the tests first.

1. Create `docs_claims.rs` with `// vox:defactored-from vox-doc-pipeline 2026-10-08` above the splitter.
   - `pub(crate) fn split_frontmatter(content: &str) -> Option<&str>`: normalize CRLF first. The content must start with a line exactly `---`; the frontmatter ends at the next line that is exactly `---`.
   - `pub(crate) struct PageMeta { title: Option<String>, description: Option<String>, capabilities: Vec<String> }`, parsed with serde_yaml. Any parse failure gives None, so the page is silently skipped (Pitfall 10).

2. `inputs.rs`: add `doc_pages: BTreeMap<String, PageMeta>`.
   - Walk `docs/src/**/*.md` in sorted order. Skip any path under `docs/src/archive/` before reading it. Use bounded reads and store `/`-separated repo-relative paths.
   - Keep pages that claim at least one capability, plus the five pinned targets.
   - Per Pitfall 11 the doc set is opt-in. Do not add unclaimed pages, so ordinary docs PRs do not drift the index.
3. `nodes.rs`:
   - For each claiming page, validate every claimed id against the set of row ids. An unknown id is an Err naming the page path and the id.
   - Append `DocLink { path, origin: "claim" }` to each claimed row, after its default link. Keep the docs list deduplicated and in a stable order.
   - Emit `doc.<path>` rows for claiming pages and pinned targets:
     - title: frontmatter title or the path; summary: description, single-lined via the existing sanitizer
     - domain "docs"
     - docs: [{path, origin "claim" or "pinned"}]
     - refs: claimed ids, sorted
     - owner, coverage and gui: null
   - Claimed ids are only ever compared against row ids, never joined into a filesystem path.
4. Add `capabilities: [cli.secrets, crate.vox-secrets]` to the frontmatter of docs/src/reference/secrets-ssot.md. Keep it valid YAML.
