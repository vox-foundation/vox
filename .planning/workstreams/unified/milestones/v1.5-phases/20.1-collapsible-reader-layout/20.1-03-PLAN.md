  <name>Task 1: Dynamic Article Width and Breakout Styling</name>
  <action>
    In `docs-astro/src/styles/reader-layout.css`, add rules for dynamic article expansion:
    1. Grid and width adjustments:
       - Default `--sl-content-width: 48rem;`
       - Single sidebar folded (`html[data-sidebar-state="collapsed"]`, or `html[data-toc-state="hidden"]`):
         - `--sl-content-width: 60rem;`
       - Both sidebars folded (`html[data-sidebar-state="collapsed"][data-toc-state="hidden"]`):
         - `--sl-content-width: 74rem;`
    2. Readable prose line length:
       - `.sl-markdown-content > p, .sl-markdown-content > ul, .sl-markdown-content > ol`:
         - `max-width: 75ch;`
    3. Wide content breakout:
       - `.sl-markdown-content table, .sl-markdown-content .expressive-code, .sl-markdown-content pre, .vox-playground`:
         - `max-width: 100%;`
         - `width: 100%;`
         - Allow horizontal scroll inside code blocks / tables if content exceeds container, preventing page-level overflow.
  </action>
