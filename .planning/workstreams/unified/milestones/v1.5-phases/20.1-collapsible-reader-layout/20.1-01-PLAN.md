<task>
  <name>Task 3: reader-layout.css Left Rail & Hover Expansion Rules</name>
  <action>
    Create `docs-astro/src/styles/reader-layout.css` with:
    1. CSS variables:
       - `--vox-sidebar-rail-width: 3.5rem;`
       - `--vox-sidebar-expanded-width: 18.75rem;`
    2. Desktop styling (`@media (min-width: 50rem)`):
       - `html[data-sidebar-state="collapsed"]`:
         - Set `--sl-sidebar-width: var(--vox-sidebar-rail-width);`
         - Set `--sl-content-inline-start: var(--vox-sidebar-rail-width);`
         - Style `.sidebar-pane` in collapsed mode to hide text labels and show compact rail styling.
         - `@media (hover: hover)`: `.sidebar-pane:hover`, `.sidebar:focus-within .sidebar-pane`:
           - Position fixed overlay: `width: var(--vox-sidebar-expanded-width);`
           - Box shadow: `0 4px 20px rgba(0, 0, 0, 0.25);`
           - `z-index: 25;`
           - Smooth transition on width and box-shadow.
    3. Touch and mobile safety:
       - `@media (hover: none)`: Do not apply hover overlay expansion.
       - Mobile viewports (< 50rem): Retain Starlight's default slide-over drawer unchanged.
    4. Accessibility & reduced motion:
       - `@media (prefers-reduced-motion: reduce)`: Disable all transitions.
  </action>
