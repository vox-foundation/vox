<objective>
Make the facet schema one artifact that every consumer derives from (TAX-02, D-02): the Rust types generate a committed JSON Schema guarded by a golden test, and the GUI TypeScript facet type is generated from that committed file with a drift check wired into `vox ci ssot-drift` and a vitest/typecheck check on the TS side.

Purpose: ROADMAP success criterion 2 (lint, indexer and GUI types derive from one schema; a drift test fails when any consumer diverges). The lint and indexer use `vox_kb_facets::Facets` directly (compile-time single source); the GUI cannot, so it gets a generated type with two independent drift checks.
Output: the schema JSON, the golden test, a hand-written closed-shape JSON-Schema-to-TS renderer in vox-cli-ci, the generated TS file, CLI flag, ssot-drift and ssot-regen wiring, and a vitest.
</objective>

## Decisions applied

- **D-02 (reversible):** committed generated JSON Schema + golden test; the GUI TS type is generated from the committed JSON file, so vox-cli-ci needs no `vox-kb-facets` edge. Runtime-only validation is not used.
- **Discretion:** the renderer is hand-written for the closed shape the schema actually has (string, boolean, string enum, array, `$ref` object, nullable) and fails on anything else; no npm dependency is added (Ponytail: no new dependency for a small renderer).
