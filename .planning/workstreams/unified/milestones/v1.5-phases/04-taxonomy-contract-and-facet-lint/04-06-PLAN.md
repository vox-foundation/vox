## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client query -> expand_query -> Tantivy | untrusted query text meets a parser |
| repository taxonomy file -> search | a missing or broken contract must not fail searches silently or wrongly |
| doc frontmatter -> card chunk | facet values from any doc become indexed text |
