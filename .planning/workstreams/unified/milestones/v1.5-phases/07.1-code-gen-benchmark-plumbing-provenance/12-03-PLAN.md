<objective>
Make local MENS generation reproducible and make `vox mens eval-local` report unbiased pass@k (BENCH-02; D-03, D-12).

Purpose: today the Candle plugins sample with an unseeded `thread_rng()`, `vox mens serve` drops any seed or top_p a client sends, and eval-local draws exactly one sample while labelling the result pass@k. A MENS row cannot be reproduced and its pass@k is the any-sample rate. This plan plumbs seed and top_p from the serve request to the sampler (metal and CUDA, same change, so no CUDA deviation is recorded) and replaces the single-sample path with an n-sample loop scored by `vox_eval::corpus_score::pass_at_k`.
Output: seeded, nucleus-capable samplers in both plugins; a seed/top_p-carrying serve chain; an eval-local `--k` flag and unbiased aggregation.
</objective>
