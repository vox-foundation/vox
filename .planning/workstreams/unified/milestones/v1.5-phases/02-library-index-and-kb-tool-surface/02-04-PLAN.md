<objective>
Make reindexing incremental and self-describing: skip unchanged files by hash, prune deleted/renamed docs and orphaned `kb_chunk` embeddings, record the build manifest and per-file errors in `kb_index_state`, detect DB↔Tantivy divergence, and add the vox-db readers the MCP tools need. The lexical-leg decision stays pinned by Phase 1's engine probe, which this plan requires and re-runs (no duplicate probe).

Purpose: IDX-01 (incremental + no orphans), IDX-03 (manifest), the data half of IDX-05 (`vox kb status` fields), IDX-07 (backend recorded, probe kept honest). Phase 5 keys vectors by `chunk_hash`, so orphan-freedom is tested now with seeded vectors (AP-07: no embedder in this phase).
Output: vox-db prune/manifest/reader ops, `library::status`, `lexical::default_index_dir`, IDX-01/IDX-03 integration tests, store tests.
</objective>
