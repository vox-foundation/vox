<objective>
Make KB content addressable as MCP resources: `kb://doc/{path}` and `kb://chunk/{hash}`, listed for discovery and read through the same `vox_kb_get` handler the daemon serves, so the stdio server needs no DB of its own. Prove the external-host path (stdio proxy → daemon) for the KB tools with the real in-process daemon harness.

Purpose: RET-01 resources half; RET-01c daemon routing. One code path for tools and resources (AP-15, AP-17).
Output: `kb_resources.rs`, server wiring, URI validation (mutation-proven), daemon routing tests.
