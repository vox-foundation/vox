# Phase 65 Plan 01: Real-Time `Stream[T]`, `Channel[Send, Recv]` & Reactive `db.Table.subscribe` (`STREAM-01..02`)

## Objective
Implement `Stream[T]` (SSE with `Last-Event-ID` replay, `CC-02`), `Channel[Send, Recv]` (typed WebSocket channel, `CC-00`), and `db.Table.subscribe(...)` (`A13-04`) bridged directly to `crates/vox-actor-runtime/src/subscription.rs` with reactive TypeScript `useQuery` delta invalidation.

## Tasks
1. **Sequenced `Last-Event-ID` Replay in `SubscriptionManager` (`STREAM-01`)**:
   - Add `SequencedStreamEvent { id: u64, channel: String, data: String }`, `publish_sequenced`, and `replay_since(channel, last_event_id)` in `crates/vox-actor-runtime/src/subscription.rs`.
2. **`HirDbTableOp::Subscribe` & Axum SSE/WebSocket/Table-Subscribe Emission (`STREAM-01`, `STREAM-02`)**:
   - Add `HirDbTableOp::Subscribe` to `crates/vox-compiler/src/hir/nodes/stmt_expr.rs`.
   - Implement `emit_realtime_stream_and_channel_routes(module: &HirModule) -> String` in `crates/vox-codegen/src/codegen_rust/emit/http.rs` emitting `/api/stream/<name>` (SSE + `Last-Event-ID` replay), `/api/channel/<name>` (WebSocket `Channel[Send, Recv]`), and `/api/subscribe/<table>` (SSE table invalidation stream).
3. **Reactive TanStack Query Hook Emission (`STREAM-02`)**:
   - Extend `vox_tanstack_query_tsx()` in `crates/vox-codegen-ts/src/tanstack_query_emit.rs` with `useVoxReactiveTableQuery` (auto-invalidates `queryKey` on `/api/subscribe/${table}` SSE events) and `useVoxEventStream`.
