# Plan 67-02: Partial `db.Table.patch`, `db.bucket` Aggregations & Multi-Tenant Row Scoping (`USERDB-02..04`)

## Goal
Emit partial column updates (`patch`), declarative `bucket_count` / `join_where` aggregations, and tenant-scoped (`all_for_tenant`, `patch_for_tenant`) queries on generated `.vox` table structs.

## Files
- `crates/vox-codegen/src/codegen_rust/emit/tables/codegen.rs`

## Tasks
1. Emit `pub async fn patch(db: &Codex, id: <pk>, patch_fields: &serde_json::Map<String, serde_json::Value>) -> Result<usize, turso::Error>` so partial field updates never clobber untouched columns (`USERDB-02`).
2. Emit `pub async fn bucket_count(db: &Codex, column: &str, limit: usize) -> Result<Vec<(String, i64)>, turso::Error>` (`USERDB-02` `db.bucket` parity).
3. Emit `pub async fn all_for_tenant(db: &Codex, tenant_val: &str) -> Result<Vec<Self>, turso::Error>` and `pub async fn patch_for_tenant(...)` when a table has a tenant scope column (`tenant`, `tenant_id`, `workspace_id`, or `scoped_by`) (`USERDB-03`).
4. Verify with unit tests in `tables::codegen::tests` (`USERDB-04`).
