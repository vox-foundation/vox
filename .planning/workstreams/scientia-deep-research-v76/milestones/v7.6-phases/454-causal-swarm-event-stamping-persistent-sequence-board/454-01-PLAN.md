# Plan 454-01: L0 Causal Swarm Stamp, Persistent `#seq` Board, `0 tok/s` Parking & Zero-Token Watchdog (`CONC-01`, `CONC-02`, `CONC-04`)

## Objective
Stamp canonical W3C `traceparent` + `#seq` + hybrid compute/lock/workspace metadata across all swarm envelopes, implement the append-only `#seq` Shared Sequence Board with `@mention` doorbell wakeups and `0 tok/s` parked actors across `BulletinBoard` and `VoxDb`, and wire the deterministic zero-token Rust watchdog.

## Tasks

1. **Pure L0 Causal Swarm Types (`CONC-01`):**
   - Create `<400`-LoC `crates/vox-orchestrator-types/src/concilium.rs` (re-exported in `lib.rs`) defining `ComputeTier` (`CloudBandit`, `LocalMensGpu`, `PopuliQuicPeer`, `InlineCpu`), `SwarmWorkspaceMode` (`Inherit`, `Share`, `Branch`), `CausalSwarmStamp`, `SequenceBoardEntry`, `SequenceBoardFilter`, `ParkedWorkerRecord`, `ConciliumSpanBar`, `ConciliumAgentLane`, `HybridComputeNodeCardDto`, `FileLockCellDto`, `ConciliumSnapshotDto`, and `PopuliPlacementDto` (pure `serde`, zero async/IO).
   - Add `#[serde(default, skip_serializing_if = "Option::is_none")] pub causal_stamp: Option<CausalSwarmStamp>` to `AgentEvent` (`events.rs`), `DbA2AMessage` (`a2a/envelope.rs`), and `RemoteTaskEnvelope` (`a2a/envelope.rs`), plus `AgentParked`, `AgentWoken`, `AgentComputeSwapped`, and `SequenceBoardPosted` variants on `AgentEventKind`.

2. **Persistent `#seq` Shared Sequence Board & `0 tok/s` Doorbell Wakeups (`CONC-02`):**
   - Extend `BulletinBoard` (`bulletin.rs`) with monotonic `AtomicU64` `#seq` allocation, bounded `RwLock<VecDeque<SequenceBoardEntry>>` (`512` entries), `extract_mentions(text: &str) -> Vec<String>` (`@agent`, `@all`, `@#channel`), `park_worker` / `wake_worker` (`0 tok/s` parked registry with `tokio::sync::Notify` doorbell), `post_board_entry(...) -> SequenceBoardEntry` (waking any parked worker matching `@agent`, `@all`, or `@#channel`), and `read_board(&SequenceBoardFilter) -> Vec<SequenceBoardEntry>`.
   - Add `append_concilium_seq_entry` and `read_concilium_seq_board(repository_id, since_seq, seqs, channel, limit)` on `VoxDb` in `crates/vox-db/src/store/ops_a2a.rs` storing JSON-serialized `SequenceBoardEntry` rows in `a2a_messages` (`msg_type = "concilium_seq_board"`, `priority = seq as i64`).

3. **Zero-Token Rust Watchdog (`CONC-04`):**
   - Create `<400`-LoC `crates/vox-orchestrator/src/concilium_watchdog.rs` (exported in `crates/vox-orchestrator/src/lib.rs`) evaluating `CircuitBreakerState`, `AttentionBudget`, lease TTL staleness, and `FileAffinityMap` lock contention, posting zero-token structured `#seq` alerts onto `BulletinBoard` and emitting `@monitor` mention ONLY when deterministic recovery rules trip (`TripReason` or stale exclusive file lock).
