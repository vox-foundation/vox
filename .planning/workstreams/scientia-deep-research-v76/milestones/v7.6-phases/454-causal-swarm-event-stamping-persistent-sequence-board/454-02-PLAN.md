# Plan 454-02: Pilot Steering RPCs (`/api/v2/concilium/*` + `vox-gui` `mission_control` Proxy) (`CONC-03`)

## Objective
Expose live operator pilot interventions (`park_agent`, `steer_agent`, `fork_agent`, `swap_agent_compute`) and unified read snapshots (`snapshot`, `board`, `placement`) over `/api/v2/concilium/*` in `vox-orchestrator-mcp` and `daemon`-class Tauri commands in `vox-gui::commands::mission_control` (`0` `VoxDb` handles in `vox-gui`).

## Tasks

1. **HTTP Gateway `/api/v2/concilium/*` Endpoints (`vox-orchestrator-mcp`):**
   - Create `<400`-LoC `crates/vox-orchestrator-mcp/src/http_gateway/concilium_api.rs` and mount in `crates/vox-orchestrator-mcp/src/http_gateway/mod.rs`:
     - `GET /api/v2/concilium/snapshot` -> `ConciliumSnapshotDto` (hydrating live orchestrator agents, causal swimlane spans, `#seq` watermark, `0 tok/s` parked workers, and wakeup arcs)
     - `GET /api/v2/concilium/board` -> `Vec<SequenceBoardEntry>` (`?since_seq=&seqs=&channel=&limit=`, merging durable `VoxDb` `a2a_messages` `#seq` rows with live `BulletinBoard` ring)
     - `GET /api/v2/concilium/placement` -> `PopuliPlacementDto` (hydrating Local Host MENS GPU, Populi QUIC Peer `iroh` nodes, Cloud Bandit Router arms, docked `@agent` pills, and `FileAffinityMap` Lock Matrix)
     - `GET /api/v2/concilium/action` & `POST /api/v2/concilium/action` (supporting both loopback `API_V2_GET` query-encoded pilot dispatch and authenticated `POST` JSON bodies for `park_agent`, `steer_agent`, `fork_agent`, and `swap_agent_compute`, broadcasting `concilium.delta` over `topic_tx` / `/v1/ws` and emitting `AgentEvent`).

2. **Zero-`VoxDb` `vox-gui` `mission_control` Tauri Proxy (`crates/vox-gui/src/commands/mission_control.rs`):**
   - Add typed `daemon`-class Tauri commands (`concilium_snapshot`, `concilium_board`, `concilium_placement`, `concilium_pilot_action`) in `crates/vox-gui/src/commands/mission_control.rs` (`<400` LoC) using `BackendCalls::api_v2_get`, and register them in `axis_invoke_handler!` (`crates/vox-gui/src/main.rs`).
