## Findings & Fixes Applied (`--fix`)

### 1. Correctness & Edge Cases
- **Board tail truncation (`concilium_board.rs`, `ops_a2a.rs`, `concilium_api.rs`):** Fixed `read_board`, `read_concilium_seq_board`, and `get_concilium_board` when `since_seq` is `None` and `seqs` is empty so they return the latest `limit` (clamped `1..=512`) entries in ascending `#seq` order instead of freezing on the oldest slice (`1..=50`). Clamped `seq` / `since_seq` DB binds to `i64::MAX`.
- **False channel-wide wakeups & lane metadata clobbering (`concilium_board.rs`):** Removed woken worker keys from `parked_channels` upon dispatch, restricted `@#channel` matching to workers actually parked on that channel (removed unconditional `Self::normalize_channel(raw) == norm_ch` wakeup), bounded `lane.spans` to `MAX_LANE_SPANS = 64`, and prevented `park_worker` with a numeric `agent_id` from clobbering an existing `lane.roster_name`.
- **Pilot action validation & mention parsing (`pilot_actions.rs`, `pilot.rs`, `concilium_impl.rs`):** Added early non-empty `agent_id` validation across client (`concilium_impl.rs`) and board/API handlers (`pilot_actions.rs`, `pilot.rs`). Updated directive mention matching to trim input and use `Self::extract_mentions` rather than substring `.contains`, rejected self-forks (`fork_name == agent_id`), auto-disambiguated `{key}-fork-N` names, preserved existing `lane.model_id` when `SwapAgentCompute` omits `target_model_id`, returned `bad_request` in `execute_pilot_action` when `!res.ok`, normalized `channel`, and emitted `CausalSwarmStamp` via `emit_stamped` on pilot action events.
- **Deadlock watchdog contention blindspot (`concilium_watchdog.rs`):** Fixed `evaluate_watchdog_pure` to trip when `cell.exclusive && (cell.contended || cell.waiters.len() >= waiter_threshold)` so `contended: true` with an empty `waiters` list (as emitted by `placement.rs` `deadlock_check()`) wakes `@monitor`, with `agent_id` fallback when `roster_name` is blank.

### 2. Security & Auth Isolation
- **Cross-site `GET` CSRF guard (`concilium_api.rs`):** Added `Sec-Fetch-Site` validation on `get_concilium_action` (requiring header absence, `same-origin`, or `none`) alongside existing loopback/token write guards, verified by `concilium_action_enforces_write_token_and_blocks_cross_site_get`.
- **UI architecture isolation (`mission_control.rs`, `concilium_impl.rs`):** `vox-gui` accesses Concilium and Populi state strictly via daemon RPC/HTTP; added `mission_control_has_zero_direct_vox_db_handles` (scanning production source prior to `\n#[cfg(test)]`) and `concilium_commands_route_through_api_v2_without_vox_db` to enforce zero direct `VoxDb` handles.

### 3. LoC, Entity Budget, & `toestub` Hygiene
- Split `apply_pilot_action` out of `concilium_board.rs` (previously `455` non-blank LoC -> `arch/god_object`) into `bulletin/pilot_actions.rs` (`292` LoC) and moved inline unit tests to `bulletin/concilium_board_tests.rs` (`67` LoC).

- Added `Phase 454` doc comments across `pub fn` items to satisfy `doc/missing-adr-citation` and resolved `ai-laziness` / `skeleton/untested-pub-api` lints on Concilium modules.
