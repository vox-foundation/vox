## Executive Summary

Vox Axis v7.3 achieved structural visual unification across its Romanesque Carrara-marble / gilded-brass design language (`RomanSurfaceHeader`, `DiegeticFxStage`, `cvFlywheel.ts`), yet live inspection of `crates/vox-gui/ui/src/` reveals **four concrete gaps** separating v7.3's visual shell from a genuinely functional, high-craft desktop control plane:

1. **Paper-Code Controls, Passive Gauges, Type-Cast RPC Bugs & Demo Fallbacks:**
   - **~65 `<RomanBrassGauge>` `<button>` elements** (`components/ui/RomanTooltip.tsx:324-331`) render across 25+ surfaces with zero `onClick` handlers, and **7 surfaces pass hardcoded magic ratios/strings** (`ModelsView.tsx:129-131`, `DiscoverySurface.tsx:68-72`, `SubAgentsView.tsx:116`, `CommandCardsView.tsx:120-124`, `Mercatus.tsx:80`, `MeshView.tsx:186`, `HarnessHealthView.tsx:94,121`).
   - **`HarnessRiverPanel.tsx`** contains **7 client-only/fake controls**: an unread `timeWindow` `<select>` (`:67,:374`), local-only `Verification Gate` (`:68,:395`), local-only `Sluice Gates I–IV` & `Flush Sluice Gate` (`:69-74,:437-495`), a hardcoded `'Compacted Context Reservoir (64% → 38% occupancy)'` fake receipt (`:507-516`), an infinite `+250 XP` local counter (`:517-527`), a broken `handleJump('operations')` route (`:245`), and hardcoded `<LudusSandbox energy={80} maxEnergy={100} />` (`:547`).
   - **`ImperiumInspector.tsx`** has **two broken RPC argument casts** on `vcsCheckpointCapture` (`:805-811`) and `vcsCheckpointRestore` (`:851-854`), a local-only `Approve` button in `PRAETORIVM` (`:679-688`), and an unhydrated `modelSlider` (`:67,:427`).
   - **`LudusSandbox.tsx`** has a client-only `Pin Context` (`:2767-2789`) that never calls `set_session_context_pins` and an infinite local `+50 XP · +8 Denarii` `Yield` counter (`:2832-2841`).
   - **`HudPanels.tsx`** dispatches **3 non-existent `viewKey`s** (`'vox-cost-analytics'` at `:98,:179`; `'vox-Ludus-view'` at `:116`; `'vox-operations-hub'` at `:214`).
   - **`ContextWindowMeter.tsx:62-66`** fabricates token slice splits (`0.18`, `0.32`, `0.28`) and fake KV cache hit percentages (`92% / 74% / 86%`).
   - **`SessionInteropModal.tsx:29-32,108` & `t3Wave3Rpc.ts`** retain hardcoded demo session IDs (`'claude-session-1'`, `'gsub_demo_1'`) and silent `catch {}` blocks that return fabricated Rust diffs, fake git OIDs, and `500 BU` battery balances even when `backendAvailable() === true`.

2. **50+ Files Still Rendering Raw Emojis & Unicode Dingbats:**
   - Playwright's `audits.ts:269-281` missed these because `coreEmojiRe` skipped `U+1F512` (`🔒`), explicitly exempted `[data-testid="urbs-imperium-inspector"]` (`:277`), scanned only `button, h1, h2, h3`, and ignored `U+2600..U+27BF` / `U+25A0..U+25FF` / `U+2190..U+21FF` plus `<canvas>` `fillText` calls (`worldRenderer.ts`, `hydraulicNetwork.ts`).

3. **28 Raw Native `<select>` Dropdowns & 5 Raw `<input type="range">` Sliders:**
   - Native OS dropdown chrome and browser range tracks clash visually with Carrara marble tablets and lack tactile feedback, keyboard search, and precision detents.

4. **High-Whitespace / Generic CRUD Layouts Across Secondary Surfaces:**
   - `populi` and `oratio` share a generic 2-card `<pre>` stdout dump (`CommandCardsView.tsx:168-249`) with hardcoded static banner strings; `Catalog` (`CommandCatalogForm.tsx:140-240`) uses a fixed `w-72` non-searchable list and a single `max-w-md` column leaving >50% dead right-hand whitespace; 8+ master-detail views lack `react-resizable-panels` splitters.

### Anti-Features (Commonly Requested, Often Problematic)

Features and patterns to explicitly **refuse** in Milestone v7.4 so scope stays sharp and architectural honesty remains intact.

| Anti-Feature | Why Requested | Why Problematic | Alternative |
|--------------|---------------|-----------------|-------------|
| **Synthetic "Demo" Telemetry When Backend Is Idle** | Empty charts or `0 tok/s` gauges look quiet on a fresh workspace before any agent task runs. | Directly violates Vox's Zero-Deception Mandate (`honestyScan.ts`). Fake curves or hardcoded `ratio: 0.78` lie to the operator and mask broken daemons. | Show honest zero/idle baselines (`0 tok/s · Idle`) paired with a **1-click live action trigger** inside the Bento card (e.g., `"Run Smoke Probe"`, `"Scan Workspace"`, `"Open Loquela Composer"`). |
| **3D WebGL / Three.js Skeuomorphic Knobs or Heavy Physics Shaders** | Tempting when building "tactile Romanesque brass knobs and sluices." | Bloats bundle size by >600 KB, competes with `LudusSandbox` 2D canvas and `DiegeticFxStage` GPU compositing, and hurts accessibility/keyboard control. | Crisp, layered **2D SVG + CSS conic/linear metallic gradients + PointerEvents** (`RomanRotaryKnob`) — <4 KB, 60 fps, crisp at any DPI, native ARIA `role="slider"`. |
| **Rotary Knobs for Unbounded Text/High-Cardinality Numeric Inputs** | Applying rotary knobs everywhere once `RomanRotaryKnob` exists. | Dragging a rotary dial across `1..3650` days or token limits `1024..200000` is imprecise and frustrating. | Use `RomanRotaryKnob` strictly for **bounded ratios, percentages, temperatures, weights, and 3–7 position detents** (`0.0–2.0`, `0–100%`, `0x/1x/3x`). Pair any wide-range dial (like Graph TTL) with a direct numeric input badge. |
| **Unicode Typographic Hacks (`▸`, `▾`, `✕`, `●`, `◆`, `✎`, `⚙`) Instead of `<Icon.*>`** | Fast to type inline inside JSX strings (`<span>Lens & Layout ▾</span>`). | Renders with uneven baseline metrics across Segoe UI / SF Pro / Noto Sans, fails screen-reader semantics unless manually `aria-hidden`, and blurs the zero-emoji enforcement boundary. | Enforce **100% `<Icon.*>` / `lucide-react` SVG components** for every directional chevron, close cross, status dot, and action glyph across JSX and `<canvas>` `Path2D` helpers. |
| **Second Competing Tiling Window Manager Inside Non-Chat Surfaces** | `ChatSurface` already uses `dockview@6.6.1`, tempting full freeform docking on every CRUD page. | Nested `dockview` grids inside `AppShell` create tab-bar inception, confusing persistence bugs, and excessive chrome overhead on 2-pane surfaces. | Keep `dockview` where multi-document tabs make sense (`ChatSurface`) and use lightweight **`react-resizable-panels` (`<Group>` / `<Panel>` / `<Separator>`) + `@container` Bento grids** on the remaining 32 surfaces. |
