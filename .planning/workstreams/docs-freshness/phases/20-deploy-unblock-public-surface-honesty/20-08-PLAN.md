  <action>
    1. `resolveDocLink(url, fromFile, ctx)` where `ctx = { repoRoot, docsSrc, repoUrl, strict }`. Return `{ href }` to rewrite, `null` to leave untouched, or throw. Leave untouched: URLs with a scheme, protocol-relative, `#…` only, site-absolute `/…`, `mailto:`. Otherwise split off `#fragment`, then a trailing `:N` / `:N-M`; decodeURI; resolve against `dirname(fromFile)`. If the resolved path is inside `docsSrc`, not under `archive/`, and is `.md`/`.mdx`: href = `/` + docSlug(rel) + `/` (root index → `/`) + fragment. Missing target → throw when `strict`, else `console.warn` and return null. (Out-of-tree and non-Markdown branches come in Task 2; until then return null for them.)
    2. `remarkDocLinks(options)`: returns a transformer that realpaths `file.path` (since 20-12 the content dir is a mirror of per-entry symlinks into docs/src), walks the tree manually (recursion over `children`), and rewrites `url` on `link` and `definition` nodes. `strict` defaults to true for files whose realpath is inside docs/src and not under `docs/src/archive/` (defence in depth: 20-12 already stops building the archive, and its links are never repaired).
    3. Register in astro.config.mjs `markdown.remarkPlugins` after `remarkVoxInclude`, with `repoRoot` and `repoUrl: 'https://github.com/vox-foundation/vox'`.
    4. Unit tests for the in-docs cases: `foo.md`, `../reference/cli.md#vox-init`, `./index.md`, `README.md` in a subdir (→ that directory's README route, which is `<dir>/readme/` per docSlug — confirm against the built page), `.mdx`, external URL untouched, `#anchor` untouched, missing target throws with the source file and URL in the message.
    5. `links.spec.ts`: `dist/tutorials/tut-getting-started/index.html` contains `href="/reference/installation/"` and no `href` ending in `.md`. (The whole-site zero-`.md`-href assertion lands in Task 3, once out-of-tree links are handled.)
  </action>
