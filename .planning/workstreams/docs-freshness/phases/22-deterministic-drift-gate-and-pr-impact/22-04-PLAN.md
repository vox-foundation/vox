<action>
1. Create `contracts/documentation/tutorial-execution-results.v1.schema.json` specifying schema for tutorial execution results (tutorial slug, status, duration, executed steps, outputs).
2. Implement `scripts/docs/tutorial-test-runner.vox`:
   - Inspects `docs/src/tutorials/*.md`.
   - Extracts executable steps:
     - Shell commands (`bash`, `sh`, `console`).
     - File creation fences (files specified with destination path comment like `# filename: src/main.vox`).
   - Sets up an isolated sandbox in `target/tmp/tutorial-sandbox/<tutorial_name>/`.
   - Executes commands sequentially using `process::spawn` with timeouts (30s per step, 120s per tutorial).
   - Validates command exit codes and expected outputs.
   - Writes `contracts/documentation/tutorial-execution-results.v1.json`.
3. Support CLI flags:
   - `--tutorial <name>`: run a single tutorial.
   - `--check`: verify results without re-running if results are fresh.
   - `--all`: run all tutorials.
</action>
<verify>
`vox run --mode interp scripts/docs/tutorial-test-runner.vox -- --tutorial tut-first-app` succeeds.
</verify>
</task>
