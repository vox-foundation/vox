## Decisions applied

- **D-01 (costly):** facet types, eligibility and loaders live in the new L0 crate; no workspace-crate dependency except `workspace-hack`.
- **D-05 / D-06 (costly):** one `effective_training_eligible`; a page with no `authorship` keeps the flag default `true`.
- **D-08 (one-way, already user-decided):** markers `<!-- kb:summary -->` / `<!-- /kb:summary -->`, 40-120 words inclusive. The rating is recorded on Task 2; no new checkpoint because the user already chose these exact markers.
- **D-09:** the three exceptions entries are pre-authorized and are written in this plan together with the edges, with `authorized_by: "user (explicit chat approval, 2026-10-10)"`.
- **Discretion, sources[] shape:** `hash` is `blake3:<64 lowercase hex>` (same form as `kb_findings.content_hash`), `date` is ISO `YYYY-MM-DD` (the UTC date of `fetched_at_ms` at promotion), `url` is `source_url`. All `Source` fields are `Option<String>` so a missing field is a precise lint error, not a parse error.
- **Discretion, quote cap:** unit is whitespace-split words; a quote is one contiguous Markdown blockquote run outside fences or one `sources[].quote` string; cap 50 words per quote and 200 words per page; applied to `origin: web-promoted` pages only (the lint applies it in 04-05).
- **Discretion, enum values:** `kb_tier` = which collection (`vox` docs vs general `library`), `scope` = `vox-internal | external` (research SUMMARY line 101), `sensitivity` = `public | private` (Phase 7 egress check reads `private`), `trust_tier` reuses the `ContextTrustTier` wire strings.
