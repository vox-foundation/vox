    - Golden unchanged: a head metric lower than base is Err; equal or higher is Ok; head tolerance > base tolerance is Err; head missing a key present at base is Err; changed budget_tokens or token_estimator is Err.
    - Golden changed: head.epoch ≤ base.epoch is Err; an empty epoch_note, or one equal to base's, is Err; with a bumped epoch and a new note, lower values are Ok; tolerance raised is still Err.
    - tightened(baseline, report) never lowers any value, and raises each value to max(baseline, report).
    - new_epoch(None, report, "note") gives epoch 1 with tolerance 0.01. new_epoch(Some(prev), ..) gives prev.epoch + 1 and keeps prev.tolerance. An empty note is Err. A report lacking `dev/human` is Err.
    - ratchet_split() == Split::Dev.
    - Baseline JSON round-trips byte-identically; unknown fields are rejected.
  </behavior>
