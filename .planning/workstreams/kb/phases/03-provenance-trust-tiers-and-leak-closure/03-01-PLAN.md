## Decisions applied

- **D-06 (taint rule, accepted default):** an LLM synthesis of Untrusted input is Untrusted, not Advisory. Encoded in `tier_for_knowledge_node_type` and in the module doc. Advisory is reserved for agent output grounded only in curated inputs.
- **Reversibility:** the db strings become stored data in 03-03; the D-01 sign-off (pre-approved, see 03-CONTEXT.md) covers that schema. No checkpoint here.

## Flagged assumptions

- **Edge probe row TRUST-06 / unclassified (status: unresolved).** The probe could not classify an edge category for TRUST-06; it stays unresolved per #1110 and is surfaced here. Planner note: the nearest edges (lookup error, no DOI, retraction) are each pinned by a named test in Task 2.
- An academic-looking URL without a resolvable DOI (for example an arXiv abstract page) is `NotApplicable`, not `Unavailable`: no lookup is possible, so it must not disable promotion (Pitfall 4).
