<objective>
Make every corpus writer require a trust tier at the type boundary, and give Library rows exactly one authoritative tier source.

Purpose: TRUST-01 ("writes without a tier fail to compile"). Phase 2 stored the Library tier per corpus in `kb_index_state.trust_tier` and passed it as a validated wire string through `IndexDeps` / `LibraryDocUpsert`, leaving Phase 3 to type it ("Phase 3 swaps the type", `library.rs:14-15`). This plan types it, writes it onto rows, keeps rows and the corpus manifest in agreement, and pins the writer set with a static test.
Output: typed `IndexDeps.trust_tier` / `LibraryDocUpsert.trust_tier` / `KbIndexState.trust_tier`, the tier column in `apply_library_document`'s own INSERT, row alignment in `put_kb_index_state`, `upsert_search_document(.., tier)` with a compile_fail doctest, every caller threaded, the wire-string validator removed, and the single-writer invariant test.
</objective>
