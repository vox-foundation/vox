<objective>
Make every corpus writer require a trust tier at the type boundary, and give Library rows exactly one authoritative tier source.

Purpose: TRUST-01 ("writes without a tier fail to compile"), and the cross-phase contract with Phase 2 AP-12: Phase 2 records the Library tier per corpus in `kb_index_state.trust_tier` and passes it as a wire string through `IndexDeps`/`LibraryDocUpsert`, leaving Phase 3 to type it "at its single construction site". This plan types it, derives each row's tier from that one value, and pins the agreement with a test, replacing the earlier hard-coded `tier_for_curated(false)`-at-the-indexer plus `library:%` backfill.
Output: typed `IndexDeps.trust_tier` and `LibraryDocUpsert.trust_tier`, row alignment inside `put_kb_index_state`, `upsert_search_document(.., tier)` with a compile_fail doctest, all callers threaded, and the single-writer invariant test.
</objective>
