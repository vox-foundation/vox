## Decisions applied

- **D-06 (DPO-only MENS signals):** DPO pairs only, from rows with `reviewed_by` set and status approved/rejected, paired by the provenance `query`; no SFT from findings (finding text is web or LLM text; TAX-06 forbids training on it without attestation).
- **D-03:** legacy `accepted=1` entries are downgraded to pending Untrusted findings; the old acceptance is preserved in provenance only. Legacy rows are copied, never deleted.
- Migration runs at every `ServerState` DB attach (03-RESEARCH A7): idempotent and near-free at 0 rows. Already-trained MENS data (`mens_queued=1` rows exported as SFT) cannot be recalled; 03-13 records this in the CHANGELOG.
