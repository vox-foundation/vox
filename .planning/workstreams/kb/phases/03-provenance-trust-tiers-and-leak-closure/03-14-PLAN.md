## Decisions applied

- **D-03 / D-05:** the automatic preamble never carries Untrusted text; explicit queries do, labelled. Tavily output is live web text, so it is Untrusted by the TRUST-01 mapping.
- **Preferred CR-01 fix (VERIFICATION gap 1, "missing" item 1):** do not fire Tavily under the exclusion, rather than firing and discarding. This saves credits and keeps the preamble path free of web egress. Consequence: an auto-preamble turn no longer files Tavily findings into the inbox. **D-04** capture is unchanged for explicit queries, and the SearXNG/DDG web leg is already skipped for the preamble (`skip_preamble_web`).
- **WR-08:** derive the flag where the trigger is consumed (`run_search_with_verification`), not in each caller. `retrieval.rs:330` keeps its own assignment. It is now redundant but harmless, and it is not edited here.
- Known behavior change for hosted CI to cover: the `goal.rs` goal-search path now drops Untrusted chunk, knowledge and web lines before CRAG relevance and the Socrates evidence counts. That is the intended WR-08 effect.

## Flagged assumptions

- Hit URLs in `sources_from_hits` are deduped on the raw path before sanitizing (unchanged). Two URLs that differ only in invisible code points collapse to the same visible string but stay separate sources. That is harmless and leaves the existing numbering tests untouched.
- A normal URL is a fixed point of the sanitizer. The existing `context_block_numbers_sources_and_demands_citations` test, which expects `https://a.example/1` verbatim, is the regression check for that.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| live web (Tavily API) to chat preamble | unprompted injection of untrusted third-party text |
