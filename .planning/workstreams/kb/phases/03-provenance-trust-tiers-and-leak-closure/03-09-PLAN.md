Output: tier lookups in vox-db, `SearchPolicy::exclude_untrusted_hits`, tier-labelled lines and `SearchExecution::min_trust_tier`, the derived envelope tier, sanitized bundle / sources / KB-tool output.
</objective>

## Decisions applied

- **D-03 / D-05:** existing Untrusted rows stay queryable by explicit tools (labelled) but are dropped from the automatic preamble now, before Phase 7 spotlighting. Accepted interim regression: chat gets less autonomous web context until Phase 7.
- **D-06:** `research_cache` nodes are excluded from search entirely (a cache, not knowledge); memory-file lines count as Advisory and repository and symbol lines as Trusted for the envelope minimum; web lines are Untrusted.
- `UnifiedHit` gains no tier field here (it is constructed in vox-gui too); per-result tier fields are RET-04 in Phase 5. `unified_hits` entries are filtered together with their lines so the two stay parallel.
