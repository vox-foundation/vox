## Assumptions pending discussion

- **A8 variation selectors:** strip U+FE00–FE0F and U+E0100–E01EF although TRUST-05 does not list them (same smuggling class). Alternative: strip only the REQUIREMENTS ranges.
- **Image allowlist default:** the host allowlist is an empty `const` and relative targets are kept. Alternative: ship a small allowlist (for example the docs site host).
- **Image replacement text:** neutralized images become `(image omitted: <alt>)`, parentheses only, so the replacement cannot form a new link or image. Alternative: drop images silently.
- **Tag-block strip breaks subdivision-flag emoji** (for example England); accepted for KB text.
