### Sampling Rate
- **Per task commit:** touched vitest files (~3 s) and, for Rust edits, the one crate's targeted test.
- **Per wave merge:** `pnpm typecheck`, `pnpm test`, the three palette Playwright specs.
- **Phase gate:** `vox ci capability-index` (verify), `vox ci operations-verify`, `vox ci ssot-drift`, `vox ci crate-edges`, hosted `ui` + `tests` lanes green before `/gsd-verify-work`.
- **Mutation proofs (AGENTS.md, required for security guards):** (1) delete the argv-token walk in `confirmation_required` and watch the bypass test fail; (2) remove the `confirmed != Some(true)` check and watch the refuse test fail; (3) delete one `ROWS_n` chunk join and watch the row-count test fail. Guard each mutation with a before/after presence check.
