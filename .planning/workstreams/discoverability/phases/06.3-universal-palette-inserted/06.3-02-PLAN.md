- vox-gui has no edge to the registry, and must not get one (C-2, AGENTS.md Dependency Discipline).

- Today exactly one CLI row is destructive: `cli.plugin.remove` (path ['plugin','remove']). Plan 06.3-04 classifies more. Tests that use `bundled_index()` must rely only on `cli.plugin.remove` and on read-only `cli.features`.
- Global clap flags such as `--json` are accepted before a subcommand, so a walk that stops at the first flag is bypassable. The gate therefore drops flag tokens and checks whether a destructive row's CLI path appears in order among the remaining tokens. A false positive (a flag value equal to a path token) fails closed: the user just confirms.
- Error-prefix precedent: chat_turn.rs `RATE_LIMITED_PREFIX`. The UI's `LEAK_PATTERN` (/__TAURI_INTERNALS__|\binvoke\b/) must not match the marker. "confirmation_required: cli.plugin.remove" does not.
- Tauri deserializes a missing `Option<T>` argument as None (tauri-2.12.1 ipc/command.rs:146-157). The key is camelCase; `confirmed` is one word.
- Local compile of vox-gui needs the sidecar files and ui/dist (build.rs:92-126). Stub files are `target/release/vox-aarch64-apple-darwin`, `target/release/vox-ml-cli-aarch64-apple-darwin` and `crates/vox-gui/ui/dist/index.html`, all gitignored. Set `VOX_GUI_SKIP_SIDECAR_AUTOBUILD=1`.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.3-06 | Elevation / Tampering | execute_command `__argv` / `__positionals` | high | mitigate | Gate evaluates the built argv. Flag tokens are dropped and the destructive path is matched as an ordered subsequence. Mutation proof 1 shows the walk is load-bearing |
| T-06.3-07 | Tampering | execute_command consent check | high | mitigate | `gate_execution` refuses unless `confirmed == Some(true)`. Mutation proof 2 removes the check and watches the refuse test fail |
| T-06.3-08 | Spoofing | `confirmed` flag is client-supplied | medium | accept | The gate protects against accidental and agent mis-click runs, not a compromised renderer that can send `confirmed: true` itself (RESEARCH Security Domain). A backend-issued nonce is the stronger option, not required by D-03 |
| T-06.3-09 | Tampering | unclassified (null) destructive verbs | medium | mitigate | Plan 06.3-04 classifies the 22 destructive-looking verbs and ratchets null counts. The UI treats null as side-effecting (D-01, plan 06.3-09) |
| T-06.3-10 | Tampering | clap aliases (e.g. a short alias of `remove`) | low | accept | The UI sends canonical catalog paths. An alias spelled by hand in raw args is not in the index and fails open per D-03 "unknown ops are not blocked" |
| T-06.3-11 | Tampering | invoke_mcp_tool (no gate) | low | accept | The palette never runs MCP tools (D-07 shows an explain card). The Catalog form switches to execute_command in plan 06.3-09. MCP destructive tools (snapshot.restore) are noted for 06.4 |
| T-06.3-12 | Injection | sidecar spawn | low | mitigate | Args go through `.args()` (no shell), so injection is limited to `vox` argv. form_argv is unchanged apart from D-16 ordering |
