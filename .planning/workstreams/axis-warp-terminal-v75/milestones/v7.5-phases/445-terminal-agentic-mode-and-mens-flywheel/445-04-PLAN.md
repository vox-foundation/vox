<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `PendingApprovalRow` / `TermBlockDto` → `TerminalApprovalCard` & `BlockCard` | Agent-supplied command strings, markdown output, and error messages rendered into the DOM and toast notifications |
| `credential_prompt === true` blocks → UI action bars (`Explain Failure`, `Fix Command`, MENS feedback) | Interactive password/passphrase blocks where sending or recording block text would leak user credentials |
| Secondary inline inputs (`Edit & Run`, `Reject + Steer`, `Correct`) → `Console` accessibility tree | Dynamic `<textarea>` / `<input>` elements competing with `<textarea aria-label="console input">` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-445-11 | Information Disclosure | `BlockCard.tsx` + `SlashMetaContent.tsx` | critical | mitigate | Hide `Explain / Fix Failed Block` (`term-explain-fix-block`) and the MENS feedback strip (`Accept`/`Reject`/`Correct`) whenever `block.credential_prompt === true` (per D-03, D-08, D-10) |
| T-445-12 | Elevation of Privilege | `TerminalApprovalCard.tsx` | high | mitigate | Render `SAFETY FLOOR GATE` / `CREDENTIAL GATE` pure-ASCII wax-seal signet and disable `Allow Pattern in Session` whenever `Boolean(approval.floor_category)` or `approval.credential_prompt === true` (per D-04, D-05) |
| T-445-13 | Information Disclosure / UI Spoofing | Error toasts & banners across `Console` / `Chat` | medium | mitigate | Pass every backend error through `sanitizeErrorForToast(err)` with `{ tone: 'warn', ..., cause: 'backend-error' }` and render untrusted command/markdown text as React text nodes without `dangerouslySetInnerHTML` (per D-11) |
</threat_model>
