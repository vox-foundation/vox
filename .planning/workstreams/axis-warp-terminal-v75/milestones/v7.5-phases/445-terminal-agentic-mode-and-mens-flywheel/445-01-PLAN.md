## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Terminal `Block` (`Accepted` / `Rejected` / `Corrected`) → `CorpusWriter` & `JournalSink` | Raw terminal inputs, stdout/stderr, `cwd`, and `git_branch` entering persistent JSONL / `vox-journal` storage for MENS training |
| Interactive PTY bytes (`Session::on_pty_bytes`) ↔ Custom `AgentTurn` / `SlashCommand` blocks | Concurrent shell stdout arriving while an async LLM turn is streaming chunks into a block |
| `vox-orchestrator-d` `TermDispatch` RPCs (`term.clear`, `term.compact`, `term.feedback`) | Daemon RPC surface shared between human GUI actions and agent MCP calls |
