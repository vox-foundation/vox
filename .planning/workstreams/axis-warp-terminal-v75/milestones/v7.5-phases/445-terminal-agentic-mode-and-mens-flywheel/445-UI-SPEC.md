## Pillar 1: Visual Hierarchy, Layout Placement & Module Decomposition

### Primary Focal Points Across Agentic Flows
1. **Active HITL Gate Priority (`<TerminalApprovalCard>`)**: When a session has a pending Co-Pilot or `Ask`-tier command approval, `<TerminalApprovalCard>` mounts with burnished brass framing (`border-brass bg-bg-elevated`) and a semantic `<Icon.waxSeal>` wax-seal signet pill (`data-roman-wax-seal="true"`) immediately above `ScriptoriumPromptEditor` in `Console` (`TerminalSessionPane`) and directly inside the active `ChatTerminalBlockCard` in `ChatTranscript` / `TurnTrace`, ensuring the operator sees the exact command, security reason, and 4 actions without scrolling past obscured chrome.
2. **In-Band Streaming Agent Block (`BlockKind::AgentTurn`)**: Submitting `?prompt`, natural-language prose, or clicking `Explain / Fix Failed Block` appends a live `BlockCard` (`kind === 'AgentTurn'`) at the tail of `BlockStreamView`, auto-scrolling into view with a routed model pill (`provider/model_id`), live streaming prose/code, and extracted 1-click runnable command cards (`Run Command` / `Run Fix` + `Edit in Prompt`).
3. **Structured Live Slash Telemetry (`BlockKind::Meta`)**: Submitting `/budget`, `/model`, `/skills`, `/memory`, `/context`, `/clear`, or `/compact` renders a crisp Roman Scriptorium telemetry card (`SlashMetaContent.tsx`) in-band rather than raw unformatted text stubs.
4. **Low-Friction MENS Flywheel Controls**: Completed blocks expose compact right-aligned `Accept` / `Reject` / `Correct` controls in the `BlockCard` footer row, keeping inline text inputs unmounted (`null`) until `Correct` is clicked.

### `< 450` Non-Blank LoC File Decomposition (`D-10` Guardrail)
Every new or modified `.ts`/`.tsx` file MUST stay strictly `< 450` non-blank LoC:
- `Console/AgentTurnContent.tsx` (new, ~175 LoC) — renders `BlockKind::AgentTurn` streaming markdown/code segments (pure React nodes, zero `dangerouslySetInnerHTML`), routed model pill, Clavis unconfigured diagnostic state, and extracted runnable command cards (`Run Command` / `Run Fix` / `Edit in Prompt`).
- `Console/TerminalApprovalCard.tsx` (new, ~210 LoC) — shared Roman Scriptorium wax-seal Co-Pilot / HITL approval card used by both `Console` (`TerminalSessionPane`) and `Chat` (`ChatTerminalBlockCard`), encapsulating `Approve`, `Edit & Run` (lazy-mounted `<textarea>`), `Allow Pattern in Session` (with safety-floor guard), and `Reject + Steer` (lazy-mounted `<input>`).

## Pillar 4: Hard Repo UI Guardrails (Zero-Tolerance Static Gates)

1. **Zero Emojis, Dingbats, Geometric Shapes, Guillemets, or Return Glyphs (`src/guards/zeroEmojiAndDingbat.test.ts`)**:
   - `BANNED_GLYPH_RE` fails CI on any `\p{Extended_Pictographic}`, `\u2600-\u27BF`, `\u23F0-\u23FE`, `\u25A0-\u25FF`, `\u2197`, `\u21BA-\u21C4`, `\u21E2`, `\u2B06`, `\u2302`, `\u2442`, `\u2295`, `\u21B5`, `\u23CE`, `\u21E5` in non-test `.ts`/`.tsx` files. Use `<Icon.*>` (including `<Icon.waxSeal>` inside `data-roman-wax-seal="true"`), `<KeycapIcon>`, and pure 7-bit ASCII punctuation (`-`, `...`) exclusively.
2. **Zero Raw Native `<select>` or `<input type="range">` (`src/guards/noRawNativeControlsGuard.test.ts`)**:
   - Use `<VoxSelect>` from `components/ui/Select.tsx` exclusively.
3. **WCAG 2.5.3 Label-in-Name & Zero Nested Interactive Controls (`axe` `label-content-name-mismatch` & `nested-interactive`)**:
   - Every `<button>` with visible text and an `aria-label` MUST start its `aria-label` with the exact visible text string in BOTH idle and active states (e.g., visible `Approve` -> `aria-label="Approve proposed command"`; visible `Accepted` -> `aria-label="Accepted block for MENS training"`).
   - Never nest `<button>`, `<input>`, or `<textarea>` inside `BlockCard`'s outer clickable container without `e.stopPropagation()` (note `BlockCard` root is a `<div>`, never a `<button>`, so child buttons are valid non-nested interactive controls).
4. **Zero `dangerouslySetInnerHTML`**:
   - `AgentTurnContent.tsx`, `TerminalApprovalCard.tsx`, and `SlashMetaContent.tsx` MUST construct React elements directly; never use `dangerouslySetInnerHTML` or `innerHTML`.
5. **Centralized Transport IPC & Mock Safety (`src/guards/transportIpcGuard.test.ts`)**:
   - All new Tauri commands (`term_agent_prompt`, `term_agent_explain_fix`, `term_slash_exec`, `term_block_feedback`) MUST be wrapped inside the `// __VOX_RAW_IPC_BEGIN__`..`// __VOX_RAW_IPC_END__` region or via existing safe wrappers in `src/transport.ts`, registered in `crates/vox-gui/src/main.rs`, classified under `pty` in `crates/vox-gui/src/remote/gate.rs`, and called in UI code with `typeof transport.fn === 'function'` guards so existing partial mocks in `Console.test.tsx` and `ChatTerminalBlockCard.test.tsx` pass without regression.
6. **Toast & State Error Sanitization (`src/guards/toastBodyGuard.test.ts`)**:
   - Every `catch (err)` surfaced via `pushToast({ body: ... })`, `set*Error(...)`, or inline error banners MUST sanitize `err` through `sanitizeErrorForToast(err)` from `src/lib/backendGuard.ts` — never `String(e)`, `String(err)`, or `String(error)`.
