# Phase 445 — Security

> Per-phase security contract: Threat register & verification audit for Terminal-Native Agentic Mode (`vox_actor_runtime::llm`), Explain/Fix Failed Block, Co-Pilot Command Approval Cards, `Autopilot` Preemption, Live Slash Commands, and MENS Redacted Trajectory Flywheel (`TERM-AGENT-01..04`).

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Terminal Session -> `JournalSink` & `CorpusWriter` | Completed/cancelled blocks and operator verdicts (`Accepted` / `Rejected` / `Corrected`) persist to `.vox/terminal-journal/` and redacted SFT corpus files. | Raw command text, ANSI/OSC output chunks, `cwd`, `git_branch`, `corrected_command`, `original_command`, and potential `credential_prompt` inputs |
| Agent Turn / Slash Output -> `Session` Block Stream | Streaming model turns and slash command summaries attach to the active terminal session alongside live PTY shell blocks. | `BlockId`-addressed custom block chunks, multi-byte UTF-8 fragments, and async agent responses |
| Untrusted / Agent Caller -> `vox-orchestrator-d` (`term.*`) | Daemon JSON-RPC dispatches `term.clear`, `term.compact`, `term.feedback`, and custom block RPCs over loopback IPC. | `session_id`, `origin` (`human` vs `agent`), `block_id`, and verdict strings |
| MCP Agent & GUI Co-Pilot -> `PendingApprovals` & Terminal PTY Execution | Agent shell/PTY tool calls park in `PendingApprovals` and resume with `Approve`, `Edit & Run`, `Allow Pattern in Session`, or `Reject + Steer` across `tasks_core.rs` (`vox_resolve_approval`) and `daemon_extra.rs` (`RESOLVE_APPROVAL`). | Potentially edited shell commands (`modified_command`), leaf session patterns (`allow_pattern`), steering prose (`steering_note`), `floor_category`, and `credential_prompt` flags |
| GUI Console -> `vox_actor_runtime::llm` (`pty/agent.rs`, `pty/approvals.rs`) | `?prompt` prose and failed-block *Explain / Fix* flows discover Clavis/local MENS endpoints and stream context + stderr snippets to the model-agnostic LLM facade. | Operator prompt text, failed command, trimmed stdout/stderr slices (`<= 8 KiB` each), `cwd`, `git_branch`, and streamed tokens |
| Webview IPC -> `commands::pty` Tauri Host Boundary (`main.rs`) | Frontend calls `term_agent_prompt`, `term_agent_explain_fix`, `term_agent_cancel`, `term_slash_exec`, and `term_block_feedback`. | Session IDs, prompt text, slash commands, and feedback verdicts crossing `gate_invoke` (`ModuleClass::Host`) |
| Co-Pilot & Block Data -> Console / Chat React Surfaces & Error Toasts | Approval metadata, agent prose, and rejected IPC errors render in `Console` and `Chat` cards/toasts. | Untrusted command strings, floor/credential metadata, LLM prose, and backend `anyhow`/daemon error messages |
