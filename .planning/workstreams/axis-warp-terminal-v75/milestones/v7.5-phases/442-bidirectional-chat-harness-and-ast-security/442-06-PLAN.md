| Boundary | Description |
|----------|-------------|
| User chat prompt (`@term:...`) → `term_mentions.rs` → outbound LLM prompt (`message.rs`) | Terminal session blocks potentially containing ANSI escape sequences, home paths, tokens, or Clavis secrets injected into LLM prompt context |
| `term_mentions.rs` → `prompt_canonical::canonicalize_prompt` (`message.rs:148-167`) | Prompt safety canonicalizer and research intent classifier (`raw_prompt_for_research` at `message.rs:137`) interacting with expanded terminal blocks |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-442-17 | Denial of Service | `chat_tools/chat/term_mentions.rs` | medium | mitigate | Fast-path return when `!prompt.contains("@term")`, rely on `16 KiB` / head-40/tail-160 per-block truncation from `TerminalBridge`, and enforce `MAX_TERM_PROMPT_ENVELOPE_BYTES = 32_768` across all `@term` citations in a single turn on valid UTF-8 char boundaries |
| T-442-18 | Tampering | `chat_tools/chat/message.rs` (`L118-177`) | medium | mitigate | Strip `@term` tokens into compact `[ref @term:...]` markers before `resolve_mentions_with_rules` (`L118-123`), keep `raw_prompt_for_research = params.prompt.clone()` (`L137`) untouched so terminal text never pollutes web-research queries, and append `<terminal_context>` strictly after `prompt_canonical::canonicalize_prompt(&expanded_prompt, true, true)` (`L148-167`) |
