<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Webview frontend (`transport.ts`) → Tauri IPC (`commands::pty` / `commands::console_a2a`) | Untrusted or remote webview invoke parameters crossing `axis_invoke_handler!` and `remote::gate` |
| `commands::console_a2a` → Agent A2A inbox (`vox_a2a_send`) | Terminal block output and operator notes forwarded to an autonomous LLM agent's durable DB inbox |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-442-14 | Information Disclosure | `commands/console_a2a.rs` (`SendToAgent`) | high | mitigate | Resolve `{ session_id, block_id, line_start, line_end }` on the Rust backend via `"vox_terminal_read"` and apply 3-stage scrubbing (`vox_terminal_core::corpus::redact::scrub_ansi_and_redact` + `vox_secrets::scrub_resolved_secrets`) plus `16 KiB` head-40/tail-160 truncation on both resolved blocks and legacy free-form `send_to_agent` notes before calling `"vox_a2a_send"` (`"route": "db"`) |
| T-442-15 | Elevation of Privilege | `main.rs` (`axis_invoke_handler!` + `remote::gate`) | high | mitigate | Keep PTY session controls in `commands::pty` (`ModuleClass::Host`, denied when Axis is attached to a remote daemon) and `send_terminal_block_to_agent` in `commands::console_a2a` (`ModuleClass::Daemon`, enforcing `CONSOLE_OPERATOR_AGENT_ID = 0` and `parse_receiver` rejecting reserved receiver `0`), verified by `remote::gate` and `console_a2a` unit tests |
</threat_model>
