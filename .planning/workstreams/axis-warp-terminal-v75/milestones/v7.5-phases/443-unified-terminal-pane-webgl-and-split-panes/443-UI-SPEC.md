## Pillar 1: Visual Hierarchy & Dual-Surface Roman Scriptorium Layout (`TERM-PANE-01`)

### Primary Focal Point & 3-Layer Hierarchy
- **Primary Focal Point**: The active `<TerminalSessionPane>` viewport (`data-active-pane="true"`), anchored on either the bottom-most active/focused `TermBlockCard` (in `Blocks` mode) or the live cursor row of the full-bleed xterm canvas (in `ALT_SCREEN` / `Raw VT` mode).
- **Layer 1 — Scriptorium Chrome (`Console.tsx` outer shell)**: `RomanSurfaceHeader` (`WORKSPACE · CONSOLE`), `AgentStrip` + quick-bridge toolbar (`continue in vox term`, `copy last block`, `send to agent`), and the honed Carrara/theme-adapted `term-session-bar` housing session tabs, `+ new session`, `Split Pane Right` / `Split Pane Down`, `<VoxSelect data-testid="term-security-level-select">`, and `term-control-mode-pill`.
- **Layer 2 — Resizable Split Workspace (`ConsoleSplitGrid.tsx`)**: Replaces the stacked `<BlockStreamView>` (`max-h-[340px]`) + `<TerminalTab>` double-echo layout with 1..N resizable panes (`Group` / `Panel` / `Separator` from `react-resizable-panels@4.22.1`, wrapped by `ResizablePanelGroup` / `ResizablePanel` / `ResizableHandle` in `src/components/ui/Resizable.tsx`), each mounting one `<TerminalSessionPane>` bound to its own `sessionId` plus `DiscoveryRail` pinned to the right edge of `Console`.
- **Layer 3 — Command Block Stream & Persistent Warm VT Canvas (`TerminalSessionPane.tsx`)**: A single unified viewport container (`relative flex min-h-0 flex-1 flex-col bg-bg-base`) where:
  - **Blocks Mode (default when `altScreen === false` and `viewMode === 'blocks'`)**: `BlockStreamView` fills `100%` of the pane height (`flex-1 min-h-0 overflow-y-auto`, removing the old `max-h-[340px]` clamp), while the xterm host `<div role="application" aria-label="terminal" data-testid="terminal-viewport">` stays mounted in the DOM behind/layered (`opacity-0 pointer-events-none absolute inset-0 -z-10` with valid dimensions) so xterm's WebGL/DOM buffer stays warm and `getByLabelText('terminal')` + `getByTestId('block-stream-view')` both remain mounted and accessible. **Textbox Accessibility Invariant**: While in `Blocks` mode (`!altScreen && viewMode === 'blocks'`), `<TerminalSessionPane>` MUST set `tabIndex={-1}` and `aria-hidden="true"` on `.xterm-helper-textarea` so `Console.test.tsx`'s `screen.getByRole('textbox')` resolves uniquely to the console prompt input!
  - **Full-Bleed VT / Auto-TUI Mode (`altScreen === true` or `viewMode === 'vt'`)**: Synchronously (`<16 ms`) flips the xterm host layer to `opacity-100 pointer-events-auto relative z-10 flex-1`, restores `tabIndex={0}` and removes `aria-hidden` on `.xterm-helper-textarea`, collapses `BlockStreamView` (`sr-only` / zero-height while preserving `data-testid="block-stream-view"` landmark if required by tests), displays the top `TUI Active - Return on exit` status strip, calls `fitAddon.fit()`, and focuses xterm (`term.focus()`).

   - `termSessionAttach(sid)` (1-arg initial attach) writes `snap.replay_utf8` once. Subsequent `SessionEvent` refreshes call `termSessionAttach(sid, lastSeq)` and **never** re-write `replay_utf8` onto `termRef` unless `snap.resync_required === true`.
