<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PTY byte stream (`vox://term-output`, `vox://term-event`) → `sessionReducer.ts` / `WebLinksTerminalAddon` | Untrusted terminal output and URLs emitted by external CLI programs, logs, or curl responses |
| Frontend `transport.ts` → Tauri `commands::pty` (`term_session_attach`) | Session attachment IPC boundary carrying `sessionId` and optional monotonic `afterSeq` cursor |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-443-01 | Denial of Service | `transport.ts` / `TerminalTab.tsx` (`termSessionAttach`) | medium | mitigate | Preserve 1-arg initial attach and reduce `SessionEvent` deltas in-memory via `sessionReducer.ts` instead of re-invoking `term_session_attach` on every event or command submit (preventing Tauri `attached_forwarders` abort/respawn churn and 2 MiB `replay_utf8` echo storms) |
| T-443-03 | Elevation of Privilege / Spoofing | `xtermAddons.ts` (`WebLinksTerminalAddon`) | high | mitigate | Strictly allowlist `http://` and `https://` web URLs (normalizing `localhost:<port>` to `http://localhost:<port>`) and reject `javascript:`, `data:`, `vbscript:`, and `file://` URLs before invoking `voxTransport.openLocator` |
| T-443-SC | Tampering | `crates/vox-gui/ui/package.json` | high | mitigate | Zero new npm or Cargo packages installed; all 5 xterm addons are implemented in-repo against pinned `@xterm/xterm@6.0.0` |
</threat_model>
