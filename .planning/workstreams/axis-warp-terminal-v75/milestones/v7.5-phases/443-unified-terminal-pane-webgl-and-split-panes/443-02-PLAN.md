<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted PTY `Stdout` / `Stderr` chunks → `sgrToSpans.ts` React DOM tree | Arbitrary escape codes, HTML/script tags, and malicious URI schemes emitted by commands or remote HTTP payloads |
| `BlockCard.tsx` `AwaitingInput` stdin bar → `onSendStdin` (`termSessionInput`) | Interactive password/sudo prompts where secrets must never be echoed in plain text or persisted in `Block.input` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-443-02 | Tampering / Cross-Site Scripting | `sgrToSpans.ts` | critical | mitigate | Construct React `<span>` and `<button type="button">` elements exclusively with text children; never set `innerHTML` or HTML-injection props; verify `<script>alert(1)</script>` renders as literal text and zero `<script>` DOM nodes exist |
| T-443-03 | Elevation of Privilege | `sgrToSpans.ts` link tokenizer | high | mitigate | Allowlist web links strictly to `http://` and `https://` (normalizing `localhost:<port>` to `http://localhost:<port>`), rejecting `javascript:`, `data:`, `vbscript:`, and `file://` schemes before calling `voxTransport.openLocator` |
| T-443-04 | Information Disclosure | `BlockCard.tsx` (`credential_prompt` stdin) | high | mitigate | Render `<input type="password" autoComplete="off">` whenever `block.credential_prompt === true`, clear React input state immediately on submit, and route stdin exclusively through `onSendStdin` (`termSessionInput`) rather than command history |
</threat_model>
