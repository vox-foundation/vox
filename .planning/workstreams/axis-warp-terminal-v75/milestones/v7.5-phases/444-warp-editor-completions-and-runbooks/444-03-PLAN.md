<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Command stdout (`!nu`, `.vox`, JSON CLIs) → `BlockCard` / `JsonLedgerTable` | Untrusted JSON payloads with deeply nested objects, huge row counts, or HTML-like strings |
| Operator `{{param}}` form input → `RunbookPanel` / `OmnibarRunbookSheet` command template | User-supplied parameter values substituted into shell or `vox run` command templates |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-444-03 | Tampering / Elevation of Privilege (Command Injection) | `RunbookPanel.tsx` + `OmnibarRunbookSheet.tsx` (`interpolateRunbookCommand`) | high | mitigate | Validate `{{param}}` identifiers (`^[A-Za-z_][A-Za-z0-9_]*$`) and shell-quote every substituted parameter value using single-quote escaping (`'${val.replace(/'/g, "'\\''")}'`) unless safe bare identifier/numeric token (`^[A-Za-z0-9_./:-]+$`), preventing `;`, `$(...)`, backtick, and newline injection |
| T-444-06 | Denial of Service / XSS | `JsonLedgerTable.tsx` | medium | mitigate | Parse JSON defensively via `tryParseStructuredJson` (ignoring payloads `> 1 MiB`), cap rendered rows at `500` with explicit truncation indicator, and render all cell values as plain React text nodes (zero raw HTML injection) |
</threat_model>
