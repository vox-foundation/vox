## Pillar 1: Visual Hierarchy, Focal Points & Module Decomposition

### Primary Focal Point & 4-Layer Visual Hierarchy
- **Primary Focal Point**: `ScriptoriumPromptEditor` anchored at the bottom dock of the active `Console` column (`border-t border-border-subtle px-2 py-2`), directly below the active `<TerminalSessionPane>`. When the operator types, presses `Tab` / `Ctrl+Space`, or invokes `Ctrl+R`, visual priority elevates immediately to the single active floating Scriptorium popover (`IntelliSensePopover` or `HistorySearchPopover`, mutually exclusive at `bottom-[calc(100%+8px)] left-0 z-50`).
- **Layer 1 — Universal Prompt Composer (`ScriptoriumPromptEditor.tsx`)**: Left cluster (`<VoxSelect data-testid="term-shell-mode-select">` + auto-detected intent pill `data-testid="console-input-mode-badge"`), center auto-growing syntax-highlighted `<textarea rows={1}>` + `<pre aria-hidden="true">` mirror (`min-h-6 max-h-40`), right chord hint (`Shift+Enter newline - Ctrl+R history`) + `Run Command` / `Ask Agent` CTA.
- **Layer 2 — Mutually Exclusive Floating Overlays (`IntelliSensePopover` vs `HistorySearchPopover`)**: Opening `HistorySearchPopover` (`Ctrl+R`) immediately dismisses `IntelliSensePopover`; typing in `ScriptoriumPromptEditor` while `HistorySearchPopover` is closed drives `IntelliSensePopover`. Both overlays NEVER mount simultaneously.
- **Layer 3 — Structured Command Output (`BlockCard.tsx` + `JsonLedgerTable.tsx`)**: Structured JSON blocks (`!nu ... | to json`, `.vox`, `--json`) render a `Table` / `JSON` segmented tab switch in the `BlockCard` header, mounting the sortable/filterable `@tanstack/react-table@9.3.1` Roman Scriptorium ledger when `Table` is selected.
- **Layer 4 — Right-Hand Discovery & Runbook Tablet (`DiscoveryRail.tsx` + `RunbookPanel.tsx`) & Subshell Strip (`Voxify Subshell`)**: Persistent `w-[268px]` right rail hosting `Action Help` (default tab) and `Runbooks` (`data-testid="term-runbook-panel"`), synchronized with `Omnibar.tsx` (`Cmd+P` / `Cmd+K`), plus `Voxify Subshell` (`data-testid="term-voxify-subshell"`) in `ConsoleSessionBar` and `TerminalSessionPane` when a nested subshell is detected.

### `< 500` Non-Blank LoC File Budget (`god_object` Guardrail)
Every new or modified `.ts`/`.tsx` file MUST stay strictly `< 450` non-blank LoC:
- `Console/ScriptoriumPromptEditor.tsx` — universal multi-line composer, mirror scroll/height sync, paste guard, `Up`/`Down` recall, `Ctrl+R` trigger.
