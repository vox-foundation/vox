<objective>
Build the production trial runner in `vox-cli-research` (D-02 default: L5). One entry point, `run_campaign`, takes a `SignedCampaign`. It:
- verifies the campaign against the Clavis allowlist through the typestate gate;
- persists the campaign and opens each run before executing it;
- runs each preregistered cell through a `TrialExecutor` (the real pipeline, or canned fixtures in tests);
- scores with `score_result` and persists each run batch atomically.

Purpose: TRIAL-05 requires the gate to be called by the production runner and proven by mutation. TRIAL-01 requires identity to propagate from the runner into the pipeline (session key, label) and into Tier A. This plan is the first producer of trial rows.
Output: `crates/vox-cli-research/src/trial/{mod,runner,executor,allowlist}.rs`.
</objective>
