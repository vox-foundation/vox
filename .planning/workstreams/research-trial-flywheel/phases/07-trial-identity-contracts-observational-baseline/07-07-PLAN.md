<objective>
Build the Tier A write API for trials. It has four parts:
- an exclusive-transaction primitive on the shared connection;
- one-transaction campaign creation and run-batch persistence, each with a public test failpoint (STORE-02, D-08 item 5);
- compare-and-set lifecycle operations (TRIAL-03);
- the attempt rules that make TRIAL-04 retries linked and same-run_id resume impossible.

Purpose: the existing BEGIN/COMMIT pattern is not isolated, because `GuardedConnection` locks per statement, so another task's statement can land inside an open transaction (RESEARCH Q3). A partial campaign/run/sample batch is exactly what success criterion 3 forbids.
Output: `crates/vox-db/src/trials.rs`, the `GuardedConnection::transaction` helper, record types in vox-db-types, and the new error variants.
</objective>
