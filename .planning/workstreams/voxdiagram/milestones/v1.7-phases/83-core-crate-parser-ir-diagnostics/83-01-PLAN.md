<interfaces>
Contract this plan CREATES (Plans 02-07 build against it; field names are binding):

span.rs
- `pub struct Span { pub start: u32, pub end: u32 }` byte offsets; derive Serialize, Deserialize, Debug, Clone, Copy, PartialEq, Eq, Default. Used by AST nodes and `Fix`.
- `pub struct Location { pub start: u32, pub end: u32, pub line: u32, pub col: u32, pub end_line: u32, pub end_col: u32 }` 1-based line/col, col counted in Unicode scalar values; same derives. Used by IR items, `Diagnostic`, `Related`.
- `pub(crate) struct LineIndex` (sorted line-start offsets, `partition_point` lookup) with `pub(crate) fn new(src)`, `pub(crate) fn location(&self, src, Span) -> Location`; `pub(crate) fn slice(src, Span) -> Option<&str>` via `str::get`.

diag.rs
- `pub enum Severity { Error, Warning }` serde lowercase.
- `pub struct Fix { pub span: Span, pub replacement: String }`.
- `pub struct Related { pub message: String, pub span: Location }`.
- `pub struct Diagnostic { pub code: &'static str, pub severity: Severity, pub message: String, pub span: Location, pub help: Option<String>, pub fixes: Vec<Fix>, pub related: Vec<Related> }` — `help`/`fixes`/`related` use `skip_serializing_if` when empty. Serialize only.
- `pub struct Stats { pub nodes: u32, pub containers: u32, pub edges: u32, pub max_depth: u32 }`.
- `pub struct CheckReport { pub schema_version: u32 /* always 1 */, pub valid: bool, pub diagnostics: Vec<Diagnostic>, pub stats: Stats, pub ir: Option<Ir> /* skip when None */ }`. `valid` == no Error-severity diagnostic; `ir` is Some only when there is no Error (A2).

ir.rs (derive Serialize, Deserialize, Debug, Clone, PartialEq, Eq; Vec only, declaration order)
- `#[serde(tag = "kind", rename_all = "kebab-case")] pub enum Ir { Graph(GraphIr) }` — Phase 86 adds `Sequence` additively.
- `pub struct GraphIr { pub direction: Direction, pub nodes: Vec<IrNode>, pub containers: Vec<IrContainer>, pub edges: Vec<IrEdge> }`
- `pub struct IrNode { pub id: String /* full dotted path */, pub local_id: String, pub label: String, pub shape: Shape, pub container: Option<String>, pub span: Location }`
- `pub struct IrContainer { pub id: String, pub local_id: String, pub label: String, pub parent: Option<String>, pub depth: u32 /* top-level container = 1 */, pub span: Location }`
- `pub struct IrEdge { pub from: String, pub to: String, pub label: Option<String>, pub span: Location }`
- `pub enum Shape { Rect /* Default */, Rounded, Diamond, Cylinder, Start, End }`, `pub enum Direction { Down /* Default */, Right, Up, Left }`, both serde lowercase.

ast.rs (derive Debug, Clone, PartialEq, Eq, Serialize; every node carries `span: Span`)
- Ordered-entry shape (RESEARCH Pattern 4): `Document { body: Block, .. }`, `Block { entries: Vec<Entry> }`, `Entry::Item(Item)`, `Item { kind: ItemKind, blank_before: bool, span }`, `ItemKind::Node(NodeDecl) | ItemKind::Edge(EdgeStmt)`, `NodeDecl { id: Ident, label: Label, shape: Shape }`, `EdgeStmt { from: Ref, to: Ref, label: Option<Label> }`, `Ref { segments: Vec<Ident>, span }`, `Ident { name, span }`, `Label { value /* decoded */, span }`. Plan 02 adds Comment/Direction/Container variants and trivia fields.

check.rs (public API)
- `pub fn check(source: &str) -> CheckReport` — never panics.
- `pub fn parse(source: &str) -> Parsed` with `pub struct Parsed { pub ast: Option<ast::Document>, pub diagnostics: Vec<Diagnostic> }` (`ast` None only when the size gate tripped).

codes.rs: `pub const UNEXPECTED_TOKEN: &str = "diagram/unexpected-token";` etc., plus `pub const ALL_CODES: &[&str]` listing every code. limits.rs: `MAX_SOURCE_BYTES = 65_536`, `MAX_NODES = 500`, `MAX_EDGES = 1_000`, `MAX_DEPTH = 4`, `MAX_LABEL_CHARS = 200`, `MAX_DIAGNOSTICS = 100` (all `pub const usize`).
