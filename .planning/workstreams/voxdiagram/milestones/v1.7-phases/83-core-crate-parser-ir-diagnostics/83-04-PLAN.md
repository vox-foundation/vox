<objective>
Make one `check` report every independent error (DGM-03) and make hostile or oversized input fail
span-precisely in bounded time (DGM-06): panic-mode recovery with declare-then-diagnose, the full syntax
and semantic diagnostic catalogue, a single sorted/deduped/capped diagnostic collector, fuel, per-kind
caps and an iterative depth skip.

Purpose: agents with no DSL training data learn from diagnostics; noisy cascades or a hang would defeat
the milestone's core value.
Output: recovery module, catalogue codes, collector, broken fixtures with `// expect:` headers, limits and
adversarial tests.
</objective>

Contract this plan adds:
- `pub(crate)` diagnostic collector in diag.rs: push returns whether the cap is reached; `finish()` sorts by `(span.start, code)`, removes exact duplicates (same code and span), and guarantees `len() <= MAX_DIAGNOSTICS` with `diagram/limit-diagnostics` (Warning) as the last entry when the cap tripped.
- Parser fuel: `4 * token_count + 1_000`, decremented once per statement-loop iteration and per scan-ahead step; exhaustion emits `diagram/limit-diagnostics` once and stops parsing.
- Codes added (all in `codes.rs` + `ALL_CODES`): `expected-quoted-label`, `unclosed-brace`, `trailing-content`, `unknown-diagram-kind`, `reserved-word`, `invalid-direction`, `duplicate-direction`, `direction-in-container`, `invalid-shape`, `unknown-attribute`, `duplicate-id`, `shadowed-id` (Warning), `empty-label`, `limit-nodes`, `limit-edges`, `limit-depth`, `limit-label`, `limit-diagnostics` (Warning) — each prefixed `diagram/`.
