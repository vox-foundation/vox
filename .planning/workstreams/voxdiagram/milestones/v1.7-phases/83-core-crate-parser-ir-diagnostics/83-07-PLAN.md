Mermaid catalogue (RESEARCH "Mermaid-ism Detection and Canonical Rewrites"; all `diagram/mermaid-syntax`, Error, one diagnostic per occurrence, all edits of one rewrite in that diagnostic's `fixes`):
- M1 arrow `-{2,}>` between refs -> fix replaces it with `->`; `==>`, `-.->`, `---`, `--x`, `--o` -> no fix (style would be lost).
- M2 `-->|text|` or `-- text -->` -> Edge with label; fixes: replace the arrow-through-closing-pipe (or `-- .. -->`) with `->` AND insert `: "text"` after the target ref (text trimmed, surrounding quotes stripped, `<br>`/`<br/>` -> newline escape, `\` and `"` escaped).
- M3 ident immediately followed by `[` `(` `{` -> implicit NodeDecl in the current scope (declared in pass A, so no undeclared-node). Statement start: replace `A[Label]` with `node A: "Label"` (+ ` { shape: x }` unless rect). Inside an edge: replace `A[Label]` with `A` and insert `node A: "Label"` via Rule R. Exact map: `[ ]` rect, `( )` rounded, `{ }` diamond, `[( )]` cylinder; `(( ))`, `([ ])`, `[[ ]]`, `{{ }}`, `>..]` -> no fix. Bracket text may be quoted (`A["Label"]`: quotes stripped) or unquoted with punctuation (`A[API: gw (beta) / x.y]`): the label runs to the matching closing bracket and is never split on `:`, `(`, `/` or `.` (corpus census FEATURES.md 0.3); `<br>`/`<br/>` become the `\n` escape. Repeat of an already declared id: same label+shape -> only the bare-id replacement; different -> `diagram/duplicate-id`.
- M4 statement-head `subgraph ID`, `subgraph ID[Title]`, `subgraph ID["Title"]` ... `end` -> Container (Mermaid frame); one diagnostic, two edits: header -> `container ID: "Title" {` (title defaults to id), the `end` line -> `}`. Title-only `subgraph My Title` -> no fix. `end` closes only inside a Mermaid frame and only as a whole statement.
- M5 first statement `graph`/`flowchart` + optional `TD|TB|BT|LR|RL` + optional `;` with no `{` -> body parsed to EOF; fixes: replace the header with `graph {` + newline + `    direction: <down|down|up|right|left>` (TD,TB->down, BT->up, LR->right, RL->left; no direction token -> just `graph {`) and insert newline + `}` + newline at EOF.
- M6 `direction LR` or `direction: LR` -> replace with `direction: right` (mapped as M5).
- M7 `%%` comment -> replace `%%` with `//`; `%%{` directives -> no fix.
- M8 `;` -> trailing: delete; mid-line: replace with newline + the statement's indent.
- M9 statement-head `style`, `classDef`, `class`, `linkStyle`, `click`, `callback`, `accTitle`, `accDescr`, and a `:::name` suffix -> skip to end of line, no fix, message "styling is theme-controlled; VoxDiagram has no equivalent". Only when the head word is not followed by `->`, `.` or `:` (so an id named `class` still works in an edge).
- M10 `A & B --> C` -> `diagram/mermaid-syntax` with a fix replacing the statement by the expanded edge lines; `a -> b -> c` -> `diagram/chained-edge` with a fix splitting it into `a -> b` and `b -> c` lines.
