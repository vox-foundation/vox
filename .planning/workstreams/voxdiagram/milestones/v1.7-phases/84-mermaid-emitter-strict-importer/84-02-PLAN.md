Created here:
- Subgraph emission (CONTEXT "Containers"): `subgraph <id> ["<label>"]` … `end`, nesting preserved.
  Emission order: header; nodes with no (known) container in IR order; then top-level containers in IR order,
  each emitting its member nodes (IR order) then its child containers (IR order) then `end`; then every edge.
  `IrContainer` has no direction field, so no `direction` line is ever emitted (CONTEXT post-research
  decision; the "container direction emitted only when set" rule has nothing to emit).
- Totality rules: a node whose `container` names no container is top level; a container nests under its
  `parent` only if that parent appears EARLIER in `ir.containers` (true for every `check()` IR; makes cycles
  impossible), otherwise it is top level; emission uses an explicit stack, never recursion; an edge endpoint
  that is no node or container gets a fresh `n<k>` id and appears as an implicit Mermaid node; edges whose
  endpoint is a container id export as a Mermaid edge to that subgraph (only hand-built IRs do this). Every
  container and node is emitted exactly once.
- `pub fn export_sequence(ir: &SequenceIr) -> String` in `mermaid/export_seq.rs`, re-exported from
  `mermaid/mod.rs`. Output: `sequenceDiagram`; `participant p<i> as <text>` per actor in order (ids are
  always opaque `p<index>`: sequence keywords such as `end`, `loop`, `opt` break as actor ids, RESEARCH
  "Sequence export"); then one participant per dangling actor id in first-appearance order, labelled with
  that id; then events in order: `p<i>->>p<j>: <text>` (solid), `p<i>-->>p<j>: <text>` (dashed),
  `Note over p<i>: <text>` or `Note over p<i>,p<j>: <text>`. A note whose `over` is empty or longer than two
  is degenerate (neither the importer nor Phase 86's parser produces one): it exports with at most its first
  two ids and is documented on `export_sequence` as outside the acceptance guarantee.
- `escape::seq_text(s: &str) -> String`: `escape::label`'s rules (without the blank-to-space rule) plus `;`
  to `#59;` and, when the trimmed text starts with `wrap:`, `nowrap:`, `:wrap:` or `:nowrap:`, its first
  character numerically encoded (`#119;`, `#110;`, `#58;`) (RESEARCH "Sequence export"). Blank message text
  prints as a bare `p0->>p1:`; blank actor labels and note text print `#32;`.
- `tests/support/roundtrip.rs::canon_sequence(&SequenceIr) -> Value` (shape in plan 84-01's interfaces:
  actors = trimmed labels including dangling participants; message = `["message", from, to, dashed, text]`,
  note = `["note", [idx…], text]`, texts trimmed).
- Hostile fixture naming: graph cases `export-hostile/gNN-<name>.*`, sequence cases `sNN-<name>.*`; each
  golden test fails on an orphan file with its own prefix.
