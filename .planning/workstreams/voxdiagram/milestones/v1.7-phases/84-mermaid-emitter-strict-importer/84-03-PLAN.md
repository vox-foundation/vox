Accepted flowchart subset (RESEARCH "Importer Rules"; physical line numbers within the block):
- Header: first non-blank line `graph` or `flowchart`, optionally followed by `TD TB LR RL BT`
  (`TD`/`TB` down, `LR` right, `RL` left, `BT` up; none = down); a header ending in `;` is `semicolon`,
  any other header is `header:<first word>`. Blank lines anywhere are ignored.
- Node reference: DSL-valid id, optionally followed IMMEDIATELY by a shape: `[…]` rect, `(…)` rounded,
  `{…}` diamond, `[(…)]` cylinder, `((…))` start, `(((…)))` end (check longer openers first). A bare id
  is rect with label = id (implicit node).
- Statement: groups of references joined by `&`, separated by arrows; an arrow is `-->`, `-->|text|`,
  `-->|"text"|`, `-- text -->` or `-- "text" -->`; spaces around tokens optional (`A-->B`). Each pair of
  consecutive groups expands to their cartesian product with that arrow's label; more than 100 edges from one
  statement is `expansion-cap` (count before materialising). A single reference alone declares or mentions
  a node; several `&`-joined references with no arrow is `statement`.
- `subgraph <id>`, `subgraph <id>[Title]`, `subgraph <id> [Title]`, `subgraph <id>["Title"]`,
  `subgraph <id> ["Title"]` open a container (no title: label = id); a trimmed line `end` closes the
  innermost one. Open subgraphs are tracked in a `Vec` (never recursion), so 4,000 nested headers cannot
  overflow the stack.
- `direction X` inside a subgraph: X equal to the diagram direction (`TD` = `TB`) goes to `dropped` as
  `subgraph-direction`; any other X is unsupported `subgraph-direction` (CONTEXT post-research decision).
- With `drop_styling`: styling lines go to `dropped` (same construct name) and a `:::name` suffix is
  stripped from its reference, which then imports normally (CONTEXT "Styling").
- Only `;`, `%%` and `:::` OUTSIDE quotes, brackets and edge text count as constructs; inside a quoted
  label they are text (exported labels contain `;`, `|`, `-->`, `end`, `subgraph` freely).

Text rules (`text.rs`), applied to node labels, subgraph titles and edge text:
- Quoted text = starts with `"` right after the opener and ends with `"` right before the closer; anything
  except `"` inside. A quoted text that starts with a backtick is `markdown-string` (Mermaid's
  markdown-string opener, rejected by the real parser; corpus block 29; RESEARCH Pitfall 4).
- Unquoted text must not contain `( ) [ ] { } | " @` (`label-syntax`; RESEARCH measured these as the parse
  errors).
- Raw `<` followed by an ASCII letter, `/`, `!` or `?`, other than `<br>`, `<br/>`, `<br />` in any case,
  is `html-label`. A raw `&name;`, `&#digits;` or `&#xhex;` is `html-entity` (it renders differently from
  its literal text; strict).
- Decoding, in this order on the raw text: the three br forms become `\n` (spaces around them kept);
  then one left-to-right pass decodes Mermaid entities `#quot; #lt; #gt; #amp; #apos; #nbsp;` and
  `#<decimal>;` (a valid scalar value) and leaves every other `#` literal, except `#<letters>;` with an
  unknown name, which is `entity`; then trim. Never decode twice (`#35;quot;` is the text `#quot;`).
- After decoding: empty node label or title is `empty-label` (an empty edge text means no label); more than
  `MAX_LABEL_CHARS` characters is `label-too-long`; any `lexer::is_forbidden` character is `forbidden-char`.
- Every rejection above except those three runs on the RAW text, never on decoded text, so the exporter's
  encoded forms (`#96;`, `#lt;`, `#amp;`, `#35;`) import back as plain text (plan 84-05's fixpoint
  property relies on this).

Semantics:
- Re-declaring a node with the same label and shape is fine; with a different one it is
  `redeclared-node` on the later line (Mermaid is last-wins; never pick one silently).
- A node id equal to a subgraph id, or a duplicate subgraph id, is `id-clash`; an edge endpoint that is a
  subgraph id is `edge-to-subgraph` (two passes: collect subgraph ids first).
- Caps: the 501st node `limit-nodes`, the 1001st edge `limit-edges`, a fifth nesting level `limit-depth`
  (on the line that crosses), from `limits`.
- Membership (CONTEXT "Mermaid subgraph nodes are global"; RESEARCH "Scope rewrite"): a node belongs to the
  first-closed subgraph whose DIRECT body mentions it (declarations and edge endpoints count; inner
  subgraphs close first and win; a node mentioned at root and later inside a subgraph belongs to the
  subgraph; root mentions never claim).
- DSL emission (`to_dsl`, extending 84-01's contract): each scope prints its member nodes in global
  first-mention order, then its child containers in open order (`container <id>: "<title>" {` … `}`), then
  the edges whose deepest common scope is this one, in source order, with endpoints written relative to
  this scope (child-container path then node id, joined by `.`; bare when the node is a direct member).
  Mermaid ids are globally unique and `id-clash` is rejected, so relative paths never shadow.

Construct catalogue (stable names; tests assert them exactly): `header:<word>`, `statement`, `comment`,
`directive` (`%%{`), `semicolon`, `styling:style`, `styling:classDef`, `styling:class`, `styling:linkStyle`,
`styling:click`, `styling:callback`, `styling:accTitle`, `styling:accDescr`, `styling:shorthand` (`:::`),
`edge-type:<token>` (`---`, `--->`, `-.->`, `-.-`, `==>`, `===`, `--o`, `--x`, `<-->`, `o--o`, `x--x`,
`~~~`), `edge-label`, `shape:<opener>` (`([`, `[[`, `{{`, `>`, `[/`, `[\`, `@{`), `label-syntax`,
`markdown-string`, `html-label`, `html-entity`, `entity`, `forbidden-char`, `empty-label`,
`label-too-long`, `invalid-id`, `reserved-id`, `id-clash`, `edge-to-subgraph`, `redeclared-node`,
`subgraph-title` (`subgraph "Title"` or a title with spaces and no brackets), `subgraph-direction`,
`direction` (at root, or an invalid token), `stray-end`, `unclosed-subgraph` (on each unclosed header),
`expansion-cap`, `limit-source`, `limit-nodes`, `limit-edges`, `limit-depth`, `internal`. A styling head
counts only when the head word is followed by whitespace and the next token is not an arrow (an id named
`class` in `class --> b` stays an edge, as in 83-07's M9).
