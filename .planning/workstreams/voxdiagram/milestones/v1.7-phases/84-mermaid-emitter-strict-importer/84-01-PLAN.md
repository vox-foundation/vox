DSL the importer emits (byte-stable contract; later importer plans keep the tracer golden unchanged):
the `fmt` output of `graph {`, then `    direction: <word>` only when the direction is not `down`, then
node declarations `node <id>: "<label>"` (plus ` { shape: <word> }` unless rect) in first-mention order,
then edges `<from> -> <to>` (plus `: "<label>"`) in source order, then `}`. A node first seen as a bare
id is rect with label = id.

Mermaid the exporter emits (one statement per line, 4 spaces per nesting level, root statements at 4):
- header `flowchart TD|LR|BT|RL` for `Down|Right|Up|Left`;
- node `<id>["…"]` rect, `<id>("…")` rounded, `<id>{"…"}` diamond, `<id>[("…")]` cylinder,
  `<id>(("…"))` start, `<id>((("…")))` end (CONTEXT "Shapes");
- all edges after all declarations: `<from> --> <to>` or `<from> -->|"…"| <to>`; a `Some("")` label is
  omitted (CONTEXT "Labels"; RESEARCH "Text encoding");
- subgraphs (`subgraph <id> ["…"]` … `end`) are plan 84-02's slice; this plan's IRs are flat.
- every label goes through `escape::label`, implementing all rows of RESEARCH "Text encoding": `&` `"`
  `<` `>` to `#amp;` `#quot;` `#lt;` `#gt;`; `#` to `#35;`; backtick to `#96;`; newline to `<br>`; `%` to
  `#37;` when the text contains `%%`; `:` to `#58;` when the text contains `style` or `classDef`; every
  other C0 control, DEL, U+2028, U+2029, U+FB02, U+00B6 to `#<decimal>;`; a result that is empty after
  trim becomes a single space (port of RESEARCH "Reference implementation of the rules").
- id policy (CONTEXT "Ids"; RESEARCH "Id policy"): keep `local_id` iff `keeps_id` holds (matches
  `[A-Za-z_][A-Za-z0-9_]*`; its ASCII-lowercase form is not one of `end graph flowchart subgraph style class
  classdef linkstyle click default interpolate call href direction` and contains neither `style` nor
  `classdef`; does not start with `o` or `x`; is not `n` followed only by digits) AND no earlier node or
  container already emitted that id; otherwise `n<i>` where i is the node index, containers continue at
  `nodes.len() + index`, and dangling edge endpoints continue after that in first-appearance order.

  `crates/vox-kb-facets/tests/facet_schema_golden.rs`); a golden with no source input fails.

Canonical sets (`*.sets.json` = `serde_json::to_string_pretty` + newline; Node builds the same shape from
the real parser's DB):
- graph: `{"kind":"graph","direction":<word>,"nodes":[[label, shape, [title…]]…],
  "edges":[[nodeKey(from), nodeKey(to), edgeLabel]…],"containers":[[title…]…]}`. Labels, titles and edge
  labels are trimmed; a missing edge label is `""`; shape is the lowercase `Shape` word; a title path lists
  container labels from the root to the innermost container; a nodeKey is that node's
  `[label, shape, [title…]]`. Rust sorts each list by `serde_json::to_string`; Node re-sorts both sides by
  `JSON.stringify` before comparing, so the two sort orders never need to agree.
- sequence (written from plan 84-02 on): `{"kind":"sequence","actors":[label…],"events":[["message",
  fromIdx, toIdx, dashed, text] | ["note", [idx…], text]…]}`, ordered, actor index = declaration order.

Node helper `docs-astro/tests/lib/mermaid-oracle.mjs` exports `accepts(src)`, `decodeLabel(s)`,
`canon(src)` (dispatch on the first non-blank line: `graph`/`flowchart` to the flowchart DB,
`stateDiagram-v2` to the state DB, `sequenceDiagram` to the sequence DB, anything else throws) and
`sameSets(a, b, message)`.
