<decisions>
## Implementation Decisions

### MCP tool & CLI shape
- `vox_validate_diagram` input `{source, from_mermaid?: bool, emit?: "svg" | "mermaid"}`; output `{valid, diagnostics[] (code, severity, span, message, fixes[]), normalized_source, stats, emitted?, unsupported?}`, mirroring `vox_validate_vuv`'s envelope; deterministic, no LLM calls. `from_mermaid: true` runs `mermaid::import` and returns the converted DSL as `normalized_source` or the by-line `unsupported` list.
- Profile: add to the `lang` profile alongside `vox_validate_vuv` (resolves `profile-parity`).
- CLI `vox diagram check|fmt|render|export|import <file|->`; exit 0 = ok, 1 = diagnostics with errors (or unsupported on import), 2 = usage/IO; `fmt --check` and `fmt --write`; `render`/`export` write to stdout or `-o FILE`; reaches the crate only via `vox_doc_pipeline::diagram` (no `vox-cli -> vox-diagram` edge).
- Diagnostics human-readable `file:line:col: code: message` by default; `--json` emits the same envelope as the MCP tool.

### Agent guidance & catalog coordination
- `vox_diagram::GRAMMAR_CARD` (existing, tested) embedded in the MCP tool description; published as a new reference page `docs/src/reference/vox-diagram.md` (full frontmatter + kb:summary + authorship llm-assisted + authorship_model), whose examples are ```` ```vox-diagram ```` fences validated by the Phase 87 lint.
- AGENTS.md: one short subsection (≤ ~10 lines): new docs diagrams use ```` ```vox-diagram ```` (link the reference page + `vox_validate_diagram`); don't add ```` ```mermaid ```` (ratchet).
- Catalog: edit only source rows (`contracts/operations/catalog.v1.yaml` and the other hand-maintained inputs); run generators locally so tests pass; on merge with `main` generated files are regenerated by `ssot-autoregen`, never hand-merged. The `unified` milestone also edits the catalog — keep the row additions append-only and minimal.
- Crate edge (USER-AUTHORIZED in chat 2026-10-16): exactly `vox-orchestrator-mcp -> vox-diagram` with ONE `exceptions` entry citing that authorization. No other edge; never regenerate baselines.
- GUI coverage: cover the tool (no new exemption; the exemption ratchet is capped and shrink-only).

### Claude's Discretion
- File names (`diagram_tools.rs`, `commands/diagram.rs`), JSON schema details, CLI help text, reference page structure.

</decisions>
