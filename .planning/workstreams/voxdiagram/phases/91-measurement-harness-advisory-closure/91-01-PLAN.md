the statistics (paired Newcombe interval and non-inferiority verdict) in `vox-eval`, the scorer in `vox-cli`, and the
Node batch oracle around the pinned real Mermaid parser, joined by the re-score chain
`tasks -> reference-inputs (Rust) -> reference-outputs (Node) -> attempts + reference-outputs -> oracle-inputs (Rust)
-> oracle-outputs (Node) -> tallies.json + tables.md (Rust)`, every link byte-checked by an ordinary offline test.

- Task 1 (tracer): the whole chain on a 3-task synthetic recording, first-pass validity only.
- Task 2: `vox-eval::paired_ni` test-first against the RESEARCH worked numbers.
- Task 3: full tallies (repair turns, exclusions, completeness, paired interval and verdict, McNemar, fidelity, cost,
  per-kind, two slots) and the recording checks.

Purpose: the live run (91-04) can only be trusted if its numbers re-derive from the raw outputs without the network;
this plan builds and proves that path before any task set or model exists.
Output: `paired_ni.rs`, the `eval_diagram` module (mod, oracle, score, render), the Node batch oracle, both re-score
tests, the synthetic fixture.
</objective>
