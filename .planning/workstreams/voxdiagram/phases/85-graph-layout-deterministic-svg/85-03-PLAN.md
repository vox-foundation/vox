<objective>
Render containers safely: dagre cannot size or title containers and can misplace leaves in dense compound
graphs, so the adapter adds a title strut, the seam pads and titles the final rect, and the verifier fails
closed on every containment rule (CONTEXT "Post-research decisions": invisible title-strut leaf per container
+ 3-rung deterministic separation ladder + fail-closed geometry verifier; residual failures return
`RenderError::Geometry`).

Purpose: the "containers" half of REND-01 and SC2's "children inside their container". Also hardens the
renderer against hand-built IR, since `Ir` is public (RESEARCH Pitfall 6).
Output: container support end to end, container verifier checks and doubles, `svg_errors` test binary,
container goldens.
</objective>
