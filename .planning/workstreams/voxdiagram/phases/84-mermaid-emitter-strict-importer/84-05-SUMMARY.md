**4. F2 generator domain (documented, not a filtered counterexample):** F2's first counterexample was a note text containing U+0001. The exporter encodes it as `#1;` and the importer refuses it as `forbidden-char` by design (pinned by a unit test in `import/text.rs`; the DSL lexer forbids those characters, so no DSL-sourced IR holds one). F2 therefore draws text from DSL-legal characters; no other input is filtered besides the blank-label preconditions.
