<objective>
Make diagnostics machine-repairable (DGM-04): a deterministic, atomic, never-panicking `apply_fixes`, a
bounded `repair` loop, `fixes[]` on every mechanically fixable native diagnostic (including the
`undeclared-node` declare-fix the user locked), a seeded repairable set proven to reach zero errors, and
the hostile-input property that guards fix safety.

Purpose: agents apply `fixes[]` without re-prompting; applying a fix must always be safe.
Output: `fixes.rs`, fix emission in lexer/parser/resolver, repairable fixtures + snapshots, S3 properties.
</objective>

- `pub fn apply_fixes(source: &str, diagnostics: &[Diagnostic]) -> FixOutcome` with `pub struct FixOutcome { pub text: String, pub applied: usize /* groups */, pub skipped: usize /* groups */ }`.
