Decision (Claude's discretion, record in the SUMMARY): sequence keywords `actor`, `reply`, `note`, `over` are contextual, not reserved. `actor <id> :` declares, `reply <id> ->` is a dashed message, `note over` starts a note; the same words followed by `->` are actor ids. Reason: Mermaid's own parser accepts `participant note` (Phase 84 `mermaid_import_words.rs` pins this), the import case `12-seq-words` declares `Note` and `loop`, and reserving them would make the importer refuse blocks Mermaid reads. The graph `RESERVED` list (which already holds `sequence`) is the only reserved list, so `grammar-card.txt` stays correct.

Sequence geometry (all integer half-pixels; px values below are doubled in code; name every constant):
- Actor box: lines = `text::wrap(label)`; size = `text::node_size(Shape::Rect, &lines)`; every actor box takes the tallest actor height; boxes sit in one top row.
- Lane centres: lane 0 at x = 0; gap_i (centre to centre, lane i to i+1) = max(w_i/2 + w_{i+1}/2 + ACTOR_GAP 24 px, max over every non-self message whose lane range [min(from,to), max(from,to)) contains i of its label box width + 2 * LANE_CLEAR 8 px).
- Message label box: lines = `text::wrap_at(text, usize::MAX)` (explicit `\n` kept, whitespace collapsed, blank lines dropped; 86-03 switches this to the 60-char soft wrap); width = widest `measure` + 2 * LABEL_PAD 4 px, height = lines * LINE_H + 2 * LABEL_PAD; no lines means no label.
- Rows: a cursor starts FIRST_ROW 20 px below the actor row. Non-self message: label box top at the cursor, centred on the midpoint of its two lanes; arrow y = cursor + label height + 4 px (6 px with no label); points `[(x_from, y), (x_to, y)]`; cursor = y + ROW_GAP 16 px. Self-message on lane x: loop points `[(x, y0), (x + SELF_W 30 px, y0), (x + SELF_W, y0 + SELF_H 20 px), (x, y0 + SELF_H)]` with y0 = cursor, label box left edge at x + SELF_W + 6 px vertically centred on the loop; cursor = max(loop bottom, label bottom) + ROW_GAP. Note: lines as messages; width = max(text width + 2 * PAD_X, NOTE_MIN_W 80 px, (rightmost lane x - leftmost lane x) + 2 * NOTE_OVERHANG 16 px), centred on the midpoint of its lanes (one lane: that lane), height = lines * LINE_H + 2 * PAD_Y, top at the cursor; cursor = bottom + ROW_GAP.
- Lifelines run from the actor box bottom to max(cursor, actor bottom + FIRST_ROW).
- Canvas: min and max over every actor rect, note rect, label rect and message point; translate everything so the minimum is `MARGIN` (16 px) on both axes; width/height = extent + 2 * MARGIN. Nothing drawn can lie outside the viewBox. An empty `SequenceIr` renders a 32 x 32 px canvas.
- Lookup of actor ids goes through a `BTreeMap<&str, usize>`; a message or note naming an unknown actor is `RenderError::InvalidIr("event {i}: unknown actor")`. Never index by IR string with `[]`.
