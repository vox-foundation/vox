# `vox-search-core`

Pure-data retrieval and trust-tier contracts (`L1`) for the Vox hybrid search stack (`vox-search`).

Extracted in `Phase 398` to provide `SearchHit`, retrieval trust-tier filtering types (`SystemVerified`, `Trusted`, `Advisory`, `Untrusted`), and query structures without compiling the full Tantivy 0.22 index and vector embedding backends.
