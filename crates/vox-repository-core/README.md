# `vox-repository-core`

Pure-data repository identity and multi-repo federation types (`L0`): `RepositoryDescriptor`, `MultiRepoCatalog`, `RepoCapability`, and `.vox/repositories.yaml` schema structures.

Extracted from `vox-repository` (`Phase 393`) so downstream crates can inspect repository descriptors without pulling in filesystem walkers or `gix` Git dependencies.
