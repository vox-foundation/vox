## What it does

Qwen3.8-27B (`27B`) is a specialized coding model for the [Vox programming language](https://voxlang.org) — a full-stack, AI-native language where database tables, backend endpoints, reactive web UI components, and typed AI agents live in one compiler-checked `.vox` file. Before publishing, Qwen3.8-27B (`27B`) must improve real Vox compiler checks on held-out prompts without losing general software engineering accuracy.

## Why this size

The flagship 27B studio model is designed for high-memory Apple Silicon workstations without needing a remote server cluster. Pick 27B for deep cross-module architecture design, complex multi-file Vox synthesis, and challenging debugging in one pass. Drop down to 9B whenever workstation memory headroom or token speed runs tight.
