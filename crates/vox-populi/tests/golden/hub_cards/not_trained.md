# Vox Mens 27B — Highest-Accuracy Private Model for Writing & Fixing Vox

## What it does

**Vox Mens 27B** writes and fixes [Vox](https://voxlang.org) (`.vox`), a full-stack language where one file defines database tables, backend queries and mutations, web UI components, and workflows that compile to Rust and TypeScript. Because Vox is newer than mainstream languages, general-purpose AI models often guess Rust or TypeScript syntax that fails to compile; **Vox Mens 27B** is fine-tuned on verified `.vox` examples so you can generate and repair Vox locally on Windows, Linux, or Mac (`Ollama`, `vLLM`, Python, or `vox mens serve`) or through Hugging Face Inference Providers without paying large cloud API rates on every prompt.

## Why this size

Vox Mens 27B offers the highest Vox accuracy in this open-weights lineup for high-VRAM GPUs, workstations, and hosted routers — though at 27B it is still a compact model compared to massive proprietary cloud APIs. Use 27B when code must stay private on your own hardware or when offloading day-to-day Vox generation and compiler fixes from metered cloud billing. Pair 27B underneath a large cloud model that handles open-ended product specs and research, or step down to 9B and 4B for lighter local runs.
